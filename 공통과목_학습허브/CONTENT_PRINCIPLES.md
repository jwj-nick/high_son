## 0. 큰 목표 — 시험을 넘어서

**시험 점수가 아니라 "평생 남는 이해"를 만든다.** 개념을 외우게 하지 말고, **왜 그런지 · 어디에 쓰이는지 · 세상과 어떻게 연결되는지**로 기억에 각인시킨다. 20년 뒤 어른이 되어도 상식으로 꺼내 쓸 수 있게.

## 1. 여덟 가지 원칙

### ① 깊이 (Depth) — 교과서보다 한 겹 더
- 교과서 수준 개념 + **"왜 그런가"의 원리 한 겹 아래**까지 내려간다.
- 유도·원리는 **직관 우선**(넓이·비유·그림) → 필요하면 "나중에 배울 것"으로 다리만 놓는다.
- ⚠️ **선보강 금지**: 아직 안 배운 지식을 전제로 시험 내지 않는다. 심화는 `🎓 더 깊이` 토글/배지로 **분리 표시**해서, 몰라도 본 흐름은 막히지 않게.

### ② 흥미 유발 (Hook) — 첫 화면에서 "오, 신기"
- 각 단원·핵심 개념 **도입부**에 놀라운 사실·반직관적 질문·역사적 일화를 둔다.
- "이걸 왜 배워?"에 답하는 훅을 **개념 앞에** 배치. (예: "멘델레예프는 아직 발견도 안 된 원소의 성질을 표의 빈칸으로 예측했다.")

### ③ 단계별 진행 (Progression) — 손 잡고 한 계단씩
- 쉬운 것 → 어려운 것. **이미 아는 것에 이름 붙이기** → 새 개념 도입. (답할 수 있는 질문부터.)
- **점진적 공개**(APP_PRINCIPLES): 문제·질문 먼저, 풀이·정답은 토글로.
- **직접 해보게** 한다: 애니메이션·시뮬레이션·클릭 탐구·퀴즈로 능동 학습.

### ④ 평생 상식 (Lifelong Keeper) — "어른이 돼도 기억할 것"
- 각 단원에 **"이건 평생 기억해두면 좋다" 1~3개**를 `📌` 배지로 **명시적으로** 표시한다.
- 시험용 디테일과 평생 상식을 **구분**하고, 후자를 강조. (시험 끝나면 잊어도 되는 것 vs 평생 갈 것)

### ⑤ 인사이트 (Insight) — 개념을 잇는 큰 그림
- 단원 간·개념 간 **연결**을 `💡`로 짚는다. (예: 주기율표 → 화학결합 → 물질의 성질 → 신소재)
- "그래서 세상이 이렇게 돌아간다"는 **관점**을 준다. 조각 지식이 아니라 지도를.

### ⑥ 실생활 (Real Life) — 내 주변에서
- 개념이 나타나는 **일상 사례**를 `🏠`로. (소금·물·배터리·전자레인지·풍선·형광등…)
- "교실 밖에서 이미 매일 보고 있었다"는 걸 깨닫게.

### ⑦ 산업·직업 이야기 (Industry & Career) — "이걸로 먹고사는 사람들"
- 관련 **산업·기술·제품**을 `🏭`로. (반도체·배터리·신소재·우주·바이오…)
- **대학 전공·직업**으로 연결 `🎓`. (재료공학·화학공학·데이터사이언스…) — perf3_motion의 `know_*` 서브페이지 패턴 계승.
- 진로 탐색(2605)과도 연결되는 씨앗.

### ⑧ 정확성 (Accuracy) — 틀린 단순화 금지
- 단순화해도 **틀린 말은 금지**. 예외·심화는 반드시 표시. (예: "옥텟 — 단 수소는 듀엣")
- 교과서 캡쳐 없으면 **표준 커리큘럼 기준** 제작 + 명시. 받으면 실전 용어·수치로 보정.
- **공개 전 `se-agent-app-reviewer` 게이트** 필수(개념 정확성 + 이 체크리스트).

## 2. 단원 앱 필수 콘텐츠 블록 (시그니처 — 매 단원 반복해 학습 언어를 통일)

| 블록 | 배지 | CSS 클래스 | 내용 |
|---|---|---|---|
| 도입 훅 | 💥 | `.hook` | 놀라운 사실/질문으로 "왜 배우나" |
| 과학자·역사 이야기 | 🔬 | `.sci` | 인물 일화, 발견 스토리 |
| 개념 상호작용 | — | Canvas/SVG/PhET | 직접 조작하며 직관 형성 |

| 인사이트 | 💡 | `.insight` | 개념 간 연결·큰 그림 |

## 3. 표준 탭 골격 (주제에 맞게 가감)

```
📋 개요        — 💥훅 + 이 단원 큰 그림 + 목차(카드)
🌍 개념탭 ×N   — 핵심 개념별 1탭. 상호작용(애니/시뮬/PhET) + 단위/비유 + 🔬과학자
🧪 PhET 랩     — 관련 PhET 임베드 + 사용가이드 + 관찰미션 3개 (있을 때)
🌐 세상 속으로  — 📌평생기억 + 💡인사이트 + 🏠실생활 + 🏭산업·🎓전공
🔥 퀴즈        — 능동 회상, 즉시 피드백, 점진 공개
✅ 정리        — 비교표 + 자가체크 + 약점태그 + ➡️다음단원 링크(순환)
```

## 4. 기술 규약 (요약 — 상세는 짝 문서)
- Canvas: DPR 스케일(너비·높이 둘 다) + lazy init(탭 노출 후) + resize 재init. (`se-perf-study-app` `setupCanvas` 스니펫)
- PhET: `…_all.html?locale=ko` iframe(aspect 834/504) + 새 탭 fallback + 탭 첫 노출 시 lazy 주입.
- 모바일: viewport, 터치타겟 **44px 이상**, 고정 px 금지, 반응형.
- KaTeX 쓰면 `$…$` 안 한글 금지. (수식 적은 앱은 `<sup>/<sub>`로 대체 권장.)
- 배포: 파일 prefix `sci1_`/`mat1_` 등, 두 리포 push, breadcrumb.
