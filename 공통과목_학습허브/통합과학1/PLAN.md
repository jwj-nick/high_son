## 4. 단원 앱 표준 구조 (perf3_motion + PhET 결합)

```
📋 개요       — 이 단원 큰 그림 + "왜 배우나" hook + 목차
🌍 개념탭 ×N  — 핵심 개념별 1탭. Canvas/SVG 애니 or PhET iframe + 단위/비유/과학자
🧪 PhET 랩    — 관련 PhET 임베드 + [무엇을·어떻게] 우리 해설 가이드 + 관찰 미션
🔥 퀴즈/몸풀기 — 개념확인 (즉시 정답 토글, 점진 공개)
✅ 정리       — 핵심 요약 + 자가 체크리스트 + 다음 단원 연결
```

### PhET 임베드 컴포넌트 규약
- iframe: `src="…_all.html?locale=ko"`, `aspect-ratio:834/504`, `width:100%`, `loading="lazy"`, `allowfullscreen`.
- **항상 fallback**: iframe 위/아래에 `PhET에서 직접 열기 ↗`(새 탭) 버튼 — X-Frame 차단·모바일 대비.
- iframe **위에 "무엇을 배우나 / 어떻게 조작하나 / 관찰 미션 3개"** 우리 해설 (한국 교과서 용어).
- 성능: iframe은 해당 탭이 처음 보일 때 `data-src`→`src` lazy 주입(초기 로드 부담↓).
