## 2. 고난도 문항 유형 (사회과 킬러 패턴)
| 유형 | 설명 | 예 |
|---|---|---|
| 📜 자료 해석 | 사료·지도·통계·그래프·풍자화를 읽고 판단 | "다음 상소문의 밑줄 친 인물의 활동은?" |

| 🔢 순서 배열 | 사건을 시간순 정렬(연대 감각) | 갑신정변·동학·을미사변·을사늑약 순서 |

## 3. 설계 (권장안 + 근거)

**권장: 과목별 "고난도 문제은행" 앱 1개씩 = 4개 신규 앱.**

- 각 앱: **단원별 탭 or 필터** + 문항 리스트. 한 문항 = 발문 + (자료) + 4~5지선다/순서배열 → 즉시 채점 → **단계별 풀이 토글**(정답근거→오답분석→함정→관련 개념앱 링크).
- 근거: ①기존 20앱 안 건드림(회귀 위험 0) ②과목 단위라 관리·배포 단순 ③단원 학습앱↔고난도앱 크로스링크로 "개념→심화" 동선.
- **대안**: 기존 각 단원앱에 `🔥🔥 고난도` 탭 추가(16앱 수정) — 통합적이나 회귀·작업량 큼. 권장 안 함.

## 4. 문항 데이터 스키마 (JS 배열, 각 앱 인라인)
```js
{
  unit: 'Ⅲ 조선',            // 단원 태그(필터용)
  type: '자료해석',           // §2 유형
  level: '상',                // 중상/상/최상
  stem: '다음 자료와 관련된 …', // 발문(textContent)
  material: '<blockquote>…</blockquote>', // (선택) 사료/표/SVG (innerHTML — <문자 주의)
  o: ['보기1','보기2','보기3','보기4'],
  a: 0,                       // 정답 index (엔진이 셔플 후 indexOf로 재추적)
  solve: {                    // 단계별 풀이
    key: '정답이 맞는 근거…',
    why: ['①오답 이유','②오답 이유','③오답 이유'],
    trap: '흔히 빠지는 함정…',
    link: 'kh1_joseon.html#…' // 개념 복습 링크(선택)
  }
}
```
- **순서 배열형**은 별도 렌더(보기 클릭→순서 지정→채점). 엔진 확장 필요.
- 퀴즈 엔진은 기존 단원앱의 Fisher-Yates 셔플 + `q.a=q.o.indexOf(correct)` 패턴 재사용하되, 해설을 `solve` 구조로 확장.
