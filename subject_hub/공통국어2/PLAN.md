## 국어 과목만의 규율 ⭐ (다른 과목과 다른 점)

1. **지문이 정본이다.** 개념 요약이 아니라 **원문↔현대어 행별 대역**이 콘텐츠의 중심. 시어 하나하나에 해설이 붙는다.
   - ⭐ **시가는 원문 전문을 싣는다(발췌 금지)** + 행별 상세 해석 (Nick 지시 2026-08-19).
   - ⭐ **소설·산문은 지문을 여러 개 넉넉히** 싣고 헷갈리는 구절마다 해설을 달며, **각 지문 바로 뒤에 그 지문으로 푸는 연계 문제**를 붙인다 — 실제 시험의 "지문→문항" 구조 그대로.
2. **해석은 교과서 통설 기준, 보수적으로.** 제망매가는 해독(양주동/김완진)이 갈리고, 고전 현대어역은 교재마다 다르다. 앱은 **널리 통용되는 현대어역**을 싣되, 앱 안에 "시험은 교과서 표기·해석이 기준"이라는 콜아웃을 반드시 둔다. 교과서 실물 확인 후 보정한다.
3. **옛한글 표기 정책**: 아래아(ㆍ)·반치음(ㅿ) 등 옛한글 조합 글자는 폰트 깨짐 위험이 있어 **원문 인용은 통용(근대화) 표기**로 싣고, 옛 글자 자체는 호환 자모(ㆍ, ㅿ, ㅸ) 단독으로 설명 박스에서만 다룬다. 이 사실을 앱에 명시한다.
4. **저작권**: 제망매가·속미인곡·춘향전 원문은 퍼블릭 도메인. 현대어 풀이는 자체 작성(교과서·참고서 풀이 전재 금지).
5. **공개 전 게이트 필수**: `se-agent-app-reviewer`로 고전 해석·문학사 사실 검증 후 배포.

- 단일 HTML · 바닐라 JS · 빌드 없음 · KaTeX 불필요. 모바일 우선.
