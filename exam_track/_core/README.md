# _core — 학기 중립 자산

> **학기 폴더는 소모품, 여기는 자산이다.** 학기가 끝나면 `26_High_1-1/` 같은 폴더는 아카이브되지만, 여기 쌓인 taxonomy와 약점 DB는 고등학교 3년 내내 자란다.
> 상위 계약: [`../CLAUDE.md`](../CLAUDE.md) · 설계 근거: [`../../00_META/LEARNING_DESIGN.md`](../../00_META/LEARNING_DESIGN.md)

## 구성

| 폴더 | 내용 | 왜 필요한가 |
|---|---|---|
| [`taxonomy/`](taxonomy/) | 과목별 **오답 유형 분류체계** | 오답노트의 가치는 해설이 아니라 "내가 왜 틀리는지의 패턴화"에 있다. 분류가 없으면 산출물이 학원 해설지 재생산이 된다. |
| [`weakness_db/`](weakness_db/) | **약점 태그 누적 DB** (JSON, git 추적) | 지금까지 오답노트는 문항 단위로 만들고 끝났다 — 약점이 누적되지 않았다. |
| [`retest/`](retest/) | **재출제 스케줄러** 규칙 + 산출물 | 시간이 지나 다시 물어보지 않으면 인출·간격반복이 일어나지 않는다. |

## 파이프라인에서의 위치

```
① 입력            ② 오답 처리                    ③ 누적·재출제  ← _core/
시험지 캡쳐   →   오답노트 + 풀이앱 + 연습문제  →  약점 DB → "오늘의 재시험"
02_text 정본      + 약점 태그 부여                  (누적·불변)   (간격반복)
```

②가 태그를 **부여**하고, ③이 태그를 **누적·소환**한다. 태그가 없는 오답노트는 이 루프에 들어오지 못한다.

## 규약

- 모든 산출물은 **JSON 또는 Markdown + git 추적**. 별도 DB 서버 없음.
- 스키마를 바꿀 땐 같은 커밋에 **마이그레이션 노트**를 남긴다.
- 과목 코드: `수학` `과학` `국어` `영어` `한국사` (약점 태그는 `과목:단원` 형식 — 예 `수학:이차함수`)
