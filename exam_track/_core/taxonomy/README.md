# 오답 taxonomy — 왜 틀렸는지의 분류체계

> 정본 데이터: [`causes.json`](causes.json) · 상위 계약: [`../../CLAUDE.md`](../../CLAUDE.md)
> 작성: 2026-07-26 (S2)

---

## 1. 왜 필요한가

기존 약점 태그는 `수학:이차함수` 하나였다. 이건 **무엇을** 공부할지는 알려주지만 **왜 틀렸는지**는 알려주지 않는다. 그런데 처치는 원인마다 완전히 다르다:

| 같은 "수학:이차함수" 오답 | 필요한 처치 |
|---|---|
| 정의역 조건을 놓쳤다 | 발문 표시 습관 (개념 재학습 불필요) |
| 부호를 틀렸다 | 검산 루틴 (개념 재학습 불필요) |
| 개념 자체를 모른다 | 학습부터 |
| 그래프를 잘못 읽었다 | 자료 해석 훈련 |

원인을 기록하지 않으면 네 경우에 **똑같이 "이차함수 다시 공부"**를 처방하게 된다. 그게 학원 해설지와 같아지는 지점이다.

## 2. 3축 태깅

```
오답 1건 = 내용(topic) × 원인(cause) × 확신도(confidence)
           수학:이차함수  C1-문제해석    확신
```

| 축 | 값 | 답하는 질문 |
|---|---|---|
| **내용** `topic` | `과목:단원` (기존 유지) | 무엇을 공부할까 |
| **원인** `cause` | C1~C8 (+과목별 세분) | 어떻게 고칠까 |
| **확신도** `confidence` | 확신 / 반신반의 / 찍음 / 시간부족 | 얼마나 급한가 |

### 확신도가 왜 별도 축인가

아이가 **답을 고를 때 얼마나 확신했는지**는 오답의 성격을 완전히 바꾼다. 수집 비용은 클릭 한 번인데 정보량이 크다:

- **확신하고 틀림 = 오개념.** 가장 위험하다. 스스로 안다고 믿으므로 다시 공부하지 않는다. → 최우선, 짧은 간격
- **반신반의 = 구별 실패.** 지식은 있고 경계가 흐리다. → 구별 훈련
- **찍음 = 지식 부재.** 학습 먼저, 그 다음 재출제. (**맞았어도 기록한다** — 찍어서 맞은 건 모르는 것이다)
- **시간부족 = 전략 문제.** 개별 재출제보다 실전 타이머가 먼저

## 3. 원인 코드 (C1~C8)

| 코드 | 이름 | 한 줄 | 처치의 방향 |
|---|---|---|---|
| **C1** | 문제해석 | 발문·조건을 놓침 | 습관 (개념 재학습 불필요) |
| **C2** | 지식부재 | 아예 모름 | 학습 먼저 |
| **C3** | 지식혼동 | 비슷한 걸 구별 못 함 | **쌍으로** 구별 훈련 |
| **C4** | 적용실패 | 알지만 이 상황에 못 씀 | 변형문제 |
| **C5** | 실행오류 | 계산·표기 실수 | 검산 루틴 |
| **C6** | 시간전략 | 실력이 아닌 배분 문제 | 실전 타이머 |
| **C7** | 자료해석 | 표·그래프·사료·지문에서 못 뽑음 | 근거 지목 훈련 |
| **C8** | 순서·연대 | 시간 순서 감각 부재 | 연표에 배열해보기 |

세부 신호(signals)와 과목별 세분은 `causes.json` 참조.

## 4. 과목별 지배 원인 — 일반화가 복제가 아닌 이유

| 과목 | 주로 나오는 원인 | 그래서 |
|---|---|---|
| 수학 | C5, C1, C4 | 다시 풀면 검증된다 |
| 과학 | C3, C5, C7 | 개념 오해와 계산을 **분리 진단**해야 처치가 갈린다 |
| 한국사 | C3, C7, C8, C1 | 다시 풀기보다 **구별 훈련**이 약. 부정형 함정·연대 감각 |
| 사회 | C3, C7, C4 | 관점 구별과 사례 적용 |
| 국어 | C7, C1, C3 | 지문 의존 → **근거 문장을 반드시 함께 기록** (`evidence_sentence`) |
| 영어 | C2, C3, C7, C4 | 어휘 부재와 구문 오해를 구별 (`unknown_words`) |

수학 스킬을 그대로 복사하면 안 되는 이유가 여기 있다. **입력받아야 할 필드부터 다르다.**

## 5. 태그 부여 규칙

1. **원인은 1~2개.** 3개를 넘기면 진단이 아니라 나열이다. 가장 결정적인 것 하나를 `primary`로.
2. **확신도는 아이가 답한다.** Claude가 추측하지 않는다. 값이 없으면 `unknown`으로 두고, 재출제 우선순위는 중간으로.
3. **찍어서 맞은 문제도 기록한다.** 정답률은 실력을 과대평가한다.
4. **C3(혼동)은 반드시 혼동한 상대를 함께 적는다** (`confused_with`). 쌍이 없으면 구별 훈련을 만들 수 없다.
5. **C5가 3회 이상 반복되면 '실수'가 아니다.** 습관으로 승격해 별도 체크리스트로 관리한다.
6. **과목을 가로지르는 원인은 신호다.** C1·C3·C7이 여러 과목에서 동시에 뜨면 그건 과목 문제가 아니라 **읽기·구별 습관 문제**다. 이건 단일 과목 오답노트로는 절대 안 보이는 것이고, 이 DB를 만드는 가장 큰 이유다.

## 6. 버전 관리

`causes.json`의 코드(C1~C8)는 **함부로 바꾸지 않는다** — 누적 데이터가 이 코드를 참조한다. 추가는 자유(C9~), 삭제·의미 변경은 마이그레이션 노트 필수.
