## 0. 왜 흥미 갈래에 있으면 안 되는가

흥미 갈래의 금지사항 1번은 **"시험·점수 이야기를 넣지 않는다"** 이다. 고난도 문제은행은 정의상 시험 대비다. 같은 폴더에 두면 두 갈래의 목적함수가 섞이고, 개념 학습 앱이 문제집처럼 읽히기 시작한다.

옮기면서 성격도 바뀐다. **독립된 문제 세트가 아니라, 약점 DB에 연결된 인출 도구다.**

## 1. 목표

시험 범위에 대해 **자료해석·복합개념·순서·사례적용·함정** 수준의 문항을 준비해 두고, 틀린 것이 **자동으로 약점 DB에 들어가 재출제 대상이 되게** 한다.

기존 단원 학습앱의 퀴즈10은 기초·중급(이해 확인)이다. 이건 그 위 계층이다.

## 2. 문항 유형

| 유형 | 설명 | 잘 나오는 원인 코드 |
|---|---|---|
| 📜 자료 해석 | 사료·지도·통계·그래프를 읽고 판단 | C7 |
| 🔗 복합 개념 | 두세 단원을 엮어야 풀림 | C4 |
| 🔢 순서 배열 | 사건을 시간순 정렬 | C8 |
| 🧩 사례 적용 | 개념을 새 사례에 적용 | C4 |
| ⚖️ 비교·판단 | 관점·입장 구별 | C3 |
| ❌ 함정(부정형) | "옳지 않은 것", 흔한 오개념 저격 | C1 |

유형과 원인 코드를 미리 대응시켜 두는 이유: **틀렸을 때 원인 진단이 반쯤 자동으로 된다.** 함정형을 틀리면 C1, 비교형을 틀리면 C3가 1순위 후보다.

## 4. 약점 DB 연결 ⭐ (이관하면서 새로 생긴 부분)

문제은행에서 틀린 문항도 **시험 오답과 같은 DB에 들어간다.** 출처만 구분한다.

```jsonc
"exam": { "id": "bank-한국사-2026-2-mid", "date": "<푼 날짜>", "subject": "한국사", "scope": "고난도 문제은행" },
"source_type": "bank"        // "exam" | "bank"
```

- 시험 오답과 **같은 재출제 사다리**를 탄다(1·3·7·16·35일).
- 통계에서는 `source_type`으로 분리해 볼 수 있다 — "시험에선 맞는데 문제은행에선 틀린다"는 그 자체로 신호다.
- 확신도는 푸는 즉시 앱에서 받는다(시험지와 달리 여기선 마찰이 거의 없다).

## 5. 형태

**과목별 문제은행 앱 1개** — 기존 앱 규약 그대로(단일 HTML·바닐라·빌드 없음).
[`../app/retest.html`](../app/retest.html)과 같은 구조를 쓴다: 문제 → 확신도 → 채점 → **결과 복사 → 채팅으로 DB 반영**.

배포는 **Tier 2(Vercel, 비공개)**. 공개 Pages에 올리지 않는다 — 정답이 붙은 문제은행이고, 아이의 풀이 이력이 붙기 때문이다.

## 6. ⚠️ 제작 착수 조건 — 지금 만들면 낭비다

**2학기 중간고사 범위가 나와야 시작한다.**

원래 계획은 1학기/표준 커리큘럼 기준 16단원 × 5문항 = 80문항이었다. 그런데 9월 초 시험의 범위는 다르다. 범위 밖 문항을 80개 만들면 **시험 대비가 아니라 교양이 되고, 그건 흥미 갈래의 일이다.**

| 조건 | 상태 |
|---|---|
| 2학기 중간 범위 (과목별 단원) | ⬜ **대기 — Nick** |
| 교과서·프린트·기출 확보 | ⬜ 있으면 실전 반영, 없으면 표준안 |
| 약점 DB 실데이터 | 🟨 수학 9건. 범위 단원과 겹치는 약점이 우선 |

범위가 나오면 **약점 DB와 교차**해서 문항을 배분한다 — 이미 틀린 단원에 문항을 더 준다. 백지에서 80문항을 만드는 것보다 효율적이고, 새 시스템이 있으니 가능해진 일이다.

## 7. 제작 순서 (범위 확보 후)

1. 범위 단원 목록 → `_core/taxonomy/topics.json` canonical에 매핑
2. 약점 DB 교차 → 단원별 문항 수 배분 (약점 있는 단원 가중)
3. 과목 1개로 파일럿 → 검증 → 나머지 확산
4. 검증: `node --check` · `<한글` 잘림 · `se-agent-app-reviewer`로 **정답키·오답분석까지** 검수
   (고난도는 정답 논쟁 위험이 크다 — 해설만 보지 말고 오답 근거를 검수한다)
5. Tier 2 배포
