## 2. 2022 개정 교육과정 범위 — 문항에 넣지 않는 것

아들(2025 입학)부터 적용. 학원 교재에 남아 있어도 학교 시험 범위가 아닐 수 있다. **"교과서 확인"은 아들 교과서를 확보하면 대조할 항목.**

| 단원 | 범위 안 | 범위 밖(넣지 않는다) | 교과서 확인 |

| 평면좌표·직선 | 두 점 거리 · **내분** · 직선의 방정식 · 평행·수직 · 점과 직선 거리 | **외분점** | 무게중심(교과서마다 갈림) |
| 원 | 원의 방정식 · 원과 직선의 위치 관계(접선·현) | **두 원의 위치 관계·공통현** | 아폴로니우스 원(자취 예제로 흔함) |
| 도형의 이동 | 평행이동 · 대칭이동(x축·y축·원점·**y=x**) | **y=−x 대칭**(규칙으로) · 점·직선에 대한 일반 대칭은 응용으로만 | 직선에 대한 대칭점(응용 예제) |
| 집합 | 집합·원소·부분집합 · 연산·드모르간 · 원소의 개수 | — | 대칭차집합 |
| 명제 | 명제·조건·진리집합 · 역·대우 · 필요·충분조건 · 증명(대우·귀류법) · 절대부등식 | — | 산술·기하평균 부등식의 범위 |
| 함수 | 함수·합성함수·역함수 · 그래프 | — | 역함수 그래프와 y=x 교점 |

## 3. 세트 설계 규격 (점검 티어)

- 12문항 · 중상 3~4 · 상 6~8 · 최상 2. 유형: 유형판별(material 필수) · 조건함정 · 계산 · 복합. 그래프해석은 실제 그래프·표 material이 있을 때만.
- 4지선다. 오답 3개는 서로 다른 원인, 각 오답 값은 why의 실수 경로로 **실제 도달**해야 한다(치명 기준). 정답 보기에 cause·why 없음.
- 검산 파일 `verify/<set>.js` 12/12 통과 후에만 게이트.
- 화면 문구: 시험·점수·등수 금지(내신 갈래여도 앱 화면은 흥미 갈래 앱 안에 있다). 목차 카드 문구 "점검 12문제".

## 4. 원인 코드 규칙 — 20차 게이트에서 굳은 것

| 코드 | 수학에서 쓰는 경우 | 쓰지 않는 경우 |
|---|---|---|
| C4 적용실패 | **material이 있고**, 어떤 도구(자취·거리 vs 판별식·대칭점)를 꺼낼지 판별 실패 | 도구는 맞게 골랐는데 공식을 잘못 쓴 것(→C2) · 식을 잘못 읽은 것(→C3) |
| C1 문제해석 | 구할 것과 다른 값(중간값·차 대신 합) · 조건 하나 누락 · 끝점 포함 · 비의 순서 · 이동 순서 | — |
| C5 실행오류 | 부호·산술·이항·옮겨 적기가 **실제로 틀린** 경우 | 산술은 맞고 정의를 오해(→C2) · 문항마다 1개씩 채움 |
| C3 지식혼동 | 혼동 쌍이 실재: 내분↔중점, 평행↔수직, x축↔y축↔원점, r↔r², (A∪B)ᶜ↔(A∩B)ᶜ, ∈↔⊂ | 쌍을 못 대면 C3 아님 · "식↔정답"은 쌍이 아님 |
| C2 지식부재 | 공식·규칙 자체를 모름(√ 누락, 2ⁿ 모름, 분모 m+n 모름) | 배운 적 없는 규칙(y=−x)을 오답 경로로 지목 |

- 같은 오류는 세트 안·세트 간에 같은 코드. 수학은 C3가 자연히 많아지므로 **C4가 정당하게 성립하는 material 문항을 세트마다 2개 이상** 설계해 균형을 잡는다.
- "앱에 근거 없음"은 문항이 아니라 앱을 채운다 → `add_app_box.js`. 20차에서 4앱에 박스 9개.
