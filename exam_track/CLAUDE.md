## 4. 3대 컴포넌트 (파이프라인)

```
① 입력            ② 오답 처리                ③ 누적·재출제
시험지 캡쳐   →   오답노트 + 풀이앱      →   약점 태그 DB  →  "오늘의 재시험"
02_text 정본      + 연습문제 (3×3)            (누적·불변)      (간격반복)
                  + 약점 태그 부여
   ✅ 5과목 검증      🟡 수학만 구현             ❌ 미구현
```

**③이 이 갈래의 가장 큰 구멍이다.** 지금까지 오답노트는 문항 단위로 만들고 끝났다 — 약점이 누적되지 않고, 시간이 지나 다시 물어보지 않는다. 학습과학이 가장 확실하게 지지하는 두 가지(**인출연습·간격반복**)를 시스템이 안 쓰고 있다는 뜻이다.

## 6. 과목 일반화는 복제가 아니다 ⭐

오답의 **성질**이 과목마다 다르므로, 수학 스킬을 그대로 복사하면 실패한다.

| 과목 | 오답의 성질 | 필요한 처치 |
|---|---|---|
| 수학 | 절차·계산·조건 누락 | 다시 풀어 검증 |
| 과학 | 개념 오해 + 계산 + 자료해석 혼재 | 개념/계산 분리 진단 |
| 사회·한국사 | 개념·용어 혼동, 자료해석 실패, 함정(부정형), 연대 감각 | **구별 훈련**(다시 풀기보다) |
| 국어 | 근거 문장 찾기 실패 (지문 의존) | 노트 형태 자체가 다름 |
| 영어 | 어휘·구문·추론 | 유형별 분리 |

→ **과목별 taxonomy를 먼저 정의한 뒤 스킬을 확장한다.** 이것이 없으면 산출물이 학원 해설지 재생산이 되고, 우리가 그들보다 나을 이유가 사라진다.
**오답노트의 가치는 해설이 아니라 "내가 왜 틀리는지의 패턴화"에 있다.**

## 7. 금지사항 (위반 = 이 갈래의 실패)

1. **해설지 재생산 금지.** 정답과 풀이만 있는 산출물은 만들지 않는다. "왜 틀렸나"와 약점 태그가 없으면 미완성이다.
2. **약점 태그 없는 오답노트 금지.** 태그가 없으면 DB에 안 들어가고, DB에 없으면 재출제되지 않는다 — 즉 학습 루프가 끊긴다.
3. **원본 캡쳐(01_capture) 수정·삭제 금지.**
4. **추측·창작 금지.** 안 보이면 `⚠️OCR?` + `issue.md` 기록. 정답 확신이 없으면 Nick에게 확인.
5. **아이를 깎는 표현 금지.** 오답은 데이터지 실패가 아니다. 흥미 갈래로 시험 압박을 전이시키지 않는다(연결은 단방향, 개념 링크만).
