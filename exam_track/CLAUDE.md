## 4. 파이프라인 (2026-07-28 재정의)

**입력이 바뀌었다.** 학교 시험지 채점 결과가 아니라 **Claude가 단원별로 출제한 문항**이 입력이다.

```
① 출제                ② 풀이·자동채점        ③ 오답 기록          ④ 재출제
단원별 문항 세트  →   아이가 앱에서 풀이  →  약점 DB(3축 태그) →  "오늘의 재시험"
+ 보기별 원인 매핑     + 확신도 즉시 수집      원인 자동 진단        (간격반복)
```

### 왜 바꿨나 (Nick 지시 2026-07-28)

> "1학기 채점 결과 입력 계획은 없습니다. 앞으로는 당신이 낸 문제를 아이가 풀고 오답에 대해서 발전시켜 나가면 됩니다."

이전 설계는 입력이 **학교 시험지 채점 결과**였는데, 5과목 `todo.md`에 `채점 결과 입력 ⏳ 대기`가 **2026-04-26부터 3개월째** 걸려 있었다. 텍스트화는 끝났는데 정오 정보가 없어 파이프라인 전체가 멈춰 있었다. 입력을 자작 문항으로 바꾸면 이 병목이 **구조적으로 사라진다.**

### 자작 문항이라서 가능해지는 것 ⭐

| | 학교 시험지 | 자작 문항 |
|---|---|---|
| 채점 | 사람이 입력해야 함 (병목) | **앱이 자동** |
| 확신도 | 시험장 습관 필요 | **푸는 즉시 수집** |
| 원인 진단 | 오답노트 읽고 사람이 추정 | **보기별 원인 매핑으로 자동** |
| 범위 | 시험 범위에 종속 | **단원별로 전량 커버** |

**보기별 원인 매핑**이 핵심이다. 문항을 만들 때 각 오답 보기에 원인 코드를 붙여둔다 — ②를 고르면 C1(조건 누락), ③을 고르면 C3(시기 혼동), ④를 고르면 C7(사료 오독). 그러면 **틀렸다는 사실만이 아니라 "어떻게 틀렸는지"가 자동으로 진단된다.** 3축 태깅의 원인 축이 처음으로 자동으로 채워진다.

## 6. 과목 일반화는 복제가 아니다 ⭐

오답의 **성질**이 과목마다 다르므로, 수학 스킬을 그대로 복사하면 실패한다.

| 과목 | 오답의 성질 | 필요한 처치 |
|---|---|---|
| 수학 | 절차·계산·조건 누락 | 다시 풀어 검증 |
| 과학 | 개념 오해 + 계산 + 자료해석 혼재 | 개념/계산 분리 진단 |
| 사회·한국사 | 개념·용어 혼동, 자료해석 실패, 함정(부정형), 연대 감각 | **구별 훈련**(다시 풀기보다) |
| 국어 | 근거 문장 찾기 실패 (지문 의존) | 노트 형태 자체가 다름 |
| 영어 | 어휘·구문·추론 | 유형별 분리 |

→ **과목별 taxonomy를 먼저 정의한 뒤 스킬을 확장한다.** 이것이 없으면 산출물이 학원 해설지 재생산이 되고, 우리가 그들보다 나을 이유가 사라진다.
**오답노트의 가치는 해설이 아니라 "내가 왜 틀리는지의 패턴화"에 있다.**

## 7. 금지사항 (위반 = 이 갈래의 실패)

1. **해설지 재생산 금지.** 정답과 풀이만 있는 산출물은 만들지 않는다. "왜 틀렸나"와 약점 태그가 없으면 미완성이다.
2. **약점 태그 없는 오답노트 금지.** 태그가 없으면 DB에 안 들어가고, DB에 없으면 재출제되지 않는다 — 즉 학습 루프가 끊긴다.
3. **원본 캡쳐(01_capture) 수정·삭제 금지.**
4. **추측·창작 금지.** 안 보이면 `⚠️OCR?` + `issue.md` 기록. 정답 확신이 없으면 Nick에게 확인.
5. **아이를 깎는 표현 금지.** 오답은 데이터지 실패가 아니다. 흥미 갈래로 시험 압박을 전이시키지 않는다(연결은 단방향, 개념 링크만).
