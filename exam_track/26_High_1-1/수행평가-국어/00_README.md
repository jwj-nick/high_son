### 👨 Nick이 할 일
1. **`08_옵션뱅크.md`** 통독 — 각 자리에 어떤 후보가 있는지 파악
2. 아들이 책 정독 후 → 빈칸 후보 + 옵션뱅크에서 선택한 1순위 알려주기

1. **검토 요청 시** → `09` §3 프로토콜대로 점수표 + 약점 리포트 (`09` §4 양식)
2. **수정 요청 시** → `08` 옵션뱅크에서 대안 제시
3. **새 산출물 요청 시** → 발표 스크립트 / 인포그래픽 SVG 등 추가 작성
