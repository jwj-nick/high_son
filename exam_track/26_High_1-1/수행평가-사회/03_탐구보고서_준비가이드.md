## 2. 탐구 유형 선택 전략

### 권장: **관련 기사 탐구** 선택

드라마/영화를 선택한 경우 → 관련 기사 탐구가 가장 자연스러운 연결.

**방법:**
1. 드라마/영화의 핵심 장면/주제 → 관련 키워드 추출
2. 해당 키워드로 뉴스 기사 검색 (네이버·다음 뉴스, 구글 뉴스)
3. 기사 2~3개 선정, 출처·날짜 기록
4. 기사 내용에서 실제 통계나 사례 인용

**예시 (나의 해방일지 선택 시):**
```
키워드: 수도권 통근, 1인 가구, 공동체 해체, 직주 분리, 경기도 아파트
→ 기사 예: "1인 가구 10년 새 OO% 증가", "수도권 출퇴근 평균 OO분"
→ 통계 출처: 통계청, 국토교통부
```

## 3. STEP별 준비 가이드 (채점기준 대응)

### STEP 1 — 탐구 주제 선정 (사전 준비 필수)

**채점 핵심:** 주제가 V단원 개념과 명확히 연결되는가 + 선택 이유가 구체적인가

**작성 전략:**
- 주제는 "현상 + V단원 개념어" 조합으로 구성
- 나쁜 예: "나의 해방일지를 탐구하겠다"
- 좋은 예: "드라마 '나의 해방일지'에 나타난 수도권 집중과 직주 분리 현상"

**선택 이유 작성 포인트:**
```
① 드라마에서 어떤 장면이 사회 현상을 보여주는지 (구체적 에피소드)
② 이 현상이 V단원의 어떤 개념과 연결되는지
③ 왜 이 주제가 현재 우리 사회에서 중요한지
```

---

### STEP 2 — 탐구 방법 및 자료 수집 계획 (사전 준비)

**채점 핵심:** 탐구 유형 선택이 적절한가 + 수집할 자료 계획이 구체적인가

**자료 수집 계획 예시 (나의 해방일지 + 관련 기사 탐구):**

| 자료 종류 | 수집 방법 | 예상 출처 |
|---|---|---|
| 드라마 장면 분석 | 특정 에피소드 시청 메모 | JTBC/넷플릭스 (에피소드 1, 3, 5 등) |
| 관련 뉴스 기사 | 네이버 뉴스 검색 | 한겨레, 중앙일보, 경향신문 등 |
| 통계 자료 | 통계청 웹사이트 | kosis.kr (1인 가구, 수도권 인구 통계) |

---

### STEP 3 — 자료 수집 및 분석 (사전 수집, 수업 중 정리)

**채점 핵심:** 자료의 신뢰성 + 출처 명시 + 자료 내용이 주제와 연결되는가

**출처 표기 필수 형식:**
```
매체명: OO일보
기사 제목: "2023년 1인 가구 전체의 35.5% 차지"
날짜: 2023.12.13
URL: (있으면 기재)
```

**사전에 준비할 것:**
- 기사 2~3개 출처·날짜·핵심 문장 메모해 두기 (수업 중 기억에만 의존하면 출처 틀릴 수 있음)
- 드라마에서 인용할 장면 에피소드·시간대 메모

---

### STEP 4 — 사회변화 현상 이해 및 분석 (수업 중 핵심 서술)

**채점 핵심:** V단원 개념어를 정확히 사용하여 현상을 분석했는가

**V단원 개념어 반드시 포함 (택 3~4개):**
- 도시화, 도시·촌락 인구 이동
- 직주 분리 (직장과 주거지의 공간적 분리)
- 공동체 해체, 고립화
- 수도권 집중·지역 불균형
- 1인 가구 증가

**분석 구조 예시:**
```
[현상] 드라마에서 주인공 가족은 경기도에 살며 서울로 장거리 통근한다.
[연결] 이는 수도권 집중으로 인한 직주 분리 현상을 보여준다.
[근거] 통계청(2023)에 따르면 수도권 인구 비율은 전체의 OO%로...
[심화] 이러한 현상은 공동체 해체로 이어지는데...
```

---

### STEP 5 — 문제점 파악 및 해결책 제안 (수업 중)

**채점 핵심:** 문제점이 현상과 논리적으로 연결되는가 + 해결책이 실현 가능한가

**문제점 (최소 2가지 이상):**
1. 개인 차원: 긴 통근 시간 → 여가·가족 시간 감소, 삶의 질 저하
2. 사회 차원: 이웃 관계 단절 → 공동체 해체, 사회적 고립 심화
3. 지역 차원: 수도권 집중 → 지방 과소화, 지역 불균형

**해결책:**
1. 제도적: 지역 균형 발전 정책 (혁신도시, 기업 지방 이전 유도)
2. 도시 설계: 주거·일자리 근접 배치 (직주근접 정책)
3. 공동체: 마을 커뮤니티 공간 확충

---

### STEP 6 — 마무리 및 자기평가 (수업 중)

**채점 핵심:** 탐구를 통해 무엇을 배웠는지 진솔하게 서술했는가

**소감 작성 포인트:**
- 탐구 전후 생각의 변화
- 드라마를 보는 새로운 시각 (사회적 시선)
- V단원 개념이 실생활과 연결된다는 점

## 4. AI 활용 주의사항

### 수업 중 실시 → AI 직접 활용 불가

이 과제는 **수업 시간 내에 답안지에 직접 작성**하는 형식. 시험 현장에서 AI 사용 불가.

### 사전 준비 단계에서 AI 활용 가능한 것

| 활용 가능 | 활용 불가 |
|---|---|
| 탐구 주제 아이디어 토론 | 답안지에 쓸 문장 그대로 생성 |
| V단원 개념어 이해 확인 | 기사 요약을 AI가 작성 |
| 드라마 선택 기준 논의 | 분석 결과를 AI가 대신 서술 |
| 자료 검색 키워드 추천 | 결론·소감을 AI가 대신 작성 |
| STEP별 구조 이해 | 실제 제출 답안 작성 |

### 실제 작성 시 지켜야 할 원칙

1. **자료 출처는 직접 찾은 것만** — AI가 제공한 통계를 출처 없이 인용하지 말 것 (사실 확인 불가, 오류 위험)
2. **분석 문장은 자신의 언어로** — AI 문장을 그대로 옮기면 문체 이질감으로 적발 가능
3. **드라마 장면 인용은 직접 시청 후** — AI가 요약한 드라마 내용을 인용하면 부정확할 수 있음
