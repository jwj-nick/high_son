# 이 앱이 만들어진 과정 — Claude Code 실전 예시

> 아빠(Nick)와 Claude Code가 대화로 주고받으며 수학 수행평가 학습 앱을 완성한 실제 기록.
> 아이에게 "AI에게 일을 맡기는 법"을 보여주기 위한 문서. (앱의 🎬 제작과정 탭과 동일 내용)

## Claude Code란?
터미널에서 **대화만으로** 파일을 읽고·만들고·고치고, 그림(시험지 사진)도 직접 보고, GitHub에 배포까지 하는 AI 코딩 도구. 이 앱의 모든 글·코드·그림 정리가 대화로 만들어졌다.

## 협업 방식
사람 말은 `(Nick)`, AI 답은 `(Claude)` 접두어로 **.md 파일에 차곡차곡** 누적 — 채팅과 파일을 함께 쓰는 "파일 기반 비동기 소통".

- **✦ 포인트:** 사람이 진행 "방식"을 교정하면 AI는 바로 반영해야 한다. — `e682ba8`

## 🎓 아이에게 — AI를 잘 쓰는 6가지
1. **🎯 구체적으로 시켜라** — "앱 만들어줘"보다 "1~5 정리된 앱을, 사이트 새 카드로".
2. **👀 중간 결과를 확인하라** — 파일이 실제로 생겼는지 보라. 안 보이면 바로 물어라.
3. **🔁 피드백으로 고쳐라** — 마음에 안 들면 즉시 교정 요청.
4. **🗺️ 계획부터 맞춰라** — 큰 작업은 "어떻게 할 건지 먼저 말해봐"로 방향 합의 후 시작.
5. **🔍 AI의 답도 검증하라** — AI가 만든 코드·AI의 검토 의견조차 다시 확인. 틀린 지적은 거른다.
6. **📝 실수는 기록·수정하라** — 커밋 실패·오류도 숨기지 말고 고치고 로그에 남긴다.

> **한 줄 요약:** 구체적으로 시키고 · 중간 결과를 확인하고 · 피드백으로 고치고 · AI의 답도 검증한다.
