## 🟢 Level 1 — 쉬운 문제 (핵심 구조 분리)

### L1-1 [연결개념: 나머지정리 기본]
**[왜 이 문제인가]** Q14에서 $\{P(x)\}^2 = h(x)Q(x)+64$에 $h$의 근을 대입하는 단계를 집중 연습합니다.

**문제**  
최고차항의 계수가 1인 이차다항식 $P(x)$에 대해 $\{P(x)\}^2$을 $x-3$으로 나눈 나머지가 $25$이다.  
$P(3)$의 가능한 값의 합을 구하여라.

**풀이 전략**: 나머지정리로 $P(3)^2=25$ → $P(3)=\pm5$ → 합 계산

**정답**: $0$

<details>
<summary>단계별 힌트</summary>

**힌트 1**: $\{P(x)\}^2=(x-3)Q(x)+25$에 $x=3$을 대입.

**힌트 2**: $\{P(3)\}^2 = 25$ → $P(3)=5$ 또는 $P(3)=-5$.

**힌트 3 (거의 정답)**: 두 값의 합 $= 5+(-5) = 0$

</details>

---

### L1-2 [연결개념: 두 조건으로 P(x) 결정]
**[왜 이 문제인가]** Q14에서 연립방정식으로 $b, c$를 결정하는 과정을 집중 연습합니다.

**문제**  
최고차항의 계수가 1인 이차다항식 $P(x)$에 대해 $P(1)=3$이고 $P(-1)=1$이다. $P(0)$의 값을 구하여라.

**풀이 전략**: $P(x)=x^2+bx+c$로 놓고 연립방정식 → $c=P(0)$

**정답**: $1$

<details>
<summary>단계별 힌트</summary>

**힌트 1**: $P(1)=1+b+c=3$ → $b+c=2$. $P(-1)=1-b+c=1$ → $-b+c=0$.

**힌트 2**: 두 식을 빼면 $2b=2$ → $b=1,\, c=1$.

**힌트 3 (거의 정답)**: $P(x)=x^2+x+1$. $P(0)=c=1$.

</details>

---

### L1-3 [연결개념: 대칭 조건으로 조건 (나) 이해]
**[왜 이 문제인가]** Q14에서 "$P(0)=P(6) \Leftrightarrow b=-6$" 메커니즘을 이해하는 문제입니다.

**문제**  
최고차항의 계수가 1인 이차다항식 $P(x)$에 대해 $P(0)=P(4)$이다. $P(x)$의 대칭축의 $x$좌표를 구하여라.

**풀이 전략**: $P(0)=P(4)$이면 $0$과 $4$의 중점이 대칭축

**정답**: $2$

<details>
<summary>단계별 힌트</summary>

**힌트 1**: $P(x)=x^2+bx+c$. $P(0)=c$, $P(4)=16+4b+c$.

**힌트 2**: $P(0)=P(4)$ → $16+4b=0$ → $b=-4$.

**힌트 3 (거의 정답)**: 대칭축 $x = -\dfrac{b}{2} = -\dfrac{-4}{2} = 2$.

</details>

## 🟡 Level 2 — 비슷한 레벨

### M1 [연결개념: 나머지 역계산]
**[왜 이 문제인가]** P(x)가 주어지면 Q14의 역방향 — 나머지를 직접 계산할 수 있는지 확인합니다.

**문제**  
최고차항의 계수가 1이고 $(x-2)(x+1)$로 나누어 떨어지는 이차다항식 $P(x)$가 있다.  
$\{P(x)\}^2$을 $(x-3)(x+2)$로 나눈 나머지를 구하여라.

**풀이 전략**: $P(x)=(x-2)(x+1)$ 유일 확정 → 나머지정리: $P(3)^2$과 $P(-2)^2$ 확인

**정답**: $16$

<details>
<summary>단계별 힌트</summary>

**힌트 1**: 최고차항의 계수 1인 이차식 중 $(x-2)(x+1)$로 나누어 떨어지는 것은 $P(x)=(x-2)(x+1)$ 하나뿐.

**힌트 2**: $P(3)=(3-2)(3+1)=4$, $P(-2)=(-4)(-1)=4$. $P(3)^2=P(-2)^2=16$.

**힌트 3 (거의 정답)**: 두 근 $x=3,\, x=-2$ 모두 나머지가 $16$으로 일치하므로 나머지 $=16$.

</details>

### M2 [연결개념: Q14 구조 변형]
**[왜 이 문제인가]** 제수와 나머지 숫자만 다르고 Q14와 완전히 같은 사고 흐름입니다.

**문제**  
최고차항의 계수가 1인 이차다항식 $P(x)$가 다음 조건을 만족시킨다.

- **(가)** $\{P(x)\}^2$을 $(x-2)(x-4)$로 나눈 나머지가 $4$이다.
- **(나)** $P(0) \neq P(6)$

모든 $Q(4)$의 값의 합을 구하여라. (단, $Q(x)$는 조건 (가)의 몫이다.)

**풀이 전략**: $P(2)=\pm2,\, P(4)=\pm2$ → 4가지 경우 → (나)로 거른 후 $Q(4)$ 합산

**정답**: $8$

<details>
<summary>단계별 힌트</summary>

**힌트 1**: $P(2)=\pm2,\, P(4)=\pm2$. $P(x)=x^2+bx+c$ 연립으로 4가지 경우 탐색.

**힌트 2**: 대칭($b=-6$)인 경우(①④)는 $P(0)=P(6)$이므로 탈락. 남은 두 경우:  
  - $P(2)=2,\, P(4)=-2$: $P(x)=x^2-8x+14$, $Q(4)=0$  
  - $P(2)=-2,\, P(4)=2$: $P(x)=x^2-4x+2$, $Q(4)=8$

**힌트 3 (거의 정답)**: $Q(4)$는 $\{P(x)\}^2=(x-2)(x-4)Q(x)+4$에 $x=4$ 대입해 구할 수도 있음:
$\{P(4)\}^2 = 0\cdot Q(4)+4$이므로 $Q(4)$ 직접 구하기 불가 (제수의 근에서 $Q$값 불확정). 다항식 나눗셈 필요.

</details>

### M3 [연결개념: 불변량 (Invariant)]
**[왜 이 문제인가]** Q14와 같은 구조에서 $P(3)$은 계수에 무관한 상수입니다. 이 불변량 구조를 이해합니다.

**문제**  
최고차항의 계수가 1인 이차다항식 $P(x)$가 $\{P(x)\}^2=(x-1)(x-5)Q(x)+c^2$을 만족시킨다.  
$P(1)=c$이고 $P(5)=-c$이며 $c>0$일 때, $P(3)$의 값을 구하여라.

**풀이 전략**: $P(x)=x^2+bx+k$로 놓고 연립 → $P(3)$이 $c$에 무관함을 보임

**정답**: $-4$

<details>
<summary>단계별 힌트</summary>

**힌트 1**: $P(1)=1+b+k=c$ → $b+k=c-1$.  
$P(5)=25+5b+k=-c$ → $5b+k=-c-25$.

**힌트 2**: 두 식을 빼면 $4b=-2c-24$ → $b=\dfrac{-c-12}{2}$.  
$k = c-1-b = \dfrac{3c+10}{2}$.

**힌트 3 (거의 정답)**: $P(3)=9+3b+k = 9+\dfrac{3(-c-12)}{2}+\dfrac{3c+10}{2} = 9+\dfrac{-26}{2} = 9-13 = \mathbf{-4}$.  
$c$ 값에 무관! (조건이 $P(1)+P(5)=0$이면 중점값은 항상 같다.)

</details>

## 🔴 Level 3 — 응용 문제

### H1 [연결개념: 나머지 크기 변화]
**[왜 이 문제인가]** Q14는 나머지=64. 나머지를 100으로 바꾸면 숫자가 커지고 검증도 더 필요합니다.

**문제**  
최고차항의 계수가 1인 이차다항식 $P(x)$가 다음 조건을 만족시킨다.

- **(가)** $\{P(x)\}^2$을 $(x-1)(x-5)$로 나눈 나머지가 $100$이다.
- **(나)** $P(0) \neq P(6)$

모든 $Q(4)$의 값의 합을 구하여라.

**풀이 전략**: Q14와 완전히 동일한 절차. $P(1)=\pm10,\, P(5)=\pm10$ → 4가지 탐색

**정답**: $44$

<details>
<summary>단계별 힌트</summary>

**힌트 1**: $P(1)=\pm10$, $P(5)=\pm10$. 대칭 경우($(+10,+10)$, $(-10,-10)$)는 $b=-6$으로 탈락.

**힌트 2**: 남은 두 경우:  
  - $P(1)=10,\, P(5)=-10$: $b=-11,\, c=20$, $P(x)=x^2-11x+20$, $Q(x)=x^2-16x+60$, $Q(4)=12$  
  - $P(1)=-10,\, P(5)=10$: $b=-1,\, c=-10$, $P(x)=x^2-x-10$, $Q(x)=x^2+4x$, $Q(4)=32$

**힌트 3 (거의 정답)**: 합 $= 12+32 = 44$.

</details>

### H2 [연결개념: Q(4) 빠른 계산법]
**[왜 이 문제인가]** Q14의 $Q(4)$를 전체 나눗셈 없이 한 번의 대입으로 구할 수 있습니다. 단, 제수의 근이 아닌 점에서만 가능합니다.

**문제**  
Q14 원문 그대로: $\{P(x)\}^2=(x-1)(x-5)Q(x)+64$, $P(0)\neq P(6)$.  
모든 $Q(0)$의 값의 합을 구하여라.

**풀이 전략**: $x=0$ 대입: $\{P(0)\}^2 = (0-1)(0-5)Q(0)+64 = 5Q(0)+64$ → $Q(0)=\dfrac{\{P(0)\}^2-64}{5}$

**정답**: $42$

<details>
<summary>단계별 힌트</summary>

**힌트 1**: Q14에서 유효한 두 경우: $P(x)=x^2-10x+17$ ($P(0)=17$)과 $P(x)=x^2-2x-7$ ($P(0)=-7$).

**힌트 2**: $Q(0)=\dfrac{\{P(0)\}^2-64}{5}$.  
Case ②: $Q(0)=(289-64)/5 = 225/5 = 45$.  
Case ③: $Q(0)=(49-64)/5 = -15/5 = -3$.

**힌트 3 (거의 정답)**: 합 $= 45+(-3) = 42$.  
💡 핵심: 제수 $(x-1)(x-5)$의 근이 아닌 점에서는 $\{P(a)\}^2=(a-1)(a-5)Q(a)+64$를 직접 써서 $Q(a)$ 계산 가능.

</details>

### H3 [연결개념: Q14 결과 + 이차함수 분석]
**[왜 이 문제인가]** Q14에서 구한 $Q(x)$로 이차함수 성질(꼭짓점)을 추가로 분석합니다.

**문제**  
Q14 원문 그대로. $Q(4)$가 소수일 때, $P(x)$의 꼭짓점의 좌표를 구하여라.

**풀이 전략**: Q14의 두 경우 $Q(4)=5$ (소수), $Q(4)=21$ (소수 아님) → 하나만 남음

**정답**: $(5,\, -8)$

<details>
<summary>단계별 힌트</summary>

**힌트 1**: Q14 두 유효 경우의 $Q(4)$ 값: $5$와 $21$. 소수인 것은 $Q(4)=5$뿐 ($21=3\times7$).

**힌트 2**: $Q(4)=5$인 경우: $P(x)=x^2-10x+17 = (x-5)^2-8$.

**힌트 3 (거의 정답)**: 꼭짓점 $= (5,\, -8)$.  
검산: $P(5)=25-50+17=-8$ ✓

</details>
