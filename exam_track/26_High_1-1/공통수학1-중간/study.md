## 핵심 개념 정리 (계속 채워나갈 영역)

### 다항식
- (a+b+c)² = a²+b²+c² + 2(ab+bc+ca)
- a³±b³ = (a±b)(a²∓ab+b²)
- 항등식: 양변 동류항 계수 비교 또는 수치 대입

### 복소수
- i² = -1, $\sqrt{-a} = \sqrt{a}\,i$ (a>0)
- 음수의 제곱근 곱셈 주의: $\sqrt{a}\sqrt{b} \neq \sqrt{ab}$ when both negative
- 켤레: $\overline{a+bi} = a-bi$, $z\bar z = a²+b² = |z|²$

### 이차방정식 / 함수
- 근과 계수: $\alpha + \beta = -b/a$, $\alpha\beta = c/a$
- 판별식 D > 0 (서로 다른 두 실근), D = 0 (중근), D < 0 (허근)
- 이차함수 ↔ 이차방정식: x절편 = 근

### 나머지정리
- $f(x)$를 $x-a$로 나눈 나머지 = $f(a)$
- 인수정리: $f(a) = 0$ ⇔ $(x-a)$가 $f(x)$의 인수
