# Ch1 — 중력에 의한 운동 : 단위 · 의미 · 유도

> 목표: $v=gt$, $s=\frac12gt^2$ 를 **외우지 않고 이해**한다. 각 기호가 무슨 단위·의미인지,
> 식이 어떻게 나오는지(직관 → 적분 다리)까지.

---

## 1. 핵심 개념 상세

### 속도와 가속도부터
- **속도(velocity) $v$** : 1초에 몇 m 가는가. 단위 **m/s**. 방향 있는 벡터.
- **가속도(acceleration) $a$** : 1초에 **속도가 얼마나 변하는가**. 단위 **m/s²**.
  - "m/s 가 1초마다 얼마씩 변하나" → (m/s)/s = **m/s²**.
  - 예: $a=10$ m/s² = 매 1초마다 속도가 10 m/s씩 늘어남.

### 중력가속도 $g$
- 지구가 끌어당겨 생기는 가속도. **$g \approx 9.8$ m/s²** (시험은 보통 10으로 계산).
- 의미: 떨어지는 모든 물체는 **매초 속도가 약 9.8 m/s씩 빨라진다.**
- **무게(질량)와 무관** — 무거운 쇠공도 가벼운 돌도 같은 $g$. (갈릴레오/아폴로 깃털 실험)

### 자유 낙하 = "처음 속도 0인 등가속도 운동"
- 가만히 놓음 → $v_0=0$. 중력만 작용 → 가속도 = $g$로 **일정**.
- 가속도가 일정 = **등가속도 운동** → 아래 두 공식이 성립.

---

## 2. 공식별 단위 · 의미 표

| 공식 | 읽는 법 | 각 기호 단위 | 의미 |
|---|---|---|---|
| $v = g\,t$ | 속도 = 중력가속도 × 시간 | $v$[m/s], $g$[m/s²], $t$[s] | 매초 $g$씩 빨라지니 $t$초 뒤 속도는 $g{\times}t$ |
| $s = \tfrac12 g t^2$ | 거리 = ½ × 중력가속도 × 시간² | $s$[m], $t$[s] | 떨어진 **거리**는 시간의 **제곱**에 비례 |
| $\bar v = \dfrac{\Delta s}{\Delta t}$ | 평균속도 = 구간거리 ÷ 구간시간 | [m/s] | 그 구간을 평균 얼마 빠르기로 갔나 |
| $a = \dfrac{\Delta v}{\Delta t}$ | 가속도 = 속도변화 ÷ 시간 | [m/s²] | 자유낙하면 항상 $=g$ |

**단위 점검(차원분석):**
- $g\,t$ → (m/s²)(s) = **m/s** ✓ (속도 단위 맞음)
- $\frac12 g t^2$ → (m/s²)(s²) = **m** ✓ (거리 단위 맞음)
- 단위가 안 맞으면 식이 틀린 것 → **검산 도구로 활용!**

## 3. 유도 — 직관에서 적분까지

### (1) $v = gt$ — 등차(누적) 직관
가속도 $g$ = 매초 속도가 $g$만큼 더해짐.
- 0초: 0, 1초: $g$, 2초: $2g$, … $t$초: $g\,t$.
- `[지금: 더하기 직관]` 일정하게 더해지니 곱셈으로 → $v=gt$.
- `[나중: 적분]` 엄밀히는 $v=\int_0^t g\,dt = gt$. (일정한 $g$를 시간으로 적분)

### (2) $s = \tfrac12 g t^2$ — 두 가지 직관 + 적분 다리

**직관 A — 평균속도 이용**
- 등가속도라 속도가 0에서 $gt$까지 **일정한 비율로** 증가.
- 그래서 **평균속도 = (처음+나중)/2 = (0 + gt)/2 = $\tfrac12 gt$.**
- 거리 = 평균속도 × 시간 = $\tfrac12 gt \times t = \tfrac12 g t^2$. ✓

**직관 B — v–t 그래프의 넓이 (★적분의 씨앗)**
- 가로축 시간 $t$, 세로축 속도 $v=gt$ → **직선 그래프**.
- **이동 거리 = 그래프 아래 넓이**(이게 핵심 원리!).
- 0~$t$까지 넓이 = 삼각형 = $\tfrac12 \times 밑변(t) \times 높이(gt) = \tfrac12 g t^2$. ✓
- `[나중: 적분]` "그래프 아래 넓이 구하기"가 바로 **적분** $s=\int_0^t v\,dt = \int_0^t gt\,dt = \tfrac12 gt^2$.
  → 지금은 삼각형 넓이로 충분하지만, 곡선(속도가 복잡하게 변할 때)은 적분이 필요하다.

> **다리 메시지:** "거리 = v–t 그래프 아래 넓이"는 평생 쓰는 원리. 고1은 도형 넓이로,
> 고2~대학은 같은 걸 **적분**으로 계산할 뿐 — 원리는 똑같다.

### (3) 구간 거리비 1 : 3 : 5 : 7 — 왜?
- 누적 거리 $s=\tfrac12 g t^2$ 에 $t=1,2,3,4$ 대입(½g=5): 5, 20, 45, 80.
- **구간**(차이): 5, 15, 25, 35 → **1 : 3 : 5 : 7** (연속 홀수).
- 이유: $t^2$ 의 차이 $ (n^2-(n-1)^2)=2n-1$ → 홀수 수열.

### (4) 수평으로 던진 물체 — "두 운동의 합성"
- **수평 방향**: 던진 뒤 미는 힘 없음 → **등속**. $x=v_x t$. (단위: (m/s)(s)=m ✓)
- **연직 방향**: 중력만 → **자유낙하 그대로**. $y=\tfrac12 g t^2$, $v_y=gt$.
- 두 방향은 **서로 간섭하지 않음(독립)** → 그래서 던진 공과 떨어뜨린 공이 **동시 착지**.
- 실제 속도 = 두 벡터 합성: 속력 $=\sqrt{v_x^2+v_y^2}$.

## 4. 자주 하는 오개념
| 오개념 | 바로잡기 |
|---|---|
| "무거우면 빨리 떨어진다" | $g$는 질량 무관. (공기저항 없을 때) 동시 착지. |
| "거리도 시간에 비례한다" | 속도가 시간에 비례, **거리는 시간²에 비례**. |
| "수평으로 던지면 더 늦게 떨어진다" | 연직 운동은 자유낙하와 동일 → 착지 시간 같다. |
| "평균속도 = 순간속도" | 구간 평균은 거리/시간. 자유낙하에선 구간 중간 시각의 순간속도와 같음(등가속 성질). |
| "가속도와 속도는 같은 것" | 속도[m/s]는 빠르기, 가속도[m/s²]는 빠르기의 변화율. |
