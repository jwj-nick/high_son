# Ch3 — 관성과 안전장치 : 의미 · 원리

> 목표: 관성을 **뉴턴 1법칙으로 정의**하고, 질량의 의미를 단위로 이해.
> 안전장치를 **"관성으로 설명" vs "충격량으로 설명"** 으로 정확히 분류.

---

## 1. 핵심 개념 상세

### 관성 (inertia) — 뉴턴 제1법칙
- **외부 힘이 없으면(또는 합력이 0이면) 물체는 운동 상태를 그대로 유지한다.**
  - 정지한 물체 → 계속 정지.
  - 운동하던 물체 → **같은 속도·같은 방향**으로 계속 운동(등속 직선).
- 관성은 "힘"이 아니라 **성질(경향)**. "관성력이 민다"가 아니라 "상태를 유지하려 한다".

### 질량 = 관성의 크기 (단위로 이해)
- **질량 $m$ [kg]** : 물질의 양이자 **관성의 척도** — 클수록 상태 바꾸기 어렵다.
- 뉴턴 2법칙 $a=\dfrac{F}{m}$ 로 보면: 같은 힘 $F$라도 **$m$이 크면 $a$가 작다** → 잘 안 변함 = 관성 큼.
- 예: 같은 힘으로 밀어도 트럭(큰 m)은 잘 안 움직이고, 공(작은 m)은 확 움직임.

### 질량 vs 무게 (★자주 헷갈림)
| 구분 | 기호·단위 | 의미 | 달에 가면? |
|---|---|---|---|
| 질량 | $m$ [kg] | 물질의 양 = 관성 | **변하지 않음** |
| 무게 | $W=mg$ [N] | 중력이 끌어당기는 **힘** | $g$가 작아져 **1/6로 줄어듦** |

## 2. 안전장치 — 두 가지 논리로 분류

> 서술형 핵심: **먼저 "관성 문제냐, 충격량 문제냐"를 정하고** 그 논리로 쓴다.

### A. 관성 논리 (상태 유지 → 잡아준다 / 막아준다)
| 장치 | 설명 |
|---|---|
| **안전벨트** | 급정거 시 몸이 운동 상태를 유지해 앞으로 쏠림 → 좌석에 고정해 막음. |
| **머리받침대** | 추돌 시 몸은 밀려도 머리는 정지 유지 → 목이 젖혀짐 → 받쳐서 보호. |

### B. 충격량 논리 (시간 ↑ → 평균 힘 ↓)
| 장치 | 설명 |
|---|---|
| **에어백** | 충돌 시간을 늘려 $F=\Delta p/\Delta t$ 의 평균 힘을 줄임. |
| **헬멧** | 충격 시간 연장 + 힘을 넓게 분산. |
| **그물·매트·범퍼** | 멈추는 시간을 늘려 충격력↓. |
| **자동차 구겨지는 차체(크럼플 존)** | 일부러 찌그러지며 충돌 시간↑ → 탑승자 힘↓. |

### 헷갈리기 쉬운 경계
- 안전벨트는 **둘 다** 약하게 관여하나, 1차 논리는 **관성(쏠림 방지)**.
- 에어백은 **충격량(시간 연장)**이 1차 논리.

---

## 3. 일상 속 관성 (서술 예시 자료)
| 상황 | 어떤 상태 유지? |
|---|---|
| 버스 급출발 → 몸 **뒤로** | 정지 상태 유지하려 함 |
| 버스 급정거 → 몸 **앞으로** | 운동 상태 유지하려 함 |
| 컵 위 종이 빠르게 빼기 → 컵 그대로 | 컵의 정지 유지 |
| 망치 자루를 바닥에 쳐서 머리 끼우기 | 망치 머리의 운동 유지 |
| 먼지 묻은 옷 털기 | 옷은 멈춰도 먼지는 운동 유지 |

---

## 4. 자주 하는 오개념
| 오개념 | 바로잡기 |
|---|---|
| "관성력이 몸을 민다" | 미는 힘이 아니라 **상태를 유지하려는 성질**. |
| "질량과 무게는 같다" | 질량[kg]≠무게[N]. 무게 = $mg$. |
| "모든 안전장치는 같은 원리" | **관성형 / 충격량형** 구분해 설명해야 만점. |
| "에어백은 관성 때문" | 에어백 1차 논리는 **충격량(시간 연장)**. |

## 앱 반영 메모
- 안전장치 카드에 **[관성형/충격량형] 색 구분 + 한 줄 논리** (지금 칩 색 재활용 → 전용 라벨로).
- "질량 vs 무게" 미니 표(달 비교)를 관성 탭에 추가.
- 서술형 연습: 장치 주고 "어떤 논리?" 고르는 즉답 카드.
