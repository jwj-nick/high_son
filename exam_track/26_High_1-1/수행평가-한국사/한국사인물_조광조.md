# 한국사인물 — 조광조 (趙光祖)

> 과제 범위: 고려 태조 ~ 조선 병자호란(1636) ✅ 해당 (조선 중종)

> 이 파일은 **힌트 초안**입니다. 직접 찾아보고 빈 칸을 채워 완성하세요.

## Q1. 인적사항 (2점)

| 항목 | 내용 | 확인 필요 |
|---|---|---|
| 이름 | **조광조 (趙光祖)** | ✅ |
| 자·호 | 자: 효직(孝直), 호: 정암(靜庵) | ✅ |
| 생몰연대 | **1482 ~ 1519** | 직접 확인 |
| 시대 | 조선 중종(中宗) 재위기 | ✅ |
| 사망 원인 | **기묘사화(己卯士禍, 1519)** — 훈구파의 모함으로 사약을 받음 | ✅ |

> 💡 조광조는 33세에 중종의 신뢰를 얻어 개혁을 시작했고, 37세에 사약을 마셨다. 불과 4년간의 개혁.

## Q2. 인물이 살던 시기의 사회 문제 (3점 — 120~160자)

### 핵심 키워드

- 🔑 **훈구파(勳舊派)의 권력 독점** — 연산군 폐위에 공을 세운 세력이 공신 지위를 이용해 부와 권력 독점
- 🔑 **공신 특권 남용** — 중종반정 공신들이 과도한 토지·노비 차지
- 🔑 **도덕적 해이** — 성리학적 도덕 정치보다 이익 추구
- 🔑 **향촌 질서 붕괴** — 지방에서 백성을 통솔할 도덕적 기준 부재
- 🔑 **불합리한 과거제** — 기회가 특정 계층에 편중

### 작성 방향

```
[연산군 폭정] → [중종반정(1506)] → [공신 세력(훈구파) 득세]
                                   → [공신 특권 남용·부정부패]
                                   → [성리학 도덕 정치 실종]
조광조의 문제의식: "지금 조선은 진정한 유교 이상국가가 아니다"
```

> 🤔 스스로 생각해보기: 조광조는 왜 "도덕"을 정치의 핵심으로 봤을까?
> 조선의 건국 이념(성리학)이 어떻게 실제 정치와 달랐는지 찾아보세요.

## Q3. 조광조의 개혁안 (3점 — 120~160자)

### 주요 개혁 목록

| 개혁 이름 | 핵심 내용 | 스스로 조사할 것 |
|---|---|---|
| **현량과 (賢良科)** | 기존 과거시험 외에, 지방에서 추천을 받아 인재를 등용하는 새로운 관리 선발 방식 | 왜 훈구파가 싫어했을까? |
| **소격서 (昭格署) 폐지** | 하늘에 제사 지내는 도교 기관 폐지 → 미신보다 유교 이념 강조 | 구체적으로 어떤 기관? |
| **향약 (鄕約) 보급** | 마을 단위 자치 규약으로 유교 도덕을 일반 백성 생활에 침투 | 향약의 4대 강목이 뭔지 찾기 |
| **위훈 삭제 (僞勳削除)** | 공신 자격이 없거나 과장된 공신들의 훈호·토지를 박탈하려 함 | 이게 기묘사화의 직접적 원인 |
| **소학 (小學) 장려** | 유교 기초 덕목서인 *소학* 보급으로 도덕 교육 강화 | — |

> ⚠️ **현량과**와 **위훈 삭제**가 시험에 자주 나옴. 특히 위훈 삭제가 기묘사화를 불러온 직접 원인임을 기억.

## Q4. 나만의 개혁안 2가지 (7점 — 학생이 직접 작성)

### 생각 방향

조광조가 해결하려 했던 문제:
1. **기득권 세력의 특권** — 공신들의 과도한 기득권 → 지금 시대에도 비슷한 문제가 있을까?
2. **도덕적 정치 회복** — 능력보다 연줄로 등용되는 문제 → 현대의 어떤 제도가 이를 막는가?
3. **향촌 질서** — 지방 자치를 어떻게 강화할까?

> 💡 "조광조의 개혁이 너무 급격해서 실패했다"는 평가가 많습니다.
> 나의 개혁안은 더 단계적·현실적으로 제안해 보세요.

## Q5. 선거 포스터 힌트 (5점)

### 정당명 아이디어

- 도덕혁신당 / 정암개혁당 / 성리학실천당 / 공신특권철폐당 ...
- 키워드: **도학(道學) / 지치(至治, 지극한 정치) / 향약**

### 공약 방향

| 공약 | 힌트 |
|---|---|
| 공약 1 | 기득권 특권 제거 → 위훈 삭제의 현대적 표현 |
| 공약 2 | 인재 등용 혁신 → 현량과의 현대적 표현 (추천제? 역량평가제?) |

### 포스터 분위기

- 조광조는 **"이상주의자"** — 포스터에 "도덕" "정의" "개혁" 키워드
- 비극적 최후를 강조하면 감동 포인트가 될 수 있음
