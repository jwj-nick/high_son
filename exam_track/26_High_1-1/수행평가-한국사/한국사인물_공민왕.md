## Q2. 인물이 살던 시기의 사회 문제 (3점 — 120~160자)

### 핵심 키워드 (골라서 연결하세요)

- 🔑 **원나라 간섭** (약 100년, 1270~1356)
- 🔑 **권문세족** — 원과 결탁해 부와 권력 독점
- 🔑 **토지 겸병** — 권문세족이 불법으로 토지를 빼앗음 → 농민 몰락
- 🔑 **정방(政房)** — 왕을 무시한 인사권 기관
- 🔑 **홍건적·왜구** — 잦은 외침으로 민생 피폐

### 작성 방향 힌트

```
[원나라 간섭] → [권문세족 성장] → [토지 겸병] → [농민 피폐]
                                 → [왕권 약화(정방)]
                                 → [홍건적·왜구 침입]
```

> 🤔 스스로 생각해보기: "원나라가 고려에 어떤 식으로 간섭했나?" 
> 쌍성총관부, 정동행성, 기황후 — 이 셋이 무엇인지 찾아보면 서술이 풍부해집니다.

## Q3. 공민왕의 개혁안 (3점 — 120~160자)

### 주요 개혁 목록 (단답 → 설명으로 바꿔야 함!)

| 개혁 이름 | 개혁 내용 (스스로 조사) |
|---|---|
| 반원 자주 정책 | 기철 등 친원 세력 숙청. 쌍성총관부 공격·수복(1356). 원의 연호·복식 폐지 |
| 전민변정도감 (田民辨正都監) | 권문세족이 불법 점유한 토지를 원래 주인에게 돌려주고, 억울하게 노비가 된 사람을 양인으로 환원 |
| 정방 폐지 | 무신정권 이래 인사권을 장악하던 정방을 폐지 → 왕 중심 인사권 회복 |
| 신돈 등용 | 승려 신돈을 등용해 개혁 추진 (성공과 실패 모두 있음) |

> ⚠️ 시험에서는 "전민변정도감"이라고만 쓰면 감점! **"어떤 제도인지" 설명**이 필수.

### 서술 예시 구조

```
공민왕은 [개혁 이름]을 실시하였다. 이는 [구체적 내용]으로,
[어떤 문제를 해결하려 했는지]를 목적으로 한 것이었다.
```

## Q4. 나만의 개혁안 2가지 (7점 — 학생이 직접 작성)

### 생각 방향만 제시 (답 아님, 힌트임)

공민왕이 해결하려 했던 문제들:
1. **토지 불평등** → 지금으로 치면 어떤 문제와 비슷한가?
2. **외세 의존 왕권 약화** → 자주성 회복을 위해 어떤 장치가 필요했을까?
3. **특권층(권문세족)의 권력 독점** → 어떤 제도적 장치로 막을 수 있었을까?

> 💡 개혁안 작성 팁: "~을 설치/실시하여 ~를 해결한다" 구조로 쓰면 명확합니다.
> 실현 가능성보다 **논리적 연결**이 중요합니다.
