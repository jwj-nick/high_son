## 작업 워크플로우

### 1단계: 사진 → 마크다운 과목표

- `01_captured_pic/*.jpg` → `02_subjects_text/*.md`
- 필수과목 / 선택과목 구분, 학점 표시, 막단위([막N]) 표시
- OCR 불확실 → `⚠️OCR?` 표시

### 2단계: 진로 방향 파악

- Nick이 `03_analysis/진로방향.md`에 관심 분야·직업·대학 계열 입력
- Claude가 과목 분류 제안 (`03_analysis/과목분류.md`)

### 3단계: 과목 조합 시뮬레이션

- 진로 방향별 추천 조합 (이공계 STEM / AI·SW / 인문사회 / 의약계 등)
- 막(묶음) 제약 조건 고려
- `03_analysis/선택시뮬레이션.md`에 기록

### 4단계: 진로 탐색 (선택)

- `/se_person_research <인물>` 로 관련 인물 조사
- 관련 직업·학과 정보 보강

### 5단계: 앱 제작 (선택)

- 과목 선택 인터랙티브 도구 (체크리스트형 HTML)
- `se_agent_app_reviewer`로 품질 검토
