# se_math_practice — 수학 연습 문제 생성 스킬

## 인자 형태
```
/se_math_practice                 # 인터랙티브
/se_math_practice Q12             # 수학 기본 (과목 생략 시 공통수학1)
/se_math_practice Q12 수학        # 과목 명시
```

## 절차

### 1. 준비
- 해당 문제의 오답노트 .md를 Read하여 약점 태그와 핵심 개념 파악
- 없으면 02_text에서 문제 원문 직접 읽기
- 해당 단원 교육과정 수준 확인 (고1 공통수학1 범위 내)

### 2. 연습 문제 생성 — 3카테고리 × 3문제

#### 카테고리 정의
| 카테고리 | 의미 | 기준 |
|---|---|---|
| 🟢 쉬운 문제 | 핵심 구조 분리, 계산 단순화 | 원본 문제의 핵심 개념 하나씩 연습 |
| 🟡 비슷한 레벨 | 같은 핵심 개념, 다른 구성 | 원본과 같은 사고 흐름, 다른 형태 |
| 🔴 응용 문제 | 확장·융합·창의 | 추가 조건, 다른 단원 결합, 역방향 질문 |

#### 각 문제 포함 내용 (모두 필수)
1. **문제 번호** — L1/L2/L3 (쉬운), M1/M2/M3 (중간), H1/H2/H3 (어려운)
2. **[연결 개념]** — 이 문제가 연습하는 핵심 개념 태그
3. **문제 본문** — 완결된 수학 문제, KaTeX 수식
4. **풀이 전략** — 접근 방향 (답은 아님, 힌트 수준)
5. **정답** — 최종 답
6. **왜 이 문제인가** — 원본 문제와의 연결 설명 (1~2줄) ← **정답판에 표시**
7. **단계별 힌트** — `<details>` 접기로 3단계 힌트

> **앱 탭 배치 규칙**: "왜 이 문제인가"는 문제판이 아닌 **정답판** 상단에 표시. 문제를 풀기 전에는 힌트 없이 도전, 정답을 확인할 때 연결 의미를 함께 파악.

### 3. 파일 저장 — .md + _practice_app.html 두 파일 생성

**파일 1**: `<과목>-중간/10_오답노트/Q<번호>_practice.md` (마크다운 연습문제)

**파일 포맷**:

```markdown
# Q<번호> 연습 문제 — <주제>

> 원본 문제: Q<번호>_<주제>.md 참조
> 약점 태그: `수학:태그1`, `수학:태그2`
> 생성일: YYYY-MM-DD

---
```

**파일 2**: `<과목>-중간/10_오답노트/Q<번호>_practice_app.html` (SPA 인터랙티브 앱)

**practice_app.html 구조**:
- 목록 뷰: 카테고리 필터 (전체/쉬운/중간/어려운) + 문제 카드 그리드
- 상세 뷰: 탭 3개 — 문제판 / 정답판 / 풀이판
- P[] 데이터 배열: `{id, cat, catLabel, title, sub, why, prob, ansVal, ansDetail, ansCheck, sol}`

**practice_app.html APP_PRINCIPLES 준수** — [APP_PRINCIPLES.md](../../../APP_PRINCIPLES.md):
- `prob` 필드: 문제만 표시, 슬라이더·JSXGraph 금지
- `why` (왜 이 문제인가): **정답판(ans 탭)**에만 표시, 문제판에는 없음
- "Q{N}의 설정에서..." 참조 문제: `prob` 필드에 정적 `<img>` 참조 이미지 포함
- 정답·풀이는 탭 전환으로만 공개

**시각화 규칙 — 연습 문제에 그림이 필요한 경우**:

함수·그래프·좌표 개념을 연습하는 문제는 `prob` 필드에 inline SVG를 포함한다.

| 문제 유형 | 그림 처리 |
|---|---|
| "Q{N}의 설정에서..." | 원본 Q{N}_app.html의 page-0 SVG를 소형(max-width:260px)으로 재사용 |
| 새로운 좌표/함수 문제 | 정성적 정적 SVG 직접 작성 (축 수치 없음, O/A/B 라벨만) |
| 순수 대수 계산 | SVG 생략 가능 |

SVG 작성 원칙 (APP_PRINCIPLES §page-0 준수):
- 좌표 수치 레이블 없음 — 점 이름(O, A, B...)만 표시
- 구간·방향을 정성적으로만 표현 (e.g., 포물선 개형, 꼭짓점 위치)
- 색상: 포물선 `#4361EE`, min 점 `#22c55e`, max 점 `#ef4444`

## 문제 생성 원칙
- **수학적 정확성 최우선** — 모든 답은 검산 후 기재
- **단순 숫자 변환 금지** — 각 문제는 다른 사고를 요구해야 함
- **고1 공통수학1 범위** — 미분·적분 등 고2 내용 제외
- **풍부한 해설** — 힌트는 "어떤 방향으로 생각할지" 제시
- **원본 문제와 연결** — 각 문제가 원본의 어떤 약점을 보완하는지 명시
- 카테고리 내 3문제는 서로 다른 각도에서 접근해야 함 (단순 반복 금지)
