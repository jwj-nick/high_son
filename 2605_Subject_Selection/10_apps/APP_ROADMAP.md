## 철학

> 아이가 **혼자 탐색하면서 질문을 만들어가는 도구**.  
> 답을 주는 앱이 아니라 **다음 질문과 검색을 유도하는 출발점**.

## Phase 0 — MVP: 진로 탐색기 (지금)

**파일**: `career_explorer.html`

### 기능
- 8가지 진로 카드 브라우저 (사이드바/모바일 드롭다운)
- 진로별 과목 스케줄 (4학기 × 막 제약 반영)
- **탐색 가이드** per 진로:
  - 탐색 질문 (스스로 생각해볼 것)
  - 추천 검색어 (클릭 → Google 검색 자동 실행)
  - 관련 학과 목록
- 개인 메모 (로컬스토리지 저장)

## Phase 1 — 과목 선택기 + 막 검증

**파일**: `subject_picker.html`  
**조건**: 진로방향.md 입력 완료 후

### 기능
- 학기별 과목 풀 전체 표시
- 클릭으로 과목 선택/해제
- **막 제약 실시간 검증**: [막4] 4개 선택 안 되면 경고
- 학점 카운터: 필수 + 선택 = 29학점 자동 계산
- "내 선택표" 저장 (로컬스토리지) + 출력 지원
- 진로 시나리오 불러오기 버튼 (과목분류.md 데이터 연동)

## Phase 2 — 진로 비교 도구

**파일**: `career_compare.html`

### 기능
- 2개 진로 나란히 비교 (side-by-side)
- 공통 과목 / 차이 과목 하이라이트
- "나라면 어느 쪽?" 판단 포인트 제시

## Phase 3 — 인물 탐구 연동

**조건**: `04_career/인물_*.md` 파일 생성 후

### 기능
- 각 진로 상세에 "탐구 인물" 섹션 추가

- 인물 프로필 카드 (학력, 커리어 경로, 선택과목 관련성)

## Phase 4 — 수능 연계 심화

## 확장 원칙

| 원칙 | 내용 |
|---|---|
| **데이터 분리** | 내용 업데이트는 JS 배열만 수정 — HTML 구조 건드리지 않음 |
| **단계별 잠금** | Phase N+1 기능은 Phase N 완료 전까지 UI에서 숨김 (disabled 처리) |
| **로컬 우선** | 개인화 데이터(메모·선택)는 localStorage — 서버 불필요 |
| **검색 연동** | 검색어 클릭 → `window.open(google search)` — 외부 API 불필요 |
| **인쇄 지원** | `@media print` CSS 추가 → 학부모·선생님과 오프라인 대화용 |

## 아이디어 / 미래 확장 메모

- **나의 진로 일기**: 날짜별 생각 변화 기록 (localStorage)
- **선생님/부모님 모드**: 같은 데이터, 다른 UI (어른 관점 메모)
- **"왜 이 과목?" 팝업**: 각 추천 과목 옆에 왜 추천하는지 툴팁
- **진로 변경 이력**: 어떤 진로를 언제 탐색했는지 기록
- **체크리스트 모드**: 탐색 질문에 체크 → "이건 알아봤어요" 표시
- **공유 기능**: URL 파라미터로 진로 선택 공유 (e.g. `?career=ai&pick=...`)
