### 1.2 핵심 신규 컴포넌트

#### A) **가상 페르소나 탭** (가장 중요한 신규 기능)

- 각 진로 카드에 *"가상 페르소나"* 탭 추가
- 모든 페르소나에 `[가상 인물]` 뱃지 + 카드 상단 경고 배너
- 페르소나 카드 구성:
  ```
  ⚠️ 가상 인물 (실존하지 않음)  ━━━━━━━━━━━━
  김지호 (31세, 2040년)
  K리그 데이터 분석가
  "축구는 90분, 데이터는 90시간"
  → 어떤 길로 왔는지 / 가치관 / 시나리오 한 줄
  ```
- *축구분석가 4 path × 4명* = 16명, *AI플러스 6분야 × 5명* = 30명
- 일반 진로(공학·AI·SW·의약·자연·인문·경영·교육·예체능)에는 페르소나가 .md에 없음 → **"실제 인물 검색 가이드" 탭으로 대체**하거나 *생략*

#### B) **실제 인물 / 자료 검색 가이드** (가상과 명확히 분리)

- 가상 페르소나 옆에 *"실제 인물·자료"* 보조 섹션
- 축구분석가 데이터 path 예: Ted Knutson (StatsBomb CEO), David Sumpter (Soccermatics 저자) → 클릭하면 Google 검색 새 탭
- 라벨링: `🟢 실제 인물 (Google 검색)` vs `🟣 가상 인물 (NCC 창작)`
- 색상·아이콘으로 시각적 분리

#### C) **공식 대학 자료 패널** ★ 신규

축구분석가 1순위 매칭 → 통계/응용통계 학과 7개 + 데이터사이언스 학과 6개 정보를 카드 형태로:

```
┌── 🏫 중앙대 응용통계학과 ─────────────────┐
│ 📊 입학정원 37명 | 가군 | 수능89%        │
│ 신뢰도: ★★★★★ (공식 PDF 추출)         │
│                                            │
│ 🔗 [학과 홈]  [입학처]  [📄 2028 PDF]   │
│ 📝 [분석 노트 (.md)]                      │
└────────────────────────────────────────────┘
```

- 학교 7개: SNU 통계 / 연세 응통 / 고려 통계 / SKKU 사회과학 / CAU 응통 / 한양 데이터사이언스 / UOS 통계
- 각 카드: 학과 홈 / 입학처 메인 / 로컬 PDF (file://) / 분석 .md (file://) 4개 링크
- 로컬 파일 링크는 동일 폴더 상대경로로 (file:// 보안상 직접 불가하니 **상대경로** `../06_univ_data/...`)

#### D) **호기심 유발 질문 강화**

기존: 5개 일반 질문 → 신규: *3종 질문 묶음* 으로 재분류
1. **🤔 자기 자신에게 묻는 질문** (감정·기질)
2. **🔍 세상에 묻는 질문** (사실·현실)
3. **🚀 다음 단계 행동 질문** (실험·실행)

축구분석가 예시:
- 🤔 *"내가 K리그 한 경기를 90분 보면서 메모를 채울 수 있을까?"*
- 🔍 *"FBref·StatsBomb 데이터가 실제로 어떻게 생겼지?"*
- 🚀 *"이번 주말, 좋아하는 팀의 한 경기를 분석한 1페이지를 써볼까?"*

#### E) **"더 깊이" 문서 인덱스** ★ 신규

각 진로별로 관련 .md 파일을 *직접 클릭해서 읽을 수 있는* 링크 목록:
- 축구분석가 → INDEX_축구분석가.md + 4 path .md
- AI+의약 → AI플러스_의약생명.md
- (브라우저에서 .md 파일을 보면 raw 마크다운이 보임 → 차후 마크다운 렌더링 검토)

## 2차 자체 리뷰 — 1차 플랜의 약점 검출

### 🔴 약점 1: 진로 카드가 18개 — 너무 많음, 사이드바 압박

- 18개 진로 = 사이드바 스크롤 길어짐. 모바일에서 select 18개 = 선택 피로
- **해결**: 사이드바를 *접이식 그룹*으로 — 기본은 "🎯 1순위 (4개)"만 펼친 상태, 나머지 2그룹은 헤더 클릭으로 펼침
- AI 플러스 6개는 *각 일반 진로 안의 "AI 플러스" 탭으로 통합* 가능 (예: 의약·생명 카드 안에 "AI 플러스" 탭) → 18개 → 12개로 감소

### 🔴 약점 2: 가상/실제 구분의 *시각적* 강도 부족

- 1차 플랜의 [가상] 뱃지·배너만으론 *아이가 빠르게 스크롤하면 놓침*
- **해결**:
  - 가상 페르소나 카드 *왼쪽에 보라색 두꺼운 세로 바*(8px)
  - 카드 배경에 *대각선 워터마크* "가상 / 시나리오"
  - 페르소나 이름 옆 항상 작은 라벨 `🎭 가상`
  - 첫 진입 시 모달: "이 앱의 인물 이야기는 *모두 AI가 만든 가상 인물*입니다. 실제 인물·기관은 ✅ 표시." (한 번만, localStorage로 기억)

### 🔴 약점 3: "더 깊이" 문서가 *raw .md*면 아이가 안 읽음

- 마크다운 raw 보여주면 표가 깨져서 보기 안 좋음
- **해결 옵션 A**: marked.js CDN으로 인라인 마크다운 렌더링 (1KB 라이브러리, 단일 HTML 유지 가능)
- **해결 옵션 B**: 핵심 내용을 *발췌*해서 모달/하단 패널에 자체 HTML로 표시
- → **A 채택** (자료가 너무 많아 다 옮기면 HTML 거대해짐)

### 🟡 약점 4: 로컬 파일 링크의 보안 제약

- 브라우저 `file://` 페이지에서 다른 `file://` 링크 — Chrome 등은 *허용*하지만 Edge 일부 모드는 막힘
- PDF는 `<a href="../06_univ_data/snu_2028_official.pdf" target="_blank">` 시도
- **해결**: 우선 상대경로로 시도하고, 안 되면 *"PDF 파일을 직접 열기: 폴더 위치 표시"* fallback 텍스트

### 🟡 약점 5: 호기심 질문이 *과목 선택과 무관한 진로 일반*에 쏠림

- 1차 플랜 질문 예시들은 "내가 좋아하는가" 위주
- *아이가 과목을 골라야 한다*는 게 진짜 목적
- **해결**: 4번째 카테고리 추가 — `📚 과목 선택에 던지는 질문`
  - 예: "정보(2-1)와 인공지능 기초(2-2)를 모두 듣지 않으면 어떤 길이 막힐까?"
  - 예: "기하 안 듣고 미적분II 들어도 될까?"

### 🟡 약점 6: 일반 8 진로에 *가상 페르소나가 없음*

- AI 플러스·축구분석가에만 페르소나 → 8 일반 진로는 페르소나 탭이 비어있음
- **해결 A**: 8 진로는 "가상 페르소나" 탭 없이 *"실제 인물·자료 검색 가이드"* 탭만
- **해결 B**: 페르소나는 *AI 플러스 자료에서 끌어옴* — 예: 일반 의약·생명 카드 안에 "AI+의약" 페르소나 5명을 *연결 안내* 형태로 노출
- → **A + B 혼합 채택**: 일반 진로 카드에 *"같은 분야의 AI 플러스 시나리오 보기"* 링크 + 실제 인물 가이드

### 🟢 약점 7: AI 플러스 통합 시 메인 진로 본질이 흐려짐

- 약점 1 해결책으로 "AI 플러스를 일반 진로의 탭으로" 했는데, 이러면 AI 플러스 시나리오의 *독립적인 통찰*이 약해짐
- **재해결**: AI 플러스는 *별도 그룹 유지하되 6개 → 6개로 사이드바 표시*. 단 사이드바 그룹이 접혀있어 처음엔 노출 안 됨. 클릭으로 펼침.
- 최종 구조 = **사이드바 3그룹 (접이식)**: ⚽ 1순위(4) | 🌐 일반(8) | ✨ AI플러스(6) = 18

### 🟢 약점 8: 모바일에서 select 18개

- **해결**: 모바일도 동일하게 *그룹 헤더 + 선택지* `<optgroup>` 사용

### 🔴 약점 9 (중요): *시작 화면(welcome)*이 무관심

- 진로 선택 안 한 상태에서 보이는 화면이 "진로를 선택하세요"만
- 아이가 *처음 열었을 때 무엇을 해야 하는지 모름*
- **해결**: welcome 화면을 *3개 안내 카드*로 구성
  1. *"먼저 ⚽ 축구분석가 4 path를 비교해보세요"* (1순위 안내)
  2. *"💭 호기심 질문에서 답을 못 한 질문이 있나요?"* (자기 점검)
  3. *"🏫 관심 학과의 공식 PDF를 직접 열어보세요"* (현실 자료 접근)
- 그리고 *"이 앱의 가상 인물 안내"* 카드를 별도 한 번 보여줌

### 🔴 약점 10 (중요): *진행감* 부재

- 아이가 *내가 어디까지 봤는지* 모름
- **해결**: 진로 카드를 *열어본 적 있으면* 사이드바에 ✓ 표시 (localStorage)
- 메모 작성한 진로엔 *📝* 아이콘

### 🟡 약점 11: 페르소나 *4명/5명 모두 카드로 표시*하면 화면 너무 김

- **해결**: 첫 1명은 카드 펼쳐서, 나머지는 *접힌 형태* (이름·한줄만), 클릭 시 펼침

### 🟡 약점 12: 16개 + 30개 = 46개 가상 페르소나 데이터 입력 부담

- 페르소나 데이터를 *축약*해도 됨: 이름·나이·직업·진입경로·가치관 한 줄
- 스토리 전문은 .md 파일 링크로 안내
- 46개 객체 = 약 5KB JSON, HTML 부담 X

### 🟢 약점 13: 대학 카드 7개만? — 사이드바 그룹과 별개로 어디 둘 것인가?

- 1차 플랜은 "축구분석가 1순위 매칭"이라고 했지만, 일반 진로별로도 학교 카드 있어야 함
- **해결**: *대학 카드 = 진로별 sched 아래 별도 섹션*에 표시. 진로별 매칭되는 학과만 노출.
- 매핑:
  - ⚽ 데이터/구단 → CAU 응통 / UOS 통계 / 한양 데이터사이언스 / SKKU 사회과학 (응통 진입 경로)
  - ⚽ 비전 → 한양 데이터사이언스 / KAIST (외부 링크) / 고려 데이터과학 / SNU 통계
  - ⚽ 콘텐츠 → (직접 매칭 학교 데이터 없음) → 일반 인문·사회 안내
  - AI·SW → 한양 데이터 / 고려 데이터과학 / SNU 통계
  - 의약·생명 → (데이터 없음) → 안내만
  - 자연과학 → SNU 통계 / 연세 응통 / 고려 통계
  - 인문·사회 / 경영·경제 → SKKU 사회과학 / CAU 응통
  - 교육·사범 / 예체능 → 데이터 없음, 안내
- 데이터 없는 진로는 *"이 분야의 대학 정보는 아직 정리 안 됨 — 다음 라운드에서"* 표시

### 🟡 약점 14: localStorage 데이터 호환성

- 기존 사용자는 `career_note_eng`, `career_note_ai` 등으로 저장. 새 id 체계와 호환?
- **해결**: 기존 8개 id (eng/ai/med/sci/hum/biz/edu/art) 유지. 신규 ⚽×4 + AI+×6 id만 추가.

### 🔴 약점 15: 한 파일 안 너무 큼?

- 현재 40KB. 신규 추가로 80~120KB 예상 — 단일 HTML로는 여전히 OK
- **해결**: 단일 HTML 유지. 다만 CSS·JS·DATA 섹션 명확히 구분, DATA는 별도 `<script id="data">` 블록.

### 3.12 marked.js 인라인 마크다운

```html
<script src="https://cdn.jsdelivr.net/npm/marked/marked.min.js"></script>
<script>
async function loadMarkdown(path) {
  try {
    const text = await (await fetch(path)).text();
    return marked.parse(text);
  } catch (e) {
    return `<p style="color:#94a3b8">⚠️ 파일을 불러올 수 없습니다. <a href="${path}" target="_blank">${path}</a> 를 직접 열어보세요.</p>`;
  }
}
</script>
```

- `file://` 프로토콜에서 fetch는 CORS 제약 → 직접 열기 안내가 fallback
- 호스팅된 경우 정상 동작
