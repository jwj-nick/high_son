## § 1. 핵심 개념: 이온결합 vs 공유결합

| 구분 | 이온결합 | 공유결합 |
|---|---|---|
| **결합 방식** | 전자를 **주고받음** (이동) | 전자쌍을 **공유** |
| **결합 원소** | 금속 + 비금속 | 비금속 + 비금속 |
| **생성물** | 양이온(+) + 음이온(−) | 공유 전자쌍 |
| **상온 상태** | 고체 결정 | 기체·액체·고체 다양 |
| **녹는점** | 높음 | 낮음 (분자성) |
| **물 용해** | 잘 녹음 | 극성: 잘 녹음 / 무극성: 안 녹음 |
| **전기 전도** | 용액·용융 상태 ✓ | 거의 전도 안 함 ✗ |
| **화학식 표기** | 이온식 Na⁺, Cl⁻ | 분자식 H₂O, CO₂ |

## § 2. 공유결합 종류

| 결합 종류 | 공유 전자쌍 | 표기 | 예시 |
|---|---|---|---|
| 단일결합 | 1쌍 | ─ | H₂, HCl, NH₃, CH₄, H₂O₂ |
| 이중결합 | 2쌍 | ═ | O₂, CO₂ |
| 삼중결합 | 3쌍 | ≡ | N₂ |

## § 3. 이온 기호·전하 암기표

| 이온 | 기호 | 전하 | 생성 |
|---|---|---|---|
| 나트륨 이온 | Na⁺ | +1 | Na → 전자 1개 잃음 |
| 마그네슘 이온 | Mg²⁺ | +2 | Mg → 전자 2개 잃음 |
| 칼슘 이온 | Ca²⁺ | +2 | Ca → 전자 2개 잃음 |
| 칼륨 이온 | K⁺ | +1 | K → 전자 1개 잃음 |
| 철(Ⅲ) 이온 | Fe³⁺ | +3 | Fe → 전자 3개 잃음 |
| 염화 이온 | Cl⁻ | −1 | Cl → 전자 1개 얻음 |
| 산화 이온 | O²⁻ | −2 | O → 전자 2개 얻음 |
| 수산화 이온 | OH⁻ | −1 | O+H 공유결합체 |
| 탄산 이온 | CO₃²⁻ | −2 | C+O 공유결합체 |
| 탄산수소 이온 | HCO₃⁻ | −1 | H+C+O 공유결합체 |

## § 4. 예시 물질 22종 — 분류 + 상세

### 🔵 이온결합 (5종)

| 번호 | 물질명 | 화학식 | 이온 비율 | 전자 이동 | 녹는점 |
|---|---|---|---|---|---|
| ① | 소금 (염화나트륨) | NaCl | Na⁺:Cl⁻ = 1:1 | Na → 1개, Cl ← 1개 | 801°C |
| ② | 산화 마그네슘 | MgO | Mg²⁺:O²⁻ = 1:1 | Mg → 2개, O ← 2개 | 2852°C |
| ③ | 산화 철(Ⅲ) | Fe₂O₃ | Fe³⁺:O²⁻ = 2:3 | Fe → 3개, O ← 2개 | 1565°C |
| ④ | 염화 칼륨 | KCl | K⁺:Cl⁻ = 1:1 | K → 1개, Cl ← 1개 | 770°C |
| ⑤ | 제설제 (염화칼슘) | CaCl₂ | Ca²⁺:Cl⁻ = 1:2 | Ca → 2개, Cl ← 1개씩 | 772°C |

**이온결합 형성 과정 (NaCl 예시)**
```
① Na (원자가전자 1개) → 전자 1개 잃음 → Na⁺(+1)
② Cl (원자가전자 7개) → 전자 1개 얻음 → Cl⁻(-1)
③ Na⁺ + Cl⁻ → 정전기적 인력 → NaCl 이온결합
```
그림: Na 원자에서 Cl 원자로 전자 이동 화살표 → 각각 이온 상태 → 결합

### 🟢 공유결합 (13종)

| 번호 | 물질명 | 화학식 | 결합 종류 | Lewis 구조 | 비공유전자쌍 |
|---|---|---|---|---|---|
| ① | 수소 기체 | H₂ | 단일결합 | H─H | 없음 |
| ② | 산소 기체 | O₂ | 이중결합 | O═O | O 각 2쌍 |
| ③ | 질소 기체 | N₂ | 삼중결합 | N≡N | N 각 1쌍 |
| ④ | 염화 수소 | HCl | 단일결합 | H─Cl | Cl 3쌍 |
| ⑤ | 암모니아 | NH₃ | 단일결합×3 | N(H)₃ | N 1쌍 |
| ⑥ | 메테인 | CH₄ | 단일결합×4 | C(H)₄ | 없음 |
| ⑦ | 이산화 탄소 | CO₂ | 이중결합×2 | O═C═O | O 각 2쌍 |
| ⑧ | 과산화 수소 | H₂O₂ | 단일결합×3 | H─O─O─H | O 각 2쌍 |
| ⑨ | 에탄올 | C₂H₅OH | 단일결합 | CH₃CH₂─O─H | — |
| ⑩ | 아세트산 | CH₃COOH | 단일+이중 | CH₃─C(═O)─OH | — |
| ⑪ | 설탕 | C₁₂H₂₂O₁₁ | 공유결합 | 복잡한 탄소화합물 | — |
| ⑫ | 포도당 | C₆H₁₂O₆ | 공유결합 | 육탄당 고리 | — |
| ⑬ | 아스피린 | C₉H₈O₄ | 공유결합 | 벤젠 고리 포함 | — |

**공유결합 형성 과정 예시**

H₂ (단일결합):
```
H• + •H → H:H → H─H
(전자 1개씩 공유 → 공유 전자쌍 1개)
```

O₂ (이중결합):
```
:Ö: + :Ö: → :O::O: → O═O
(전자 2개씩 공유 → 공유 전자쌍 2개)
```

N₂ (삼중결합):
```
:N• + •N: → N:::N → N≡N
(전자 3개씩 공유 → 공유 전자쌍 3개)
```

NH₃ (N 중심 + H 3개):
```
N (원자가전자 5개) + 3H (원자가전자 1개씩)
→ N-H 단일결합 3개, N에 비공유전자쌍 1쌍 남음
→ 삼각뿔 구조
```

### 🟡 혼합형 — 이온결합 + 공유결합 (4종)

| 번호 | 물질명 | 화학식 | 이온 부분 | 공유 부분 |
|---|---|---|---|---|
| ① | 수산화 나트륨 | NaOH | Na⁺ ↔ OH⁻ | O─H (OH⁻ 내부) |
| ② | 제산제 (수산화마그네슘) | Mg(OH)₂ | Mg²⁺ ↔ 2OH⁻ | O─H (각 OH⁻ 내부) |
| ③ | 탄산 칼슘 | CaCO₃ | Ca²⁺ ↔ CO₃²⁻ | C─O (CO₃²⁻ 내부) |
| ④ | 베이킹파우더 (탄산수소나트륨) | NaHCO₃ | Na⁺ ↔ HCO₃⁻ | H─O, C─O (HCO₃⁻ 내부) |

**혼합형 핵심 원리:**
> 다원자 이온(OH⁻, CO₃²⁻, HCO₃⁻) 내부는 비금속끼리 → 공유결합
> 다원자 이온과 금속 이온 사이는 금속+비금속 → 이온결합

## § 5. 원자 모형 그리기 (시험 체크리스트)

### 이온결합 그림 (전자 이동)
```
[Na]       →      [Na⁺]    +    e⁻   →   [Cl⁻]
원자핵+11e     원자핵+10e    (이동)      원자핵+18e
(K:2, L:8, M:1) (K:2, L:8)         (K:2, L:8, M:8)
```
- Na 원자: 전자 껍질 3개 (K=2, L=8, M=1)
- Na⁺: 전자 껍질 2개 (K=2, L=8) — 최외각 전자 0개
- Cl 원자: 전자 껍질 3개 (K=2, L=8, M=7)
- Cl⁻: 전자 껍질 3개 (K=2, L=8, M=8)

### 공유결합 그림 (전자 공유)
- 두 원자의 원자가 전자가 **겹치는 부분** 표시
- 공유된 전자쌍은 선으로: ─(단일), ═(이중), ≡(삼중)
- 비공유 전자쌍은 점 2개씩(••)으로 표시
