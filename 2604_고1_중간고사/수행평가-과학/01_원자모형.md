# 과학 수행평가 준비 — 1. 원자 모형

> 시험일: 2026-05-07(목) | 범위: 교과서 57~87쪽

---

## 핵심 개념

### 원자의 구조
- **원자핵:** 양성자(+) + 중성자(중성)가 중심에 위치
- **전자(−):** 원자핵 주위의 전자 껍질에 배치
- **원자 번호 = 양성자 수 = 전자 수** (전기적 중성 상태)

### 전자 껍질 (보어 모형)
| 껍질 이름 | 기호 | 최대 전자 수 |
|---|---|---|
| 1번째 껍질 | K | 2 |
| 2번째 껍질 | L | 8 |
| 3번째 껍질 | M | 8 (고교 수준) |

**규칙:** 안쪽 껍질부터 채운다. K(2) → L(8) → M(8) 순.

### 원자가 전자 (가장 중요!)
- **정의:** 가장 바깥 껍질에 있는 전자
- **왜 중요한가:** 화학 결합에 직접 참여하는 전자
- 같은 족(세로줄) 원소는 원자가 전자 수가 같음 → 화학적 성질 유사

## 그림으로 그리는 방법 (단계별)

### 예시: 나트륨 (Na, 원자번호 11)

**Step 1.** 원자번호 확인 → 양성자 11개, 전자 11개  
**Step 2.** 원자핵 원 그리기 → 안에 "11p" 표기 (양성자 수)  
**Step 3.** K껍질: 원자핵 바깥에 첫 번째 원, 전자 2개 점으로 표시  
**Step 4.** L껍질: 두 번째 원, 전자 8개 점으로 표시  
**Step 5.** M껍질: 세 번째 원, 전자 1개 점으로 표시  
**Step 6.** 원자가 전자: M껍질의 전자 1개 → 동그라미나 화살표로 강조

```
         ●
    ●●●  |  ●●●
  ●      |      ●
●   ●●   11p  ●●   ●    ← M껍질 전자 1개 = 원자가 전자
  ●      |      ●
    ●●●  |  ●●●
         ●
```

(실제 시험에서는 동심원 + 점으로 깔끔하게 그리기)

### 그리는 순서 핵심 규칙
1. 원자핵 원 → 양성자 수 표기
2. K껍질 원 → 전자 최대 2개 배치
3. L껍질 원 → 전자 최대 8개 배치 (남은 전자 수 확인)
4. M껍질 원 → 나머지 전자 배치
5. 가장 바깥 껍질 전자 = **원자가 전자** 명시

## 자주 출제되는 원자 모형 연습 세트

시험에 자주 나오는 원소들:

| 연습 원소 | 이유 |
|---|---|
| H, C, N, O | 유기화합물·공유결합 핵심 |
| Na, Cl | NaCl(이온결합) 대표 |
| Mg, O | MgO(이온결합) 대표 |
| Ca, Cl | CaCl₂(이온결합) 대표 |
| Na, O, H | NaOH 구성 원소 |

## 시험 체크리스트

- [ ] 원자번호 = 양성자 수 = 전자 수 암기
- [ ] K:2, L:8, M:8 순서 기억
- [ ] 원자가 전자 = 가장 바깥 껍질 전자 수
- [ ] 위 주요 원소 12가지 전자 배치 그릴 수 있음
- [ ] 양성자·전자·전자껍질 위치와 개수를 그림에 명확히 표기
- [ ] 네온(Ne)·헬륨(He)은 원자가 전자 0 = 안정 = 결합 안 함
