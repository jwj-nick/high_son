## 2. 평가 3요소 (공지 분석)

| # | 평가 주제 | 학생이 할 일 (계산·설명) |
|---|---|---|
| ① | 중력에 의한 물체의 운동 분석 | 자유낙하·수평투사의 **구간별 이동거리, 구간 평균속도, 속도 변화량, 가속도** 구하고 운동 설명 |
| ② | 충격 받은 물체의 운동량 변화 분석 | 충돌 과정의 **충격량, 운동량 변화량, 평균 충격력, 속도 변화량** 설명 |
| ③ | 안전사고·안전장치 설명 | 일상 사례에서 **관성 법칙** 설명 + 안전장치의 과학 원리 설명 |

> **핵심:** 교실에서 주어진 데이터로 **빠르고 정확하게 계산**하고 **과정을 서술**하는 평가.
> → 앱은 (1) 개념을 확실히 이해시키고 (2) 계산 절차를 손에 익히게 하고 (3) 서술 훈련을 시킨다.

## 3. 설계 철학 (Nick 요청 반영)

1. **기본 개념을 재미있고·흥미롭고·시각적으로** — 애니메이션/시뮬레이션, 직관 우선
2. **의미부여** — "왜 이걸 배우나?" (안전벨트·스포츠·우주… 실생활 연결)
3. **과학자 에피소드** — 갈릴레오(피사의 사탑/낙하), 뉴턴(운동 법칙) 스토리
4. **몸풀기 → 도전** 2단계 문제: 쉬운 개념확인 → 실전형 도전
5. **오답노트식 점진 공개** — 도전 문제는 **문제만 먼저** 제시
   - 권장 풀이 시간 표시 ("이 문제 3분 안에!")
   - "계산 과정 꼭 적기" 코칭
   - [풀이 보기] 누르면 **단계별로 하나씩** 공개 (수학 Q16 앱 패턴)

## 4. 앱 구조 (통합 단일 HTML, 탭 기반)

| 탭 | 제목 | 내용 |
|---|---|---|
| ① | 📋 개요 | 일정·배점·평가 3요소 + "왜 운동을 배우나" 의미부여 hook |
| ② | 🌍 중력 운동 | 자유낙하·수평투사 **애니메이션** + 구간표 자동계산 + 갈릴레오 에피소드 + 왜 중요한가 |

- 바닐라 HTML/CSS/JS, 빌드 없음 (math_2 앱과 동일 기조)

- 애니메이션: Canvas 또는 SVG + requestAnimationFrame
- APP_PRINCIPLES 준수: 도전 문제 = 문제 페이지(문제만) → 풀이 페이지(점진 공개)
