## 1. 왜 MathTelling 자산이 결정적인가

수행평가는 단순히 "비에트가 뭘 했는지" 나열하는 게 아니라 **사고 방식의 변화** 와 **자기 관심분야 활용**(문항 3, 600자)을 묻는다.
이 부분에서 점수가 갈린다. 그런데 비에트 단독 자료(`수학자_비에트.md`)만으로는 **비에트가 왜 혁명적이었는지의 "전후 대비"** 가 약하다.

MathTelling 의 인물 서사는 **비에트의 앞·뒤 시대**를 이야기로 풀어놓은 자산이라 그대로 답안의 깊이로 연결된다.

| 답안 약점 | MathTelling 보강 자산 |
|---|---|
| "비에트 이전엔 글자가 없었다" 가 추상적 | Unit 3 알콰리즈미 — *"어떤 수에 5를 더하면 8이 된다"* 식 묘사 |
| 미지수 기호화가 한 번에 일어난 게 아님을 모름 | Unit 4 디오판토스 — 미지수를 기호로 쓴 **부분적** 첫 시도 |
| "사고 변화"의 깊이가 얕음 | Literacy 트랙 L1~L4 — **문자=자리(slot)**, 압축 표현, 일반형↔구체형 |
| 자기 관심분야 활용을 막연하게 씀 | Literacy 트랙의 메타 인식 → 코딩/AI/알고리즘 자연스러운 연결 |

## 3. 답안 강화 전략 — 문항별

### 문항 1 — 발견 이론
이미 [수학자_비에트.md §수학 업적](수학자_비에트.md) 에 충분.
키워드: **대수학 문자 기호 체계 (모음=미지수, 자음=상수)** + **비에트 공식 (근과 계수의 관계)**

### 문항 2 — 공통수학1 연결 (300자)
직접 연결고리 한 줄 잡기:

> 비에트 공식 = **근과 계수의 관계** (Ⅱ. 방정식·이차방정식 직접 등장)
> 이차방정식 $ax^2+bx+c=0$ 의 두 근 $\alpha, \beta$ → $\alpha+\beta=-\frac{b}{a}$, $\alpha\beta=\frac{c}{a}$
> + 다항식 표기($ax^2+bx+c$) 자체가 비에트 유산이라는 메타 포인트 추가

### 문항 3 — 사고 변화 + 자기 관심분야 활용 (600자) ⭐ 점수 갈림목

**3단 구조로 작성:**

#### Before — 글자 없는 700년 (MathTelling Unit 3·4 활용)
- 알콰리즈미(9세기): 방정식을 **말로** 풀었다 — *"어떤 수에 5를 더하면 8이 된다"*
- 디오판토스(3세기): 미지수에 그리스 첫 글자를 붙인 **부분적** 시도
- → 문제마다 새로 설명을 써야 했고, 일반화가 불가능했다

#### Hero — 비에트의 1591년 혁명
- *"In artem analyticam isagoge"* — 모음(A,E,I)=미지수, 자음(B,C,D)=상수
- 처음으로 **모든 이차방정식을 한 줄로** 표현 가능 (구체 → 일반)
- 결과: 근과 계수의 관계를 **계수만 보고** 알 수 있게 됨 (= 비에트 공식)

#### After — 사고 방식의 변화 + 내 관심분야 활용
- **핵심 사고 변화**: "구체적인 한 문제 → 모든 같은 형태 문제의 일반 규칙"
  - = **추상화·패턴 인식·압축 표현** (Literacy 트랙 L1~L4 메타 인식)
- 데카르트가 $x, y, z$ 로 정착시킨 후 → 뉴턴·라이프니츠 미적분으로 확장
- **현대 활용 (자기 관심분야 — 컴퓨터/코딩 방향이라면)**:
  - 변수(variable) 개념 = 비에트의 "자리(slot)" 개념 그대로
  - `algorithm` 어원도 알콰리즈미의 라틴어 표기 → 비에트 → 현대 코드
  - AI/머신러닝의 모든 수식($\theta, w, b$ 같은 파라미터)이 비에트 유산
  - 일상 예: 엑셀의 셀 참조($A1$), 함수의 인자(parameter), 게임의 변수
- **다른 관심사 적용 시 변형**: (음악 → 코드 진행을 변수로 표현 / 운동 → 통계 변수 / 글쓰기 → 변수가 만드는 일반화의 미학)

## 5. 답안에 쓸 만한 핵심 인용·문장 후보

> "어떤 수에 5를 더하면 8이 된다" → 비에트 이전 800년간 방정식이 쓰이던 방식 (출처: MathTelling Unit 3)

> "말 대신 기호, 설명 대신 식." — 디오판토스가 처음 시도한 것을, 비에트가 **완성**했다.

> 비에트의 *In artem analyticam isagoge*(1591) 한 권이 없었다면, $ax^2+bx+c=0$ 도, $\alpha+\beta=-\frac{b}{a}$ 도, 컴퓨터 코드의 변수 `x` 도 존재하지 않는다.

> 비에트가 만든 건 공식이 아니라 **언어** 자체였다. 그 언어 위에 데카르트·뉴턴·튜링·현대 AI 가 모두 서 있다.
