# study — 수행평가 수학 #2 학습 노트

## 약점 태그 (예상)
- `수학:연립일차부등식` — 두 부등식 공통범위, 변수 치환(A=x, B=250-x)
- `수학:순열` — ₙPᵣ, 이웃하여 서기(묶음 3!×2!), 양끝 고정(2!×4!)
- `수학:조합` — ₙCᵣ, 묶음 나누기(₇C₃), 같은 것 붙이기(₅C₃)
- `수학:논술서술` — 풀이 과정·근거를 문장으로 작성

## 핵심 개념

### A. 연립일차부등식
1. 미지수 설정: 간식 A = x g → 간식 B = (250 − x) g
2. 비율 환산: "100g당 값" → 1g당 값 = 값/100
3. 두 제약(에너지·나트륨) 각각 부등식 → 공통 범위(교집합)
4. **가장 빡빡한(작은) 상한**이 답을 결정 — 나트륨 쪽(178.6)이 에너지(183.9)보다 작음
5. 반올림: 문제 지시대로 소수 첫째 자리

### B. 순열·조합 9가지 유형 (2번 박스)
| 상황 | 키워드 | 식 |
|---|---|---|
| 순서 O, 일부 선택 | "일렬로", "순서대로" | ₙPᵣ |
| 순서 X, 일부 선택 | "뽑는", "택하는" | ₙCᵣ |
| 한쪽 끝 고정 | "A가 끝에" | 2 × (나머지)! |
| 양쪽 끝 고정 | "A,B 양끝" | 2! × (가운데)! |
| 이웃하여 | "A,B 이웃" | (묶음 전체)! × (묶음 내)! |
| 같은 것 일부에 | "똑같은 메모 3장" | 자리 선택 = ₙCᵣ |
| 두 묶음 나누기 | "3송이·4송이" | ₙC₃ (크기 다르면 한 번만) |
