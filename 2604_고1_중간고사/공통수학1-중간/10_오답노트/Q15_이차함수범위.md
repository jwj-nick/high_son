## 문제 (원문)
두 자연수 $a, b$에 대하여 $0 \le x \le 3$에서 이차함수
$$f(x) = (x-a)^2 + 3b$$
의 최댓값을 $M$, 최솟값을 $m$이라 하자.
$M \le 25$이고 $m \ge 6$을 만족시키는 모든 순서쌍 $(a, b)$의 개수는? [5.5점]

① $16$  ② $17$  ③ $18$  ④ $19$  ⑤ $20$

## 채점
| | |
|---|---|
| 내 답 | 미입력 |
| 정답 | ③ $18$ |
| 배점 | 5.5점 |
| 오답 유형 | 꼭짓점 위치에 따른 최대·최솟값 변화를 경우별로 나누지 않음 |

## § 개념 체크

| # | 질문 | 핵심 답 |
|---|---|---|
| 1 | $(x-a)^2$은 $x=a$에서 최솟값을 가진다. 구간 $[0,3]$ 내에 $a$가 있을 때 최솟값은? | $f(a)=3b$ (꼭짓점값) |
| 2 | 꼭짓점 $x=a$가 구간 안($1 \le a \le 3$)에 있을 때 최댓값은? | 양끝 $f(0),\, f(3)$ 중 큰 값 |
| 3 | $a=1$일 때 최댓값은? | $f(0)=1+3b$, $f(3)=4+3b$ → $M=f(3)=4+3b$ |
| 4 | $a=4$일 때 (꼭짓점이 구간 오른쪽 밖) 최솟값은? | $f(3)=(3-4)^2+3b=1+3b$ |
| 5 | $a \ge 5$이면 $M$이 $25$를 초과하는가? | $M=f(0)=a^2+3b \ge 25+3b > 25$. 항상 초과. |

## § 풀이 (올바른 접근)

### 1단계: 꼭짓점 위치로 경우 분류
$f(x)=(x-a)^2+3b$는 위로 볼록한 포물선. 꼭짓점 $x=a$.

| 범위 | 최솟값 $m$ | 최댓값 $M$ |
|---|---|---|
| $a=1$: $0<a<3$ | $f(a)=f(1)=3b$ | $\max(f(0),f(3))=\max(1+3b,\,4+3b)=4+3b$ |
| $a=2$: $0<a<3$ | $f(2)=3b$ | $\max(f(0),f(3))=\max(4+3b,\,1+3b)=4+3b$ |
| $a=3$: 끝점 포함 | $f(3)=3b$ | $f(0)=9+3b$ |
| $a \ge 4$: 꼭짓점이 구간 오른쪽 밖 | $f(3)=(a-3)^2+3b$ | $f(0)=a^2+3b$ |

**왜 경우를 나누나?** 꼭짓점 위치에 따라 최솟값이 달라지기 때문.

### 2단계: 각 경우에 $M \le 25$, $m \ge 6$ 적용

**$a=1$**: $m=3b \ge 6$ → $b \ge 2$. $M=4+3b \le 25$ → $b \le 7$.  
$b \in \{2,3,4,5,6,7\}$ → **6가지**

**$a=2$**: $m=3b \ge 6$ → $b \ge 2$. $M=4+3b \le 25$ → $b \le 7$.  
$b \in \{2,3,4,5,6,7\}$ → **6가지**

**$a=3$**: $m=3b \ge 6$ → $b \ge 2$. $M=9+3b \le 25$ → $b \le 5$.  
$b \in \{2,3,4,5\}$ → **4가지**

**$a=4$**: $m=1+3b \ge 6$ → $b \ge 2$ (자연수). $M=16+3b \le 25$ → $b \le 3$.  
$b \in \{2,3\}$ → **2가지**

**$a \ge 5$**: $M = a^2+3b \ge 25+3 = 28 > 25$. **0가지**

### 3단계: 합산
$$6 + 6 + 4 + 2 = \mathbf{18}$$

### 검산
$a=4,\, b=2$: $M=16+6=22 \le 25$ ✓, $m=1+6=7 \ge 6$ ✓  
$a=4,\, b=3$: $M=16+9=25 \le 25$ ✓, $m=1+9=10 \ge 6$ ✓  
$a=3,\, b=5$: $M=9+15=24 \le 25$ ✓, $m=15 \ge 6$ ✓

## § 왜 틀렸나
| 유형 | 구체적 상황 | 교정 포인트 |
|---|---|---|
| 경우 미분류 | 꼭짓점 위치와 무관하게 최솟값을 항상 $3b$로 씀 | 꼭짓점이 구간 밖이면 최솟값≠$3b$ |
| $a \ge 4$ 누락 | $a=1,2,3$만 검토 | $a=4$도 유효한 경우가 있음 |
| 경계 계산 오류 | $a=3$일 때 최댓값 계산 실수 | $f(0)=(0-3)^2+3b=9+3b$ 직접 계산 |

## § 핵심 개념

### 닫힌 구간에서 이차함수의 최대·최소
$[p,q]$에서 $f(x)=(x-a)^2+k$ (위로 볼록):
- 꼭짓점 $a \in [p,q]$이면: 최솟값 $=k$, 최댓값 $=\max(f(p),f(q))$
- 꼭짓점 $a < p$이면: $f$는 $[p,q]$에서 증가 → 최솟값 $=f(p)$, 최댓값 $=f(q)$
- 꼭짓점 $a > q$이면: $f$는 $[p,q]$에서 감소 → 최솟값 $=f(q)$, 최댓값 $=f(p)$
