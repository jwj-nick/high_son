### Q17 [5.8점]
삼각형 $ABC$ 의 세 변의 길이 $a, b, c$ 가 다음 〈조건〉을 만족시킨다. 삼각형 $ABC$ 의 둘레의 길이의 최댓값을 $M$, 최솟값을 $m$ 이라 할 때, $M - m$ 의 값은? (단, $a, b, c$ 는 정수이다.)

**조건**
- (가) $a < b < c$
- (나) 다항식 $ax^2 - (a^2 + ab)x + a^2 b$ 를 $x - c$ 로 나눈 나머지는 $21$ 이다.

① $4$  ② $10$  ③ $16$
④ $22$  ⑤ $30$

### Q18 [5.9점]
두 복소수 $z_1 = a + bi$, $z_2 = c + di$ 에 대하여 $a, b, c, d$ 는 자연수이고, $z_1 \overline{z_1} = 5$ 일 때, 〈보기〉에서 옳은 것만을 있는 대로 고른 것은? (단, $i = \sqrt{-1}$ 이고, $\overline{z}$ 는 복소수 $z$ 의 켤레복소수이다.)

**보기**
- ㄱ. $a^2 + b^2 = 25$
- ㄴ. $z_1 - z_2 = -4i$ 이면 $c + d = 7$
- ㄷ. $(z_1 + z_2)(\overline{z_1} + \overline{z_2}) = 52$ 이면 $z_2 \overline{z_2}$ 의 최댓값은 $25$ 이다.

① ㄱ  ② ㄴ  ③ ㄷ
④ ㄴ, ㄷ  ⑤ ㄱ, ㄴ, ㄷ
