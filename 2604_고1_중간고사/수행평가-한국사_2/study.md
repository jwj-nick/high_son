# study — 한국사1 개항기 약점·학습 전략

## 시험 한 줄 요약
개항기(1863~1885) **용어 28개**를 빈칸에 정확히 써넣는 시험. 26개 이상 = 10점 만점.

## 학습 전략 (3단계)
1. **흐름 먼저** — 타임라인으로 사건 인과를 외운다 (개별 암기보다 강력).
   - 양요 라인: 병인박해→병인양요 / 제너럴셔먼호→신미양요→척화비
   - 개항 라인: 운요호→강화도조약→수신사
   - 개화 라인: 조사시찰단·영선사·별기군→임오군란→제물포·조청상민
   - 정변 라인: 개화파 분화→갑신정변→한성조약·톈진조약·거문도
2. **빈칸 반복** — 시험 형식 그대로 입력 훈련, 표기 정확도 체크.
3. **오답 집중** — 틀린 것만 망각곡선으로 재반복.

## 헷갈리기 쉬운 짝 (오답 빈출 예상)
| 구분 | A | B |
|---|---|---|
| 양요 | 병인양요(1866, 프랑스) | 신미양요(1871, 미국) |
| 1866 두 사건 | 병인박해(천주교) | 제너럴셔먼호(미국 상선) |
| 임오군란 후 조약 | 제물포 조약(일본) | 조청상민수륙무역장정(청) |
| 갑신정변 후 조약 | 한성조약(조-일) | 톈진 조약(청-일) |
| 사절단 파견국 | 조사시찰단(일본) | 영선사(청) |
| 개화파 | 온건(동도서기·김홍집) | 급진(메이지·김옥균) |
