## 2. 유형 분류 — **용어 암기형** (신규 유형)
기존 3유형과 구분된다:
- 계산·분석형(과학_2 `se_perf_study_app`) ❌
- 보고서 Step형(사회 `se_perf_eval_step`) ❌
- 인물 조사형(정도전 `se_perf_eval_person`) ❌
- → **용어 암기형(빈칸 채우기 시험 대비)** ✅ — 가장 가까운 자산: `study-quiz` / example jsx 플래시카드

> **목표:** 28개 용어를 **정확한 표기로 암기**하고 **빈칸 형식에 익숙**해져 26개 이상(만점권) 달성.
> 단순 암기가 아니라 **개항기 인과 흐름(타임라인)**으로 묶어 외운다 — 사건이 사건을 부르는 구조.

## 3. 설계 철학
1. **흐름 우선.** 연도·인과(병인박해→병인양요, 운요호→강화도조약…)를 타임라인으로 먼저 잡고 용어를 건다.
2. **시험과 동일한 빈칸 형식**으로 훈련 — 입력→채점, 표기 정확도 강조.
3. **오답 집중 반복** — 틀린 용어만 다시 도는 루프(망각곡선).
4. **실전 모드** — 30문항 모의 + 평가척도로 점수 환산 → 실제 점수 감각.
5. 캡쳐(자습서·교과서)에서 **사료·지도·인물 사진** crop → 플래시카드에 시각 단서 보강.

| ⑥ | 🎯 실전 모드 | 30문항 랜덤 모의 → 맞은 개수 → **평가척도 점수 환산** |

### 기술 규약
- **단일 HTML + 바닐라 JS** (빌드 없음). React example jsx는 데이터·UX 레퍼런스로만 사용.
- `APP_PRINCIPLES.md` / `APP_HOSTING.md` 준수 (모바일/데스크탑, 파일명 규칙).
- 진도·오답은 `localStorage` 저장.
- 용어 데이터는 `02_text/용어정본.md`와 동기화(앱 상단 주석에 정본 경로 명시).
