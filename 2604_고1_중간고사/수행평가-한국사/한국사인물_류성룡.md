## Q2. 인물이 살던 시기의 사회 문제 (3점 — 120~160자)

### 핵심 키워드

- 🔑 **임진왜란(1592~1598) 이전의 국방 공백** — 200년 평화로 군비 해이, 군역제 문란
- 🔑 **붕당 정쟁** — 동인·서인 갈등으로 왜란 대비 소홀
- 🔑 **임진왜란 발발** — 일본군의 급속 북상, 한양 함락, 선조 의주 피난
- 🔑 **전시 행정·군사 체계 붕괴** — 기존 군사 조직(오위제)이 전쟁에서 무너짐
- 🔑 **민생 피폐** — 전쟁으로 토지 대부분 황폐화, 인구 감소

### 작성 방향

```
[200년 평화 → 군비 해이] + [붕당 정쟁 → 왜란 대비 실패]
→ [임진왜란 발발(1592)] → [한양 함락, 선조 피난, 의병 봉기]
→ [기존 군사체계 붕괴 → 새로운 군사·행정 개혁 필요]
류성룡의 역할: "전쟁 중 실질적 개혁을 주도한 재상"
```

> 🤔 스스로 생각해보기:
> - 류성룡이 이순신을 전라좌수사로 천거한 이유는?
> - 전쟁 중 새로운 군사 제도가 왜 필요했을까?

## Q3. 류성룡의 개혁안 (3점 — 120~160자)

### 주요 개혁 목록

| 개혁 이름 | 핵심 내용 | 스스로 조사 |
|---|---|---|
| **훈련도감 (訓鍊都監) 설치** | 임진왜란 중 창설(1593). 기존 징병제 대신 **급료를 주는 상비군(직업 군인)** 편성. 조총·기마·포 3기 훈련 | 기존 군사 제도(오위제)와 차이? |
| **속오법 (束伍法)** | 지방 향촌 방위를 위해 양인·천인 신분에 관계없이 장정을 편성하는 군사 조직 | 신분제와 어떻게 충돌? |
| **이순신 천거** | 조산보만호 이순신을 전라좌수사로 파격 발탁 → 해전 승리의 기반 | — |
| **징비록 (懲毖錄) 집필** | 임진왜란 전 과정의 원인·경과·교훈을 기록한 회고록. "징비"는 "미리 징계하여 후환을 막는다"는 뜻 | 어떤 내용이 담겨 있나? |

> ⚠️ **훈련도감**이 핵심 — "급료를 받는 직업 군인" "기존 징병제와 다름"을 반드시 설명해야 함.

### 서술 예시 구조

```
류성룡은 [훈련도감]을 설치하였다. 이는 [기존 징병제와 달리 급료를 주는 상비군 제도]로,
[임진왜란 중 무너진 군사 체계를 재건]하고 [지속적인 전투력을 유지]하기 위한 개혁이었다.
```

## Q4. 나만의 개혁안 2가지 (7점 — 학생이 직접 작성)

### 생각 방향

류성룡이 해결하려 했던 문제:
1. **상비군 부재** — 훈련도감으로 일부 해결. 전국적으로 확대하는 방법은?
2. **전시 행정 혼란** — 왕이 도망가도 작동하는 국가 시스템을 어떻게 만들까?
3. **신분제와 군사 편성** — 속오법이 신분을 초월했듯, 더 나아가면 어떤 개혁이 가능할까?

> 💡 류성룡의 *징비록* 마지막 부분: "우리 후손은 이런 실수를 반복하지 말라."
> 나의 개혁안은 "두 번 다시 이런 위기가 안 생기게" 하는 방향으로 구성해 보세요.

## Q5. 선거 포스터 힌트 (5점)

### 정당명 아이디어

- 국방재건당 / 징비개혁당 / 서애민생당 / 상비군창설당 ...
- 키워드: **국방 / 상비군 / 준비 / 민생 재건**

### 공약 방향

| 공약 | 힌트 |
|---|---|
| 공약 1 | 군사 개혁 → 훈련도감의 현대적 표현 (직업군인제, 상비군) |
| 공약 2 | 전후 복구·민생 → 토지 재분배, 인구 복구 정책 |

### 포스터 분위기

- 류성룡은 **"위기의 재상"** — "나라를 구한 관료" 이미지
- *징비록*의 "경계하여 준비하라" 메시지가 포스터 슬로건으로 어울림
