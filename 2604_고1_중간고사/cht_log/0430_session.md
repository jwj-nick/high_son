## 주요 논의 및 결정사항

### 1. 오답노트 포맷 확정 (v1)
Q12 오답노트를 예시로 삼아 7섹션 포맷 확정:
1. 문제 (원문)
2. 채점 (내 답 / 정답 / 배점 / 오답 유형)
3. § 개념 체크 — Q&A 테이블 (앱의 인터랙티브 요소)
4. § 풀이 (올바른 접근) — 단계별
5. § 왜 틀렸나 — 유형/상황/교정 포인트 표
6. § 핵심 개념
7. § 약점 태그

### 2. 오답노트 HTML 앱 포맷 확정
- 단일 HTML 파일, 바닐라 JS, KaTeX CDN
- 페이지: 문제 → 단계별 풀이 (N단계) → 한페이지 요약
- 진행 도트로 단계 이동, 두 버튼 (단계별 / 요약 바로보기)
- 친절한 한국어 말투, deg 등 비표준 기호 설명 박스 추가

### 3. Q12 오답노트 작업
- **정답 정정**: 기존 예시 파일의 f(2)=85(④)는 오류 → 정답 **⑤ 105**
- 정확한 풀이: P(x)=x²+6x+4, Q(x)=x+3, f(x)=x³+9x²+22x+17
- 생성 파일:
  - `공통수학1-중간/10_오답노트/Q12_다항식나눗셈.md`
  - `공통수학1-중간/10_오답노트/Q12_app.html` (5단계 풀이 앱)

### 4. deg 표기 처리 방식 결정
- **deg는 국제 표준 기호** (ISO 80000-2, 영미 교과서 모두 사용)
- 앱에서: 첫 등장 시 초록 박스로 설명 + 이후 보라색 한글 병행 표기
- 규칙: 비표준·낯선 기호는 첫 등장 시 설명, 이후 "한글설명 (수식)" 형태
