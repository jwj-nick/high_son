# mat-start — 재진입

## 절차
1. `inbox/README.md`를 읽는다 (예시문항 전문. 사진은 세부 확인이 필요할 때만 연다).
2. `SESSION_LOG.md` 마지막 라운드를 읽는다 (Nick의 마지막 지시와 Claude의 마지막 약속).
3. `PLAN.md` §3 산출물 표의 ⬜ 항목과 §5 라운드 계획을 대조해 **현재 라운드**를 정한다. §7 열린 질문 중 ⬜가 남아 있으면 그 답이 필요한 산출물은 뒤로 미룬다.
4. `10_prep/01_analysis.md` §0(정답표)·§4(변형 축)·§5(감점 포인트)를 읽는다 — 모든 산출물의 근거.
5. `git status`·`ls 10_prep 90_output`으로 디스크 실측 (로그와 어긋나면 디스크가 진실). 다른 과제 세션의 스테이징 파일이 보이면 건드리지 않는다.
6. 브리핑 3줄: 현재 라운드 / 이번에 만들 산출물 / Nick 확인 지점 여부.
7. Nick 확인 지점(`PLAN.md` §5)이 아니면 **묻지 않고** 진행한다. 확인 지점이면 질문만 간결히.

- 경로를 지정하지 않은 `git commit` (다른 세션의 스테이징을 끌어간다).
