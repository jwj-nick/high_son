# mat-log — 라운드 기록

## 규칙 (science-1-2-1 라운드 1에서 Nick이 정한 과제 폴더 표준)
- Nick의 발화는 **원문 그대로**(오타 포함) 인용 블록으로 남긴다. 요약·정정 금지.
- Claude 답변은 **전문**을 남긴다. 사용자에게 보내는 텍스트와 로그의 텍스트가 같아야 한다.
- 답하기 **전에** 로그를 먼저 쓴다.

## 절차
1. `SESSION_LOG.md` 끝에 다음 틀을 추가한다.

   ```
   ---
   ## 라운드 N — <한 줄 제목> (YYYY-MM-DD)
   ### Nick (원문)
   > (원문)
   ### Claude 답변 (전문)
   (답변)
   ```

2. 결정이 바뀌면 `PLAN.md` 해당 표 상태(⬜/🟡/✅)와 §8 변경 이력에 한 줄. 열린 질문이 닫히면 §7 상태 갱신.
3. 커밋은 **이 폴더만**: `git add perf_track/math-1-2-1/<파일들>` 뒤 `git commit -m "perf(math-1-2-1): 라운드 N — <요지>" -- perf_track/math-1-2-1`. 다른 과제 세션(society·science)이 스테이징한 파일은 절대 포함하지 않는다.
