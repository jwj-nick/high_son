## 시험의 본질과 준비 전략

"유형은 그대로, 숫자만 바뀐다"는 말은 이 시험이 **파라미터만 바뀌는 템플릿**이라는 뜻입니다. 그래서 준비는 네 가지로 좁혀집니다.

1. 두 문제의 논리를 "왜 그 방법이 되는가"까지 한 번 확실히 이해한다. (접선 조건이 왜 "중심~직선 거리 = 반지름"인지, 대칭이동하면 왜 꺾인 길이 펴지는지.)
2. **만점 답안 골격**(문장 순서와 근거 문장)을 손에 익힌다. 논술형이므로 채점은 과정 문장에 붙습니다.
3. 숫자가 바뀐 변형을 **손으로** 6~8회 풀고 답 쪽과 대조해 자가 채점한다.
4. 함정 3종(2번의 대칭 순서, 반지름 빼기, 1번의 단위)을 전날 점검한다.

1번은 계단식 소문항이라 개념만 정확하면 되고, 위험은 분수·근호 손계산(25x²−10x+1, √(400/25))과 서술 누락입니다. 2번은 한 덩어리 논술이라 논리 순서 자체가 점수입니다. 특히 "P가 놓인 직선에 A를, Q가 놓인 직선에 B를 대칭시킨다"는 규칙이 실전에서 순서가 바뀌면 그대로 함정이 되므로, 변형 은행에 순서를 바꾼 문제를 일부러 넣겠습니다.

## 확인 지점 1 — 답안 틀 전문 (아들이 외울 순서, ▢에 숫자만 갈아끼움)

**카드 ① 1번형 — 원 밖의 점에서 그은 접선**

- 문제 1: 중심이 (▢, ▢)이고 반지름의 길이가 ▢인 원의 방정식은 (x − ▢)² + (y − ▢)² = ▢² → ▢
- 문제 2-1: 직선 y − ▢ = m(x − ▢)를 정리하면 mx − y + (▢m + ▢) = 0. 직선이 원에 접하려면 **원의 중심 C(▢, ▢)에서 이 직선까지의 거리가 반지름 ▢과 같아야** 하므로 |▢m + ▢| / √(m² + 1) = ▢ → 양변 제곱 → ▢m² = ▢(m² + 1) → m² = ▢. (A와 C가 수직 배치면 m이 사라지고 상수만 남는다: |▢| / √(m² + 1) = ▢ → ▢ = ▢(m² + 1)) 따라서 m = ▢ 또는 m = −▢ (둘 다 쓴다)
- 문제 2-2: m = ▢ : y − ▢ = ▢(x − ▢) → y = ▢x + ▢ / m = −▢ : y − ▢ = −▢(x − ▢) → y = −▢x + ▢
- 문제 3 (방법 A, 대입 → 중근): 기울기가 ▢수인 직선 y = ▢x + ▢ 를 원에 대입하면 (x − ▢)² + (▢x + ▢)² = ▢ → 양변에 ▢를 곱하고 전개·정리 → ▢x² + ▢x + ▢ = 0. 접하므로 **중근**: (▢x + ▢)² = 0 → x = ▢, y = ▢. 따라서 P(▢, ▢) [검산: (▢ − ▢)² + (▢ − ▢)² = ▢ ✓]
- 문제 3 (방법 B, 수선의 발): 접점은 **중심 C에서 접선에 내린 수선의 발**이다. 접선에 수직이고 C(▢, ▢)를 지나는 직선: y − ▢ = ▢(x − ▢). 두 직선을 연립: ▢x + ▢ = ▢x + ▢ → 양변에 ▢를 곱하면 ▢x + ▢ = ▢x + ▢ → x = ▢, y = ▢ → P(▢, ▢)
- 문제 4: AP = √((▢ − ▢)² + (▢ − ▢)²) = √(▢ + ▢) = √▢ = ▢. 한 눈금의 실제 길이가 ▢ m이므로 실제 길이 = ▢ × ▢ = **▢ m** (단위!) [검산: CP ⊥ AP, AC = ▢, CP = ▢ → AP = √(AC² − CP²) = √(▢ − ▢) = ▢ ✓]

**카드 ② 2번형 — 두 직선을 차례로 거치는 최단 경로 (대칭이동)**

- ① 원 C₁ 위의 점 A를 **▢**(P가 놓인 직선)에 대하여 대칭이동한 점을 A′이라 하자. [▢ 대칭: (x, y) → (▢, ▢)] 점 P는 ▢ 위의 점이고 ▢은 선분 AA′의 수직이등분선이므로 **AP = A′P**
- ② 원 C₂ 위의 점 B를 **▢**(Q가 놓인 직선)에 대하여 대칭이동한 점을 B′이라 하자. 점 Q는 ▢ 위의 점이므로 **QB = QB′**
- ③ AP + PQ + QB = A′P + PQ + QB′ ≥ **A′B′** (등호: P, Q가 선분 A′B′ 위에 이 순서로 놓일 때)
- ④ A′은 원 C₁을 ▢에 대칭이동한 원 C₁′: (x − ▢)² + (y − ▢)² = ▢ (중심 (▢, ▢), 반지름 ▢) 위를 움직인다. B′은 원 C₂를 ▢에 대칭이동한 원 C₂′: … 위를 움직인다.
- ⑤ C₁′C₂′ = √((▢ − ▢)² + (▢ − ▢)²) = √▢ = ▢ (▢ > ▢ + ▢ 이므로 두 원은 서로 밖). **점에서 원 위의 점까지 거리의 최솟값 = (중심까지의 거리) − (반지름)** 이므로 A′B′ ≥ A′C₂′ − ▢, A′C₂′ ≥ C₁′C₂′ − ▢. 따라서 A′B′의 최솟값 = ▢ − ▢ − ▢ = ▢ (등호: A′, B′이 선분 C₁′C₂′ 위에 있을 때)
- ⑥ 따라서 최소 길이는 **▢**. (선택, 시간 남으면) 최솟값을 주는 A′, B′에 대하여 선분 A′B′이 ▢을 P(▢, ▢)에서, ▢을 Q(▢, ▢)에서 차례로 지나므로 A → P → Q → B 순서의 경로가 실제로 존재한다.

예시문항에 이 틀을 채우면 1번은 (x − 2)² + (y − 1)² = 9, m = ±3/4, y = (3/4)x + 13/4 와 y = −(3/4)x − 5/4, P(1/5, 17/5), 4 × 10 = 40 m이고, 2번은 C₁′(8, −2), C₂′(−4, 3), 중심 거리 13, 13 − 2 − 2 = 9입니다.
