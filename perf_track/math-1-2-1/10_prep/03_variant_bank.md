## V1 — 1번형 · 수평 배치(예시와 같은 꼴), 삼조 5-12-13

**원형 분수대와 조명 케이블 설계하기**

> 한 공원에서는 광장 한가운데의 원형 분수대와 직선 모양의 조명 케이블을 만들려고 한다. 이를 좌표평면에 나타냈을 때 원형 분수대의 중심은 C(1, 2)이고, 반지름의 길이는 5이다. 또한 좌표평면에서 한 눈금의 실제 길이는 10 m이다. 분수대 밖에 있는 전원함 A(−12, 2)에서 출발하여 분수대 가장자리에 닿는 직선 모양의 조명 케이블을 설치하려고 한다. 케이블은 분수대의 내부를 지나지 않고 분수대의 경계와 한 점에서만 만나도록 설계한다. (단, 케이블의 굵기는 생각하지 않는다.)

- 문제 1. 원형 분수대의 방정식 — 중심이 C(1, 2)이고 반지름의 길이가 5인 원형 분수대의 경계를 나타내는 원의 방정식을 구하시오.
- 문제 2. 조명 케이블의 방정식 — 점 A(−12, 2)를 지나고 기울기가 m인 직선의 방정식을 y − 2 = m(x + 12)이라고 하자. 이 직선이 원형 분수대의 경계와 한 점에서만 만나도록, 즉 원형 분수대에 접하도록 조명 케이블을 만들려고 한다.
-   1. 가능한 기울기 m의 값을 모두 구하시오.
-   2. 두 조명 케이블의 방정식을 각각 구하시오.
- 문제 3. 조명 케이블과 원형 분수대가 만나는 점 — 문제 2에서 구한 두 조명 케이블 중 기울기가 양수인 조명 케이블을 선택하자. 이 조명 케이블과 원형 분수대가 만나는 점을 P라고 할 때, 점 P의 좌표를 구하시오.
- 문제 4. 실제 조명 케이블의 길이 — 점 A에서 문제 3에서 구한 접점 P까지 조명 케이블을 설치하려고 한다. 좌표평면에서 한 눈금의 실제 길이가 10 m일 때, 설치해야 하는 조명 케이블 AP의 실제 길이를 구하시오. 풀이 과정과 단위를 함께 나타내시오.

### 풀이

**문제 1. 원의 방정식**
- 중심이 (a, b)이고 반지름의 길이가 r인 원의 방정식은 (x − a)² + (y − b)² = r² 이다.
- 중심이 C(1, 2), 반지름이 5이므로
- ▶ (x − 1)² + (y − 2)² = 25

**문제 2-1. 기울기 m**
- 직선 y − 2 = m(x + 12)를 정리하면  mx − y + (12m + 2) = 0
- 직선이 원에 접하려면 **원의 중심 C(1, 2)에서 이 직선까지의 거리가 반지름 5와 같아야** 하므로
- |m − 2 + 12m + 2| / √(m² + 1) = 5
- → |13m| / √(m² + 1) = 5
- 양변을 제곱하면  169m² = 25(m² + 1)
- → 144m² = 25  →  m² = 25/144
- ▶ m = 5/12 또는 m = −5/12

**문제 2-2. 두 조명 케이블의 방정식**
- m = 5/12 :  y − 2 = (5/12)(x + 12)  →  ▶ y = (5/12)x + 7   (일반형 5x − 12y + 84 = 0)
- m = −5/12 :  y − 2 = −(5/12)(x + 12)  →  ▶ y = −(5/12)x − 3   (일반형 5x + 12y + 36 = 0)

**문제 3. 접점 P — 방법 A (대입 → 중근, 교과서 표준)**
- 기울기가 양수인 조명 케이블 y = (5/12)x + 7을 원의 방정식에 대입한다.
- (x − 1)² + ((5/12)x + 7 − 2)² = 25
- → (x − 1)² + ((5x + 60)/12)² = 25
- 양변에 144를 곱하면  144(x − 1)² + (5x + 60)² = 3600
- 전개하여 정리하면  169x² + 312x + 144 = 0
- → (13x + 12)² = 0   (접하므로 **중근**)
- → x = −12/13,  y = (5/12)(−12/13) + 7 = 86/13
- ▶ P(−12/13, 86/13)

**문제 3. 접점 P — 방법 B (수선의 발, 계산이 짧다)**
- 접점 P는 **원의 중심 C에서 접선에 내린 수선의 발**이다. (접선 ⊥ 반지름 CP)
- 접선에 수직인 직선의 기울기는 −12/5 이고 C(1, 2)를 지나므로  y − 2 = −(12/5)(x − 1)  →  y = −(12/5)x + 22/5
- 두 직선을 연립:  (5/12)x + 7 = −(12/5)x + 22/5
- 양변에 60을 곱하면  25x + 420 = −144x + 264
- → 169x = −156  →  x = −12/13,  y = 86/13
- ▶ P(−12/13, 86/13)  (방법 A와 일치)

**검산 — P가 원 위에 있는가**
- (−12/13 − 1)² + (86/13 − 2)² = (−25/13)² + (60/13)² = 625/169 + 3600/169 = 25 = 25  ✓

**문제 4. 실제 길이 — 방법 A (두 점 사이 거리)**
- 두 점 A(−12, 2), P(−12/13, 86/13) 사이의 거리는
- AP = √((−12/13 + 12)² + (86/13 − 2)²) = √((144/13)² + (60/13)²) = √(20736/169 + 3600/169) = √144 = 12
- 한 눈금의 실제 길이가 10 m이므로  실제 길이 = 12 × 10 = 120 m
- ▶ 조명 케이블 AP의 실제 길이는 **120 m**

**문제 4. 검산 — 방법 B (접선의 길이, 직각삼각형)**
- 접점 P에서 반지름 CP ⊥ 접선 AP 이므로 △APC는 ∠P = 90°인 직각삼각형.
- A와 C의 y좌표가 같으므로 AC = |1 − (−12)| = 13,  CP = 5
- AP = √(AC² − CP²) = √(169 − 25) = √144 = 12  ✓  (문제 3의 P가 틀려도 이 값은 살아남는다)

## V2 — 1번형 · 수직 배치(A가 C 아래), 삼조 3-4-5

**원형 호수와 나무 데크 길 설계하기**

> 한 도시는 시민 휴식 공간으로 원형 호수와 직선 모양의 나무 데크 길을 만들려고 한다. 이를 좌표평면에 나타냈을 때 원형 호수의 중심은 C(3, 4)이고, 반지름의 길이는 3이다. 또한 좌표평면에서 한 눈금의 실제 길이는 20 m이다. 호수 밖에 있는 정자 A(3, −1)에서 출발하여 호수에 닿는 직선 모양의 나무 데크 길을 만들려고 한다. 데크 길은 호수의 내부를 지나지 않고 호수의 경계와 한 점에서만 만나도록 설계한다. (단, 데크 길의 폭은 생각하지 않는다.)

- 문제 1. 원형 호수의 방정식 — 중심이 C(3, 4)이고 반지름의 길이가 3인 원형 호수의 경계를 나타내는 원의 방정식을 구하시오.
- 문제 2. 나무 데크 길의 방정식 — 점 A(3, −1)을 지나고 기울기가 m인 직선의 방정식을 y + 1 = m(x − 3)이라고 하자. 이 직선이 원형 호수의 경계와 한 점에서만 만나도록, 즉 원형 호수에 접하도록 나무 데크 길을 만들려고 한다.
-   1. 가능한 기울기 m의 값을 모두 구하시오.
-   2. 두 나무 데크 길의 방정식을 각각 구하시오.
- 문제 3. 나무 데크 길과 원형 호수가 만나는 점 — 문제 2에서 구한 두 나무 데크 길 중 기울기가 음수인 나무 데크 길을 선택하자. 이 나무 데크 길과 원형 호수가 만나는 점을 P라고 할 때, 점 P의 좌표를 구하시오.
- 문제 4. 실제 나무 데크 길의 길이 — 점 A에서 문제 3에서 구한 접점 P까지 나무 데크 길을 설치하려고 한다. 좌표평면에서 한 눈금의 실제 길이가 20 m일 때, 설치해야 하는 나무 데크 길 AP의 실제 길이를 구하시오. 풀이 과정과 단위를 함께 나타내시오.

### 풀이

**문제 1. 원의 방정식**
- 중심이 (a, b)이고 반지름의 길이가 r인 원의 방정식은 (x − a)² + (y − b)² = r² 이다.
- 중심이 C(3, 4), 반지름이 3이므로
- ▶ (x − 3)² + (y − 4)² = 9

**문제 2-1. 기울기 m**
- 직선 y + 1 = m(x − 3)을 정리하면  mx − y + (−3m − 1) = 0
- 직선이 원에 접하려면 **원의 중심 C(3, 4)에서 이 직선까지의 거리가 반지름 3과 같아야** 하므로
- |3m − 4 − 3m − 1| / √(m² + 1) = 3
- → |−5| / √(m² + 1) = 3   (m이 사라지고 상수만 남는다)
- 양변을 제곱하면  25 = 9(m² + 1)
- → 9m² = 16  →  m² = 16/9
- ▶ m = 4/3 또는 m = −4/3

**문제 2-2. 두 나무 데크 길의 방정식**
- m = 4/3 :  y + 1 = (4/3)(x − 3)  →  ▶ y = (4/3)x − 5   (일반형 4x − 3y − 15 = 0)
- m = −4/3 :  y + 1 = −(4/3)(x − 3)  →  ▶ y = −(4/3)x + 3   (일반형 4x + 3y − 9 = 0)

**문제 3. 접점 P — 방법 A (대입 → 중근, 교과서 표준)**
- 기울기가 음수인 나무 데크 길 y = −(4/3)x + 3을 원의 방정식에 대입한다.
- (x − 3)² + (−(4/3)x + 3 − 4)² = 9
- → (x − 3)² + ((−4x − 3)/3)² = 9
- 양변에 9를 곱하면  9(x − 3)² + (−4x − 3)² = 81
- 전개하여 정리하면  25x² − 30x + 9 = 0
- → (5x − 3)² = 0   (접하므로 **중근**)
- → x = 3/5,  y = −(4/3)(3/5) + 3 = 11/5
- ▶ P(3/5, 11/5)

**문제 3. 접점 P — 방법 B (수선의 발, 계산이 짧다)**
- 접점 P는 **원의 중심 C에서 접선에 내린 수선의 발**이다. (접선 ⊥ 반지름 CP)
- 접선에 수직인 직선의 기울기는 3/4 이고 C(3, 4)를 지나므로  y − 4 = (3/4)(x − 3)  →  y = (3/4)x + 7/4
- 두 직선을 연립:  −(4/3)x + 3 = (3/4)x + 7/4
- 양변에 12를 곱하면  −16x + 36 = 9x + 21
- → 25x = 15  →  x = 3/5,  y = 11/5
- ▶ P(3/5, 11/5)  (방법 A와 일치)

**검산 — P가 원 위에 있는가**
- (3/5 − 3)² + (11/5 − 4)² = (−12/5)² + (−9/5)² = 144/25 + 81/25 = 9 = 9  ✓

**문제 4. 실제 길이 — 방법 A (두 점 사이 거리)**
- 두 점 A(3, −1), P(3/5, 11/5) 사이의 거리는
- AP = √((3/5 − 3)² + (11/5 + 1)²) = √((−12/5)² + (16/5)²) = √(144/25 + 256/25) = √16 = 4
- 한 눈금의 실제 길이가 20 m이므로  실제 길이 = 4 × 20 = 80 m
- ▶ 나무 데크 길 AP의 실제 길이는 **80 m**

**문제 4. 검산 — 방법 B (접선의 길이, 직각삼각형)**
- 접점 P에서 반지름 CP ⊥ 접선 AP 이므로 △APC는 ∠P = 90°인 직각삼각형.
- A와 C의 x좌표가 같으므로 AC = |4 − (−1)| = 5,  CP = 3
- AP = √(AC² − CP²) = √(25 − 9) = √16 = 4  ✓  (문제 3의 P가 틀려도 이 값은 살아남는다)

## V3 — 1번형 · 수평 배치(A가 C 오른쪽), 음수 기울기 선택, 삼조 6-8-10

**원형 잔디 광장과 자전거 도로 설계하기**

> 한 대학은 캠퍼스 중앙에 원형 잔디 광장과 직선 모양의 자전거 도로를 만들려고 한다. 이를 좌표평면에 나타냈을 때 원형 잔디 광장의 중심은 C(−2, 3)이고, 반지름의 길이는 6이다. 또한 좌표평면에서 한 눈금의 실제 길이는 5 m이다. 광장 밖에 있는 정문 A(8, 3)에서 출발하여 광장에 닿는 직선 모양의 자전거 도로를 만들려고 한다. 도로는 광장의 내부를 지나지 않고 광장의 경계와 한 점에서만 만나도록 설계한다. (단, 도로의 폭은 생각하지 않는다.)

- 문제 1. 원형 잔디 광장의 방정식 — 중심이 C(−2, 3)이고 반지름의 길이가 6인 원형 잔디 광장의 경계를 나타내는 원의 방정식을 구하시오.
- 문제 2. 자전거 도로의 방정식 — 점 A(8, 3)을 지나고 기울기가 m인 직선의 방정식을 y − 3 = m(x − 8)이라고 하자. 이 직선이 원형 잔디 광장의 경계와 한 점에서만 만나도록, 즉 원형 잔디 광장에 접하도록 자전거 도로를 만들려고 한다.
-   1. 가능한 기울기 m의 값을 모두 구하시오.

## V5 — 2번형 · x축 → y = x (예시와 같은 직선), 다른 숫자, 삼조 5-12-13

**조명 케이블의 최소 길이**

> 한 놀이공원에서는 두 원형 회전 놀이기구 C₁, C₂와 두 직선 도로를 따라 야간 조명 케이블을 설치하려고 한다. 설계도에서 두 원은 C₁: (x + 7)² + (y + 1)² = 1, C₂: (x + 4)² + (y − 5)² = 4로 나타내고, 두 직선 도로는 각각 x축과 직선 y = x로 나타낸다. 조명 케이블은 원 C₁ 위의 점 A에서 시작하여 x축 위의 점 P, 직선 y = x 위의 점 Q를 차례로 지나 원 C₂ 위의 점 B까지 연결하려고 한다.

- 조명 케이블을 최소한으로 사용하여 설계하려고 할 때, 필요한 조명 케이블의 최소 길이를 구하는 풀이 과정과 답을 논술하시오. (단, 그림은 문제의 이해를 돕기 위한 예시도이다.)

### 풀이

**① P가 놓인 x축에 대하여 A를 대칭이동**
- 원 C₁ 위의 점 A를 x축에 대하여 대칭이동한 점을 A′이라 하자.  [x축 대칭: (x, y) → (x, −y)]
- 점 P는 x축 위의 점이고, x축은 선분 AA′의 수직이등분선이므로  **AP = A′P**

**② Q가 놓인 직선 y = x에 대하여 B를 대칭이동**
- 원 C₂ 위의 점 B를 직선 y = x에 대하여 대칭이동한 점을 B′이라 하자.  [직선 y = x 대칭: (x, y) → (y, x)]
- 점 Q는 직선 y = x 위의 점이므로 같은 이유로  **QB = QB′**

**③ 꺾인 길을 곧은 길로**
- AP + PQ + QB = A′P + PQ + QB′ ≥ **A′B′**
- (두 점을 잇는 가장 짧은 길은 선분. 등호는 P, Q가 선분 A′B′ 위에 이 순서로 놓일 때)

**④ 대칭이동한 원(점)의 방정식**
- A가 원 C₁ 위를 움직이므로 A′은 원 C₁을 x축에 대하여 대칭이동한 원  C₁′: (x + 7)² + (y − 1)² = 1  (중심 C₁′(−7, 1), 반지름 1) 위를 움직인다.
- B가 원 C₂ 위를 움직이므로 B′은 원 C₂를 직선 y = x에 대하여 대칭이동한 원  C₂′: (x − 5)² + (y + 4)² = 4  (중심 C₂′(5, −4), 반지름 2) 위를 움직인다.
- (원의 대칭이동 = 중심만 대칭이동, 반지름은 그대로)

**⑤ 두 원 위의 점 사이의 최소 거리**
- C₁′C₂′ = √((−7 − 5)² + (1 + 4)²) = √(144 + 25) = √169 = 13
- 13 > 1 + 2 이므로 두 원은 서로 밖에 있다. **점에서 원 위의 점까지 거리의 최솟값 = (중심까지의 거리) − (반지름)** 을 두 번 쓴다.
- A′을 고정하면 B′이 원 C₂′ 위를 움직이므로  A′B′ ≥ A′C₂′ − 2
- A′이 원 C₁′ 위를 움직이므로  A′C₂′ ≥ C₁′C₂′ − 1 = 13 − 1 = 12
- ▶ A′B′의 최솟값 = 13 − 1 − 2 = **10**   (등호: A′, B′이 선분 C₁′C₂′ 위에 있을 때)

**⑥ 답**
- 따라서 조명 케이블의 최소 길이는 **10** (좌표 단위)

**순서 확인** _(선택)_
- (선택 보강 — 시간이 남으면) 최솟값을 주는 A′(−79/13, 8/13), B′(41/13, −42/13)에 대하여 선분 A′B′은 x축을 P(−23/5, 0)에서, 직선 y = x를 Q(−23/17, −23/17)에서 **차례로** 지나므로 A → P → Q → B 순서의 경로가 실제로 존재한다.
- 이때 A(−79/13, −8/13), B(−42/13, 41/13).

- 5 > 1 이므로 A′은 원 C₂′ 밖에 있고, **점에서 원 위의 점까지 거리의 최솟값 = (중심까지의 거리) − (반지름)** 이므로
- ▶ A′B′의 최솟값 = 5 − 1 = **4**   (등호: B′이 선분 A′C₂′ 위에 있을 때)

**⑥ 답**
- 따라서 로봇의 이동 경로의 최소 길이는 **4** (좌표 단위)

**순서 확인** _(선택)_
- (선택 보강 — 시간이 남으면) 최솟값을 주는 A′(3, −1), B′(−1/5, 7/5)에 대하여 선분 A′B′은 x축을 P(5/3, 0)에서, 직선 y = x를 Q(5/7, 5/7)에서 **차례로** 지나므로 A → P → Q → B 순서의 경로가 실제로 존재한다.
- 이때 A(3, 1), B(7/5, −1/5).
