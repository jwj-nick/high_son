## 1. 1번 풀이 — 원형 생태공원과 산책로

설정: 중심 C(2, 1), 반지름 3, 외부점 A(−3, 1), 눈금 1 = 10 m.

### 1-1. 원의 방정식
중심 (a, b), 반지름 r인 원: (x − a)² + (y − b)² = r².
→ **(x − 2)² + (y − 1)² = 9**
(전개하면 x² + y² − 4x − 2y − 4 = 0. 요구가 없으면 전개하지 않는다. 전개는 실수만 늘린다.)

### 1-2-1. 기울기 m
직선 y − 1 = m(x + 3)을 일반형으로: **mx − y + 3m + 1 = 0**.
직선이 원에 접한다 ⇔ 중심 C(2, 1)에서 직선까지의 거리 = 반지름 3.

  d = |m·2 − 1 + 3m + 1| / √(m² + 1) = |5m| / √(m² + 1) = 3
  25m² = 9(m² + 1) → 16m² = 9 → m² = 9/16
  → **m = 3/4 또는 m = −3/4**

대안(판별식): 직선을 원에 대입해 x에 대한 이차방정식의 판별식 D = 0. 식이 길어 시험에서는 비추천. 접선 조건은 "거리 = 반지름"으로 통일한다.

검산 감각: AC = 5, r = 3이므로 접선 길이는 4(3-4-5). A와 C가 같은 높이(y = 1)이므로 접선의 기울기 = ±(r / 접선 길이) = ±3/4. 실전에서 숫자가 바뀌어도 **A와 C가 수평이면 m = ±r/ℓ, 수직이면 m = ±ℓ/r**가 나온다(ℓ = 접선 길이). 답을 낸 뒤 이걸로 1초 검산. (2026-09-12 리뷰어 지적으로 정정: 처음엔 수직도 ±r/ℓ로 잘못 적었음.)

### 1-2-2. 두 산책로의 방정식
- m = 3/4: y − 1 = (3/4)(x + 3) → **y = (3/4)x + 13/4** (4y = 3x + 13 ⇔ 3x − 4y + 13 = 0)
- m = −3/4: y − 1 = −(3/4)(x + 3) → **y = −(3/4)x − 5/4** (4y = −3x − 5 ⇔ 3x + 4y + 5 = 0)

### 1-3. 접점 P (기울기 양수인 산책로)
접선 y = (3/4)x + 13/4.

**방법 A — 교과서 표준(대입 → 중근).** 원에 대입:
  (x − 2)² + ((3/4)x + 13/4 − 1)² = 9
  (x − 2)² + (3(x + 3)/4)² = 9
  16(x − 2)² + 9(x + 3)² = 144            ← 양변 ×16
  16x² − 64x + 64 + 9x² + 54x + 81 = 144
  25x² − 10x + 1 = 0 → (5x − 1)² = 0 → **x = 1/5** (중근: 접하므로 당연)
  y = (3/4)(1/5) + 13/4 = 3/20 + 65/20 = 68/20 = **17/5**
  → **P(1/5, 17/5)**

**방법 B — 수선의 발(계산이 더 짧다).** 접점 = 중심 C에서 접선에 내린 수선의 발. 접선에 수직(기울기 −4/3)이고 C(2, 1)을 지나는 직선: y − 1 = −(4/3)(x − 2) → y = −(4/3)x + 11/3.
  연립: (3/4)x + 13/4 = −(4/3)x + 11/3 → ×12: 9x + 39 = −16x + 44 → 25x = 5 → x = 1/5, y = 17/5. ✓

**방법 C — 검산 전용(3-4-5).** AP = 4(1-4 참조), 직선 방향은 기울기 3/4 → (4, 3) 방향(길이 5). A에서 4만큼: (4·4/5, 4·3/5) = (16/5, 12/5). P = (−3 + 16/5, 1 + 12/5) = (1/5, 17/5). ✓
원 위 검산: (1/5 − 2)² + (17/5 − 1)² = 81/25 + 144/25 = 225/25 = 9 ✓

권장: 답안에는 **A 또는 B 중 하나**를 쓰고, 마지막에 "원 위 검산" 한 줄을 붙인다. 시험 직전 연습에서 A·B 둘 다 손에 익힌 뒤 본인이 빠른 쪽을 고른다.

### 1-4. 실제 산책로 길이
**방법 A — 두 점 사이 거리.**
  AP = √((1/5 − (−3))² + (17/5 − 1)²) = √((16/5)² + (12/5)²) = √(256/25 + 144/25) = √(400/25) = √16 = **4**
**방법 B — 접선 길이(더 짧고, 문제 3 결과가 틀려도 살아남는다).**
  접점 P에서 반지름 CP ⊥ 접선 AP → △APC는 ∠P = 90°인 직각삼각형. AC = 5(같은 y좌표라 x좌표 차 |2 − (−3)|), CP = 3 → AP = √(AC² − CP²) = √(25 − 9) = 4.
눈금 환산: 한 눈금 = 10 m → **AP의 실제 길이 = 4 × 10 = 40 m**. (단위 m 필수.)

권장: 답안에 A를 쓰고 B로 검산(한 줄). 서술 요구("풀이 과정과 단위")를 만족하려면 거리 공식 식·계산·환산 문장·단위 4가지가 다 보여야 한다.

## 2. 2번 풀이 — 칸딘스키풍 LED 라인 (대칭이동 최단 경로)

설정: C₁: (x − 8)² + (y − 2)² = 4 (중심 (8, 2), r₁ = 2), C₂: (x − 3)² + (y + 4)² = 4 (중심 (3, −4), r₂ = 2).
경로: A(C₁ 위) → P(x축 위) → Q(y = x 위) → B(C₂ 위). AP + PQ + QB의 최솟값.

### 원리 한 줄
"직선 위의 점을 거쳐 가는 경로"는 그 직선에 대해 **한쪽 끝을 대칭이동하면 꺾인 길이 곧은 길로 펴진다.** 경유 직선이 2개면 양 끝점을 **각각 자기 직선에 대해 한 번씩** 대칭이동한다. 끝점이 원 위를 움직이면 원째로 대칭이동하고, 두 원 위 점 사이 최소 거리는 **중심 거리 − r₁ − r₂**.

### 풀이
① **A를 x축에 대해 대칭이동**한 점을 A′. P는 x축 위의 점이므로 x축은 선분 AA′의 수직이등분선 → **AP = A′P**.
② **B를 직선 y = x에 대해 대칭이동**한 점을 B′. Q는 y = x 위의 점이므로 **QB = QB′**.
③ AP + PQ + QB = A′P + PQ + QB′ ≥ **A′B′** (두 점을 잇는 가장 짧은 길은 선분; 등호는 P, Q가 선분 A′B′ 위에 이 순서로 놓일 때).
④ A가 C₁ 위를 움직이므로 A′은 C₁을 x축 대칭이동한 원 **C₁′: (x − 8)² + (y + 2)² = 4** (중심 C₁′(8, −2), 반지름 2) 위를 움직인다. [x축 대칭: (x, y) → (x, −y)]
   B가 C₂ 위를 움직이므로 B′은 C₂를 y = x 대칭이동한 원 **C₂′: (x + 4)² + (y − 3)² = 4** (중심 C₂′(−4, 3), 반지름 2) 위를 움직인다. [y = x 대칭: (x, y) → (y, x)]
⑤ 두 중심 사이 거리 C₁′C₂′ = √((8 − (−4))² + (−2 − 3)²) = √(144 + 25) = √169 = **13**. 13 > 2 + 2 이므로 두 원은 서로 밖에 있다.
   범위 안 사실 **"점에서 원 위의 점까지 거리의 최솟값 = (중심까지의 거리) − (반지름)"**을 두 번 쓴다: A′을 고정하면 A′B′ ≥ A′C₂′ − 2, A′이 C₁′ 위를 움직이므로 A′C₂′ ≥ C₁′C₂′ − 2 = 11. 따라서 A′B′ ≥ 13 − 2 − 2 = 9 (등호: A′, B′이 선분 C₁′C₂′ 위). ("두 원 위 점 사이 최소 거리 = 중심 거리 − r₁ − r₂"를 공식처럼 쓰면 결과는 같지만, 두 원의 위치 관계는 2022 개정 범위 밖이라 이렇게 근거를 대는 편이 완결됨 — 리뷰어 Y2.)
⑥ 따라서 LED 라인의 최소 길이는 **9**.

(선택 보강, 한 줄) 최솟값을 주는 A′(80/13, −16/13), B′(−28/13, 29/13)에 대하여 선분 A′B′은 x축을 (16/5, 0)에서, 직선 y = x를 (16/17, 16/17)에서 **차례로** 지나므로, 실제로 A → P → Q → B 순서로 놓이는 경로가 존재한다. 이때 A(80/13, 16/13), B(29/13, −28/13). (중심을 잇는 선분이 아니라 **A′B′**을 기준으로 말해야 P, Q가 두 점 사이에 있음이 보장된다 — 리뷰어 Y4.)
→ 고1 수준 채점에서 요구하지 않을 가능성이 크지만, 쓰면 논리가 완결된다. 계산이 부담이면 생략.

### 같은 답이 나오는 다른 방법 (선생님 모범답안이 이쪽일 수도 있다)
A를 x축 대칭 → A′, 이어서 A′을 y = x 대칭 → A″. 그러면 A′P + PQ ≥ A′Q = A″Q, A″Q + QB ≥ A″B. C₁은 (8, 2) → (8, −2) → (−2, 8)로 옮겨지고, 중심 거리 √((−2 − 3)² + (8 + 4)²) = √(25 + 144) = 13 → 최솟값 9. 값이 같은 이유: 앞 방법의 (A′, B′) 쌍을 통째로 y = x 대칭이동한 것이 (A″, B)이기 때문. **둘 다 정답**이며, 아들이 이해하기 쉬운 쪽(양 끝점 각각 한 번 대칭)을 기본으로 한다.

### 답안에 반드시 보여야 하는 것
1. 대칭이동 규칙과 대칭이동한 점(원)의 좌표(방정식) — C₁′(8, −2), C₂′(−4, 3).
2. "P가 x축 위의 점이므로 AP = A′P" 같은 **근거 문장**(왜 같은지).
3. 합 ≥ A′B′ 부등식과 등호 조건(한 직선 위).
4. 두 원 밖 조건 확인(중심 거리 13 > 반지름 합 4) 뒤 **점–원 최소 거리를 두 번 적용해 중심 거리 − r₁ − r₂**.
5. 답 **9** (좌표 단위이므로 단위 없음. 1번과 달리 실제 길이 환산이 없다 — 문제에 눈금 정보가 주어지면 환산).

## 5. 감점 포인트 (논술형 채점 관점에서 답안에 꼭 있어야 하는 것)

### 1번
- [ ] 1-1: 표준형 그대로. 중심·반지름을 문장으로 한 번 언급("중심 (2, 1), 반지름 3이므로").
- [ ] 1-2-1: 직선을 **일반형** mx − y + 3m + 1 = 0으로 정리해 보여 준다(거리 공식은 일반형에 쓴다).
- [ ] 1-2-1: 접선 조건을 **문장**으로: "직선이 원에 접하려면 원의 중심에서 직선까지의 거리가 반지름과 같아야 하므로".
- [ ] 1-2-1: 절댓값 방정식 → 양변 제곱 → m = ±3/4 **둘 다**.
- [ ] 1-2-2: 두 직선 **모두** 쓴다. y = mx + b 꼴이든 일반형이든 한 가지로 통일.
- [ ] 1-3: "접하므로 중근" 언급(방법 A) 또는 "접점은 중심에서 접선에 내린 수선의 발이므로"(방법 B). 답 P(1/5, 17/5)를 좌표 형태로.
- [ ] 1-4: 거리 공식 식 → 계산 → "한 눈금 10 m이므로 4 × 10" → **40 m**(단위).
- [ ] 분수·근호 계산 실수 방지: 25x² − 10x + 1, √(400/25) = 4 같은 자리에서 손계산 검산.

### 2번
- [ ] 대칭이동 규칙 명시 + 대칭이동한 원의 **중심 좌표**(방정식까지 쓰면 더 좋음).
- [ ] "P가 x축 위의 점이므로 AP = A′P" — **왜 같은지** 근거 문장(수직이등분선).
- [ ] 부등식 A′P + PQ + QB′ ≥ A′B′ 와 등호 조건.
- [ ] 두 원 밖 조건(중심 거리 > r₁ + r₂) 확인 후, "점–원 최소 거리 = 중심까지 거리 − 반지름"을 두 번 써서 최솟값 = 중심 거리 − r₁ − r₂.
- [ ] 답 9. 단위 없음(문제에 눈금이 없음).
- [ ] 함정: 대칭 순서 뒤바꿈(A를 y = x에, B를 x축에) → 중심 (2, 8)·(3, 4)로 계산하면 √(1 + 16) − 4 ≠ 9. **P가 놓인 직선에 A를, Q가 놓인 직선에 B를** 대칭시킨다는 걸 규칙으로 외운다.
- [ ] 함정: 반지름 빼는 것 잊고 13이라고 답함 / 한쪽만 빼서 11.
