# 책 지도 정본 — 『앵무새 죽이기』 (하퍼 리, 1960 · 열린책들 김욱동 옮김)

> 앱 📖 탭·프린트 팩의 원천. 여기 없는 사실은 앱에 쓰지 않는다.
> ⚠️ 인용은 **책의 실제 문장**으로만 한다. 이 문서의 "뜻" 열은 원문의 취지를 내가 옮긴 것이지 책의 문장이 아니다. 아이가 표시한 쪽 사진이 오면 그 문장으로 교체·확정한다.
> 배경 사실: 1930년대(대공황) 미국 앨라배마의 가상 마을 메이콤. 인종 분리(짐 크로 법) 시대. 화자는 여섯 살에서 아홉 살이 되는 스카웃. 1부 = 1~11장(부 래들리와 마을), 2부 = 12~31장(재판과 그 이후).

## 1. 인물 관계

| 인물 | 누구 | 이 책에서 맡은 자리 |
|---|---|---|
| 스카웃(진 루이즈 핀치) | 화자, 6→9세 | 편견을 아직 배우지 않은 눈. 어른들의 모순을 그대로 드러냄 |
| 젬(제러미 핀치) | 스카웃의 오빠, 10→13세 | 재판을 통해 어른 세계의 불의를 처음 겪음 |
| 애티커스 핀치 | 아버지, 변호사·주의회 의원 | 톰을 변호. "법정 앞의 평등"을 믿는 사람 |
| 캘퍼니아 | 핀치 집의 흑인 가정부 | 두 세계(백인 집·흑인 교회)를 오가는 다리 |
| 딜(찰스 베이커 해리스) | 여름마다 오는 친구 | 재판의 잔인함에 우는 아이(19장) |
| 톰 로빈슨 | 흑인 청년, 왼팔 불구 | 누명 → 유죄 평결 → 탈출 시도 중 사살 |
| 메이엘라 유얼 | 19세, 고발자 | 가난·고립·아버지의 폭력 속에 있는 가해자이자 피해자 |
| 밥 유얼 | 메이엘라의 아버지 | 마을 최하층 백인. 재판 뒤 애티커스·아이들에게 보복 |
| 부(아서) 래들리 | 은둔한 이웃 | 소문 속 괴물 → 아이들을 구하는 사람 |
| 모디 앳킨슨 | 이웃 아주머니 | 아이들에게 애티커스·앵무새의 뜻을 설명 |
| 알렉산드라 고모 | 애티커스의 여동생 | 가문·혈통·"숙녀다움"의 규범 |
| 헥 테이트 | 보안관 | 첫 증인. 결말에서 부 래들리를 지킴 |
| 테일러 판사 | 재판장 | 애티커스를 국선 변호인으로 지정 |
| 길머 | 검사 | 톰에게 모욕적으로 질문 |
| 돌퍼스 레이먼드 | 흑인 여성과 사는 백인 | 마을이 이해할 "이유"를 주려고 술꾼 행세 |
| 사익스 목사 | 흑인 교회 목사 | 발코니에서 아이들과 재판 관람 |
| 언더우드 | 신문 발행인 | 교도소 밤 산탄총으로 애티커스 보호, 톰 사망 사설 |
| 링크 디스 | 톰의 고용주 | 법정에서 톰의 성실함 증언, 재판 뒤 헬렌 보호 |
| 커닝햄 집안 | 가난하지만 자존심 있는 농민 | 교도소 밤의 군중 → 배심원 중 한 명은 처음에 무죄 주장 |
| 듀보스 부인 | 이웃 노부인 | 모르핀을 끊고 죽음 → "용기"의 정의(11장) |
| 게이츠 선생 | 스카웃의 3학년 담임 | 히틀러 비판과 흑인 비하를 동시에(26장) |

## 6. 흔한 오해·사실 점검

- 톰 로빈슨의 죄명은 "성폭행(강간)"이며 실제로는 메이엘라가 먼저 접근했고 아버지 밥 유얼이 이를 보고 딸을 때렸다는 것이 재판에서 드러나는 정황이다.
- 다친 곳은 메이엘라의 **오른쪽** 얼굴 → 왼손잡이의 소행 → 밥 유얼은 왼손잡이, 톰은 **왼팔**을 못 씀.
- 톰은 재판에서 유죄, 항소 준비 중 **교도소 운동장에서 탈출을 시도하다 총에 맞아** 죽음(24장, 17발).
- 배심원단은 **백인 남성**만. 여성은 당시 앨라배마에서 배심원이 될 수 없었다(23장).
- 밥 유얼은 할로윈 밤에 아이들을 습격하다 죽는다(28장). 보안관은 "자기 칼 위에 넘어졌다"로 정리한다(30장).
- 애티커스는 톰의 변호를 **판사에게 지정받았지만** 형식적으로 하지 않고 진짜로 변호하려 했기 때문에 마을의 미움을 산다(16장에서 설명).
- 제목의 'mockingbird'는 흉내지빠귀. 국내 제목이 '앵무새'로 굳어짐.
