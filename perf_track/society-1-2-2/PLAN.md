## 8. STEP2 준비 절차 (compact 뒤 재진입용 — 9/15 밤 ~ 9/16 아침)

**입력(Nick이 세션에 넣는 것):** ① 아들의 답 5개(읽기 전후 변화 / 제일 센 문장 2개 위치 / 떠오른 뉴스·주변 일 / 제일 화난 장면·이유 / 왜 지금도 읽히나) ② 표시한 쪽 **사진**(문장 원문 확보용). 답이 짧거나 일부만 와도 진행한다 — 빈 곳은 책 지도의 추천 조합(Q6+Q7 또는 Q3+Q11)으로 메운다.

**절차(한 단계 = 한 산출물):**
1. 사진을 `inbox/`에 등재(`son_p<쪽>.jpg`)하고 문장을 **원문 그대로** 전사 → `10_prep/03_step2_reference.md` 상단에 "확정 문장 ①②(장·쪽·원문)".
2. 문장마다: 선정 기준(4종 중 하나) → 이유 뼈대(5요소 중 아이 답에서 나온 2~3개를 **아이 말** 기준으로 키워드 사슬) → **연결 문단 재료**(헌법 조항 1개 + 제도·사례 1개, `02_book_map.md` §5에서). 두 문장의 연결 주제가 서로 다르게.
3. 흐름 예시 문단은 **쓰지 않는다**(STEP1과 달리 아이가 직접 읽고 쓴 내용이라 예시가 있으면 베끼기 유혹이 큼). 뼈대와 재료까지만. 단 "연결 문단"의 **형태 예시 한 문장**("이 문장은 헌법 제○조가 보장하는 ○○와 이어진다고 생각했다. 왜냐하면 …")은 둔다.
4. 앱 갱신: `perf_mockingbird.html`의 STEP2 렌더에 "내 문장 재료" 카드(확정 문장 ①② + 뼈대 + 연결 재료)를 추가하고, 노트에 두 문장을 미리 넣어 두는 초기값은 **두지 않는다**(아이가 직접 등록).
5. 프린트: `build_print.py`의 STEP2 카드에 "확정 문장 재료" 상자 추가 → `python build_print.py` → 쪽수 확인(STEP2 2쪽 유지).
