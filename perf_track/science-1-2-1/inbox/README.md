## 2. 교과서 핵심 내용 (p42~49)

### p42 — 산성과 염기성
- 산(레몬·식초)은 **푸른색 리트머스 종이를 붉게**: 산성. 대표 물질 = 염산, 황산, 아세트산.
- 염기(비누·제산제)는 **붉은색 리트머스 종이를 푸르게**: 염기성. 대표 물질 = 수산화 나트륨, 수산화 칼륨, 수산화 칼슘.
- 그림 I-14: 산은 달걀 껍데기(탄산 칼슘)와 반응해 **이산화 탄소 발생**. 염기는 달걀흰자(단백질)를 **녹임**. 산·염기 수용액 모두 **전류가 흐른다**.
- 도입 질문: 생선에 레몬즙 → 비린내 제거는 어떤 화학 반응인가? (→ 중화 반응)

### p43 — 산·염기의 공통 성질의 원인, 이온화, 지시약
- 전기영동 실험(그림 I-15/16): 묽은 염산에 전류 → 푸른 리트머스가 붉게 변한 부분이 **(−)극 쪽으로 이동** → 산성은 **양이온(H⁺)** 때문. 수산화 나트륨 수용액 → 붉은 리트머스가 푸르게 변한 부분이 **(+)극 쪽으로 이동** → 염기성은 **음이온(OH⁻)** 때문.
- 아레니우스 정의: **산 = 물에 녹아 H⁺를 내놓는 물질, 염기 = 물에 녹아 OH⁻를 내놓는 물질.**
- 이온화식:
  - HCl → H⁺ + Cl⁻ / H₂SO₄ → 2H⁺ + SO₄²⁻ / CH₃COOH → H⁺ + CH₃COO⁻
  - NaOH → Na⁺ + OH⁻ / KOH → K⁺ + OH⁻ / Ca(OH)₂ → Ca²⁺ + 2OH⁻
  - (아들 손글씨) H₂CO₃ → 2H⁺ + CO₃²⁻, Mg(OH)₂ → Mg²⁺ + 2OH⁻
- 지시약 4종(사진의 색): 리트머스 종이(산성 붉음/염기성 푸름), **페놀프탈레인**(산성·중성 **무색**, 염기성 **붉은색**), **BTB**(산성 **노랑**, 중성 **초록**, 염기성 **파랑**), 메틸 오렌지(산성 붉음, 중성·염기성 노랑).
- 확인 1·2 (아들 답 정답): (−)극으로 이동 = H⁺, (+)극으로 이동 = OH⁻.

### p44 — 탐구: 산과 염기를 혼합할 때 용액의 변화
- 준비물: **같은 농도**의 염산과 수산화 나트륨 수용액, 페놀프탈레인, 자석 젓개, 뷰렛, 무선 온도 센서.
- 과정: 비커에 염산 20 mL + 페놀프탈레인 2~3방울 → 뷰렛에 NaOH 40 mL → 온도 측정 시작 → 천천히 떨어뜨리며 다 떨어질 때까지 온도 측정.
- (아들 메모) 염산 20 mL 위에 "30mL"라고 씀 → 실제 수업 실험은 30 mL로 했을 가능성.

### p45 — 결과 정리 + 디지털 온도계 실험 표
- 결과 및 정리 3문항: ① 온도 변화 설명 ② 색 변화로 성질 변화 설명 ③ 온도 변화를 성질 변화와 관련지어 설명. (아들 답 ①: "증가하였다가 감소한다")
- 디지털 온도계 실험: 염산 20 mL + 페놀프탈레인, NaOH를 **4 mL씩** 넣으며 온도·색 기록.

| NaOH 부피(mL) | 0 | 4 | 8 | 12 | 16 | 20 | 24 | 28 |
|---|---|---|---|---|---|---|---|---|
| 온도(℃, 아들 실측) | 20.7 | 20.9 | 21.1 | **21.2** | 20.9 | 20.8 | 20.7 | – |
| 색(아들 기록, 판독 불확실) | 무색 | 무색 | 무색 | 핑크? | 핑크 | 핑크 | 핑크 | – |

- ⚠️ 실측 최고 온도가 **12 mL**에서 나옴. 교과서 설정(같은 농도, 염산 20 mL)이면 중화점은 20 mL여야 하므로, 수업에서는 농도가 달랐거나 다른 조건이었을 것. **아들에게 확인 필요** (체크리스트 1번 "중화점 부피" 직결).

### p46 — 중화 반응
- **HCl + NaOH → NaCl + H₂O** (산 + 염기 → 염 + 물). 알짜: **H⁺ + OH⁻ → H₂O**, 1:1로 반응.
- 그림 I-18 (페놀프탈레인 넣은 묽은 염산에 NaOH 첨가) 4단계 입자 모형: H⁺ 2·OH⁻ 0 (산성) → H⁺ 1·OH⁻ 0·물 1 (산성) → H⁺ 0·OH⁻ 0·물 2 (중성) → H⁺ 0·OH⁻ 1·물 2 (염기성).
- ⚠️ 아들 손글씨가 색을 "노랑 → 노랑 → 초록 → (붉?)"으로 적음. 이는 **BTB 색**이고, 그림은 **페놀프탈레인**(무색→무색→무색→붉은색)이다. **지시약 혼동 가능성** (체크리스트 8번 직결).

### p47 — 색 변화 서술 + 중화열 그래프
- 페놀프탈레인 넣은 묽은 염산에 NaOH를 넣으면 H⁺가 점점 줄지만, **H⁺가 모두 반응하기 전까지 산성이라 색이 변하지 않음** → 모두 반응하면 **중성** → 이후 OH⁻ 증가로 **염기성** → **붉은색**.
- 중화 반응이 일어날 때 온도가 높아짐 = **중화열** 발생(발열).
- 그래프 I-19: (가) 중화 반응 동안 계속 중화열 발생 → 온도 상승. **중화점에서 최고**. (나) H⁺가 모두 반응한 뒤에는 NaOH를 넣어도 중화 반응이 없어 중화열이 없고, **온도가 낮은 용액이 가해져 온도가 낮아짐**.
- **중화열은 반응하는 H⁺·OH⁻가 많을수록 더 많이 발생** → 완전히 중화됐을 때 온도 최고.
- 확인: 묽은 염산(H⁺ 1, Cl⁻ 1) + 수산화 칼슘(Ca²⁺ 1, OH⁻ 2) → 물 1 + OH⁻ 1 남음 → **염기성** (아들 답 정답).

## 2-B. 수업 학습지(부교재) 핵심 내용 (p12~15, "02. 중화 반응")

### ws p12 — 1. 산의 성질
- (1) **산 = 물에 녹아 수소 이온(H⁺)을 내놓는 물질.** 예) 염화수소, 황산, 탄산, 아세트산, 질산.
  - HCl → H⁺ + Cl⁻ / H₂SO₄ → 2H⁺ + SO₄²⁻ / H₂CO₃ → 2H⁺ + CO₃²⁻ / CH₃COOH → H⁺ + CH₃COO⁻ / HNO₃ → H⁺ + NO₃⁻ (아들 손글씨, 전부 정답)
  - ※ 화학식에 H가 있어도 물에 녹아 H⁺를 내놓지 않으면 산이 아니다. 예) CH₄
- (2) **산성** = 산의 공통 성질, **수소 이온** 때문에 나타남. 산마다 내놓는 **음이온**이 달라 서로 다른 성질도 나타남.
  - ① 맛: 신맛 ② 전기 전도성: 양이온(H⁺)·음이온으로 나뉘어 전류가 흐름 ③ 금속과 반응: 수소보다 산화하기 쉬운 금속(Mg·Zn·Fe)과 반응해 **H₂ 발생**(산화환원). Mg + 2H⁺ → Mg²⁺ + H₂ / Zn + 2H⁺ → Zn²⁺ + H₂ ④ **탄산칼슘**(CaCO₃, 달걀·조개 껍데기·석회석)과 반응해 CO₂ 발생.
- (3) 이온 확인 실험: 질산 칼륨 수용액을 적신 **푸른색** 리트머스 + 묽은 염산을 적신 실. 질산 칼륨의 역할 = **전해질**(전류가 흐르게 함). 결과: **(−)극 쪽으로 붉은색이 번짐**. (+)극으로 끌려가는 이온 = Cl⁻·NO₃⁻, (−)극으로 = **H⁺**·K⁺. 아세트산으로 해도 같음 → 산성의 원인 = 양이온 **H⁺**.
- (4) 주변 산성 물질: 식초(아세트산 3~6%), 탄산 음료(CO₂+H₂O→탄산), 신맛 과일, 위액.

### ws p13 — 2. 염기의 성질 / 3. 지시약 / 4. pH
- (1) **염기 = 물에 녹아 수산화 이온(OH⁻)을 내놓는 물질.** 예) 수산화나트륨·수산화칼슘·수산화칼륨·**암모니아**.
  - NaOH → Na⁺ + OH⁻ / KOH → K⁺ + OH⁻ / Ca(OH)₂ → Ca²⁺ + 2OH⁻ / **NH₃ + H₂O → NH₄⁺ + OH⁻**
  - ※ OH가 있어도 OH⁻를 내놓지 않으면 염기가 아니다. 예) C₂H₅OH(에탄올). 반대로 암모니아는 OH가 없어도 물에서 OH⁻를 만들므로 염기.
- (2) **염기성** = **수산화 이온** 때문. 염기마다 **양이온**이 달라 다른 성질도 있음. ① 쓴맛 ② 전기 전도성 ③ 대부분의 금속·탄산칼슘과 **반응하지 않음** ④ **단백질을 녹임** → 비누가 미끈거림.
- (3) 이온 확인 실험: **붉은색** 리트머스 + NaOH 수용액 실. 결과: **(+)극 쪽으로 푸른색이 번짐**. (+)극으로 = **OH⁻**·NO₃⁻, (−)극으로 = Na⁺·K⁺. 암모니아수로 해도 같음 → 염기성의 원인 = 음이온 **OH⁻**.
- (4) 주변 염기성 물질: NaOH(비누·세정제), Mg(OH)₂(제산제), NaHCO₃(제빵 소다), Ca(OH)₂(석회수 — CO₂와 반응해 흰 앙금 CaCO₃ 생성, CO₂ 검출: Ca(OH)₂ + CO₂ → CaCO₃ + H₂O).
- **3. 지시약 표** (아들이 채운 것, 전부 정답):

| 지시약 | 산성 | 중성 | 염기성 |
|---|---|---|---|
| 리트머스 종이 | 푸른색→붉은색 | – | 붉은색→푸른색 |
| 메틸 오렌지 | 붉은색 | 노란색 | 노란색 |
| 페놀프탈레인 | 무색 | 무색 | 붉은색 |
| BTB | 노란색 | 초록색 | 파란색 |

- **4. pH**: 수용액의 H⁺ 농도를 0~14 숫자로 나타낸 것. 작을수록 산성 강함, 클수록 염기성 강함. pH<7 산성 / =7 중성 / >7 염기성.

### ws p14 — 5. 중화 반응 / 6. 중화 반응이 일어날 때의 변화
- **5. 중화 반응 = 산과 염기의 수용액이 반응하여 물과 염을 생성하는 반응.**
  - HCl → H⁺ + Cl⁻, NaOH → Na⁺ + OH⁻, 합치면 **HCl + NaOH → H₂O + Na⁺ + Cl⁻**
  - ※ **염** = 중화 반응에서 산의 음이온과 염기의 양이온이 결합해 생성된 물질(NaCl).
  - (1) **알짜 이온 반응식: H⁺ + OH⁻ → H₂O.** 두 이온은 **1:1**로 반응.
  - (2) **중화열** = 중화 반응 때 발생하는 열. 중화 반응은 열을 방출하는 **발열 반응**.
  - (3) **중화점** = 산의 H⁺와 염기의 OH⁻가 모두 반응하여 중화가 완결된 지점.
- **6-(1) 지시약 색 변화 (수업은 BTB 기준):** 묽은 염산에 BTB 1~2방울 후 NaOH를 가하면 처음 **노란색(산성)** → 중화점에서 **초록색(중성)** → (넘기면 파란색). ← 교과서 p46 그림 옆에 아들이 "노랑·초록"이라 쓴 이유가 이것.
- **6-(2) 온도 변화 — A~E 시험관 실험 (같은 농도, 총 부피 20 mL 고정):**

| 시험관 | A | B | C | D | E |
|---|---|---|---|---|---|
| HCl(mL) | 6 | 8 | **10** | 12 | 14 |
| NaOH(mL) | 14 | 12 | **10** | 8 | 6 |
| 용액 색(BTB, 아들 기록) | 파란색 | 파란색 | **초록색** | 노란색 | 노란색 |
| 액성 | 염기성 | 염기성 | **중성** | 산성 | 산성 |

  - 온도 그래프: **C(10:10)에서 최고 = 중화점**, 양쪽으로 갈수록 낮아짐. 같은 농도이므로 부피가 같을 때 완전 중화되고, 반응한 H⁺·OH⁻ 수가 가장 많아 중화열 최대.

### ws p15 — 6-(3) 이온 수의 변화 / 7. 생활 속 이용
- 일정량의 묽은 염산(H⁺ 2·Cl⁻ 2)에 같은 농도 NaOH를 (Na⁺+OH⁻) 한 쌍씩 가할 때, A→B→C→D (아들 표, 전부 정답):

| | A | B | **C (중화점)** | D |
|---|---|---|---|---|
| H⁺ | 2 | 1 | 0 | 0 |
| Cl⁻ | 2 | 2 | 2 | 2 |
| Na⁺ | 0 | 1 | 2 | 3 |
| OH⁻ | 0 | 0 | 0 | 1 |
| 총 이온 수 | 4 | 4 | 4 | 6 |
| 생성된 물 분자 수 | 0 | 1 | 2 | 2 |
| 액성 | 산성 | 산성 | **중성** | 염기성 |

  - 그래프 읽기 포인트: **Cl⁻ 일정**(구경꾼 이온), **Na⁺ 계속 증가**, **H⁺ 감소하다 0**, **OH⁻는 중화점 이후 증가**, **총 이온 수는 중화점까지 일정**(H⁺ 하나 빠지면 Na⁺ 하나 들어옴) **후 증가**, **물 분자 수는 중화점까지 증가 후 일정**, 온도는 중화점에서 최고.
- **7. 생활 속 이용 7사례** (교과서 p48보다 넓음): (1) 위산 과다 → 약한 염기성 제산제 (2) **산성비, 비료 등으로** 산성화된 토양이나 호수 → 염기인 **석회 가루** (3) 생선 비린내 → 레몬의 **시트르산** (생선 손질 후 도마를 식초로 닦는 것도 같은 원리) (4) 충치 원인 산성 물질 → 치약의 염기성 물질 (5) **벌에 쏘였을 때 → 암모니아수** 약 (6) 산성비 원인 **이산화 황** → 배출 전 **산화 칼슘**과 반응 (7) 묵은 김치 신맛 → **제빵 소다**.

### wb p072 — 완자쌤 비법 특강: 중화 반응에서 이온 수와 생성된 물의 양 변화
- 설정: 묽은 염산 50 mL에 NaOH 수용액을 조금씩 넣으며 최고 온도 측정. A = NaOH 25 mL, **B = 50 mL(최고 온도 = 중화점)**, C = 100 mL.
- 풀이 절차 6단계 (서술형 답안의 뼈대로 그대로 쓸 수 있음):
  1. 최고 온도가 가장 높은 B에서 중화 반응이 완결 → B가 중화점.
  2. 중화점에서 염산 50 mL와 NaOH 50 mL가 반응 → **1:1 부피비**로 반응.
  3. H⁺와 OH⁻는 1:1 개수비로 반응하므로, 염산 50 mL의 H⁺ 수 = NaOH 50 mL의 OH⁻ 수.
  4. B에서 생성된 물 분자 수를 2N이라 두면, 염산 50 mL의 H⁺·Cl⁻는 각 2N, NaOH 50 mL의 Na⁺·OH⁻는 각 2N. A는 25 mL씩 반응 → 물 N. C는 중화점 이후 반응 없음 → 물 2N(B와 같음).
  5. 표:

| 구분 | A (25 mL) | B (50 mL, 중화점) | C (100 mL) |
|---|---|---|---|
| H⁺ | N | 0 | 0 |
| Cl⁻ | 2N | 2N | 2N |
| Na⁺ | N | 2N | 4N |
| OH⁻ | 0 | 0 | 2N |
| 전체 이온 수 | 4N | 4N | 8N |
| 생성된 물 분자 수 | N | 2N | 2N |

  6. 그래프 3종 읽기: **각 이온** — H⁺가 없어지고 OH⁻가 나타나기 시작하는 B가 중화점. **전체 이온 수** — 중화점까지 일정(H⁺ 감소분만큼 Na⁺ 증가, Cl⁻ 일정)하다가 중화점 이후 증가. **물 분자 수** — 증가하다가 일정해지는 B가 중화점.
- Q1 A~C 생성된 물의 양 비교 → **A < B = C**. Q2 BTB 색 → **A 노란색, B 초록색, C 파란색**.

## 3. 사진에서 드러난 준비 포인트 (첫 진단, 학습지·문제집 반영 후 갱신)

1. **중화점 부피 계산**(체크리스트 1) — 문제 유형이 셋으로 갈린다. ⓐ 교과서 p45·p47: 일정량 산에 염기를 넣어 가는 적정형(온도 최고점 = 중화점), ⓑ 학습지 p14: 총 부피 고정 A~E 시험관형(같은 농도면 부피가 같은 C가 중화점), ⓒ 교과서 p49: (가)(나)(다) 부피 조합형(반응한 이온 수 = 작은 쪽 부피). 세 유형 모두 "같은 농도면 같은 부피가 1:1 반응"이라는 하나의 원리로 풀린다는 것을 서술로 쓸 수 있어야 한다. 단, p45 아들 실측은 12 mL에서 최고였으므로 **수업 실험 조건(농도·부피)은 아들에게 확인 필요**.
2. **혼합 용액의 액성**(체크리스트 2) — 학습지 p15 이온 수 표가 그대로 출제 후보. "남은 이온이 H⁺면 산성, 없으면 중성, OH⁻면 염기성"을 이온 수 세기로 근거를 붙여 쓰는 연습. **문제집 14번을 틀린 것으로 보이는데**(ㄷ: (가)의 남은 H⁺ = 40−20, (다)의 남은 OH⁻ = 40−20), 원인은 "남은 이온 수 = 큰 쪽 부피 − 작은 쪽 부피"를 숫자로 계산하는 단계를 건너뛴 것. 이 계산이 체크리스트 1·2번의 공통 뿌리다.
3. **지시약**(체크리스트 8) — 처음에 p46 손글씨(노랑·초록)를 혼동으로 봤으나, 학습지 p14가 BTB 기준으로 가르쳤고 p13 지시약 표는 아들이 정확히 채웠다. 따라서 혼동이 아니라 **"어느 지시약을 썼는지 밝히고 그 색으로 액성을 판단"하는 서술 습관**이 과제다. 페놀프탈레인(무색→붉은색)과 BTB(노랑→초록→파랑) 두 가지를 모두 문장으로 쓸 수 있어야 한다.
4. **열 출입 + 근거**(체크리스트 3·4) — 답은 "발열(중화열)". 근거는 ⓐ 온도 측정 데이터(중화점까지 상승) ⓑ 중화점 이후 하강 이유(반응 없음 + 낮은 온도 용액 추가) 두 단계로.
5. **생활 속 사례**(체크리스트 5·6·7) — 교과서 6 + 학습지 7 = 사례마다 "산성 물질 / 염기성 물질 / 왜 쓰는가" 3칸을 채우는 형태로 정리하면 세 항목이 한 번에 해결된다.
6. **반응식**(체크리스트 9) — 분자식(HCl + NaOH → NaCl + H₂O), 이온식(HCl + NaOH → H₂O + Na⁺ + Cl⁻), 알짜 이온식(H⁺ + OH⁻ → H₂O) 세 가지 층위와 "염"의 정의.
7. **예상 문항의 원형** — 문제집 서술형 19번(부피 조합 → 물의 양 부등호 + 온도 근거)과 20번(치약 → 산·염기 구분 + 중화 까닭)이 체크리스트 9항목 중 7개를 덮는다. 여기에 반응식(9)·지시약(8)을 붙이면 한 세트가 된다. 완자 p072 비법 특강의 6단계 절차는 서술형 답안의 문장 순서로 그대로 쓸 수 있다.
8. **아들 현재 수준(문제집 흔적 기준)** — 객관식 08~16 중 14번 하나만 오답 의심, 나머지 정답. 개념은 잡혀 있고, 약점은 ⓐ 남은 이온 수 계산 ⓑ 지시약을 명시한 서술 두 가지로 좁혀진다.
