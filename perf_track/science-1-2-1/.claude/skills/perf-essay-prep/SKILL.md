# perf-essay-prep — 논술형 체크리스트 대비

## 언제 쓰나
학교가 **채점 체크리스트를 미리 공개**하고, 답안을 **손으로 서술**하는 수행평가. 계산·자료해석이 섞여 있어도 최종 형태가 서술이면 이 스킬. (계산 시험 = `se-perf-study-app`, 보고서 = `se-perf-eval-step`, 인물 = `se-perf-eval-person`)

## 목적함수
**체크리스트 항목마다 요구 키워드가 들어간 완전한 문장을 아이가 손으로 쓸 수 있게 한다.** 개념 애니메이션·넓은 범위 문제은행은 목적이 아니다.

## 입력
- 안내문 체크리스트(항목 번호·문구 그대로).
- 정본 색인(`inbox/README.md`): 교과서·학습지·문제집에서 옮긴 내용 + 아이의 풀이 흔적(약점 근거).

## 산출물과 순서 (한 단계 = 파일 하나, 만들고 나서 다음)

### 1. `10_prep/01_answer_keys.md` — 모범답안 정본
항목마다:

```
## 항목 N — <체크리스트 문구>
- 대표 문항 (이 항목을 묻는 소문항 예시 2개)
- 모범 문장 틀 (한 문장~세 문장, **키워드 굵게**)
- 필수 키워드 (채점표에 들어갈 것, 3~5개)
- 감점 포인트 (아이 흔적에서 뽑은 실제 실수 + 일반적 실수)
- 변형 표현 (같은 뜻을 다르게 묻는 경우)
```

- 키워드는 교과서 문장에서 가져온다. 교과서에 없는 용어로 채점표를 만들지 않는다.

### 2. `10_prep/02_mock_bank.md` — 모의 은행
- 시나리오 = 자료에서 실제로 본 실험 형태(예: 적정 표형 / 총 부피 고정형 / 부피 조합 그래프형). 시나리오마다 소문항을 체크리스트 항목에 **1:1 대응**시켜 만든다.
- 소문항마다: 문항 / 배점 / 모범답안 / 키워드 채점표(체크박스) / 부족 시 돌아갈 카드 번호.
- 숫자는 정본 자료의 실제 수치를 우선 쓰고, 아이 확인이 필요한 조건(수업 실험 조건)은 `04_questions`에 질문으로 남기고 보정 예정 표시.

### 3. `10_prep/03_ion_drill.md` — 약점 드릴 정본
- 아이 흔적에서 확인된 약점만. 10문 안팎, 즉시 채점 가능한 단답. 풀이는 "계산 절차" 한 줄.
- 부수 표(지시약 표, 생활 속 사례 표 등)도 여기에.

### 4. `10_prep/04_questions_for_son.md` — 아이 질문지
- **매우 구체적으로**: 무엇을, 왜 묻는지, 답 예시, 답 적는 칸. 아이가 답하면 모의 숫자를 어떻게 바꿀지도 적는다.
- 같은 질문을 앱 📋시작 탭과 프린트 팩 마지막 장에 넣는다.

### 5. 과목 검산
- `se-agent-app-reviewer`에 1~3 정본을 넘겨 사실 오류·범위 밖 개념·키워드 부정확을 잡는다. 🔴 0이어야 다음 단계.

### 6. `90_output/print_pack.html` — 프린트 팩
- `@media print` + `page-break-before`. 순서: 카드 → 모의 1~N 문제 쪽 → (별도 쪽) 답안·채점표 → 드릴 → 표 → 질문지.
- 답안 쪽을 문제 쪽과 분리해 아이가 문제만 먼저 보게 한다.

### 7. `10_prep/app/<name>.html` — 자가채점 앱 (단일 HTML)
- 바닐라, 빌드 없음, **Canvas·KaTeX 없음**(첨자는 유니코드). SVG·DOM만.
- 탭: 📋시작(정보·일정·질문 카드+[복사]) · 🃏카드(플립) · 🧪실험실(SVG 시뮬, 있으면) · ⚡드릴(랜덤 생성·즉시 채점·되풀이) · 🎨부수 표 퀴즈 · ✍️모의(타이머 → 종이 → 점진 공개 → 키워드 체크 → 점수 → 카드로) · 🌱사례 · ✅전날 점검.
- 점진 공개: 문제 먼저, 모범답안은 버튼으로, 키워드는 체크박스로 아이가 스스로 표시.
- localStorage 키 prefix 통일. 전송 UI 없음(질문 답은 [복사] → 카톡).
- 모바일: viewport, 고정 px 금지, 터치 44px, `@media (max-width:640px)`, breadcrumb nav.

### 8. 게이트 → 배포
1. 인라인 JS `node --check`  2. innerHTML `<`+알파벳 스캔  3. 모바일 규약  4. app-reviewer 🔴 0.
5. 배포: `high1/<subject>/<N>sem_perf_<topic>.html` + `index.html` 카드 → public·private 두 리포 push(네트워크 명령은 단독으로).

### 9. 피드백 반영
- Nick이 세션에 넣어 준 아이 답을 `SESSION_LOG.md`에 원문으로 남기고 → `02_mock_bank.md` 숫자·조건 보정 → 앱·프린트 재생성 → 재배포.

## 금지
- 정본 없이 앱에 즉흥 작성. 범위 밖 개념. 교과서에 없는 채점 키워드. 아이 취미·진로 억지 연결.
