# hist-start — 재진입

## 절차
1. `inbox/README.md`를 읽는다 (자료 정본. §2에 새 사진이 등재됐는지, 등재 안 된 사진이 폴더에 있는지 `ls inbox`로 대조).
2. `SESSION_LOG.md` 마지막 라운드를 읽는다 (Nick의 마지막 지시와 Claude의 마지막 약속).
3. `PLAN.md` §3 산출물 표의 ⬜/🟡 항목과 §5 라운드 계획을 대조해 **현재 라운드**를 정한다. §7 열린 질문 중 닫힌 것이 있으면 상태를 갱신한다.
4. `git status`·`ls 10_prep 90_output`으로 디스크 실측 (로그와 어긋나면 디스크가 진실).
5. 브리핑 3줄: 현재 라운드 / 이번에 만들 산출물 / Nick 확인 지점 여부. **채팅 안에서 자기완결**(문항은 원문으로, 파일 요지는 붙여서; 번호·파일명만으로 지칭하지 않는다).
6. Nick 확인 지점(`PLAN.md` §5)이 아니면 **묻지 않고** `hist-prep` 절차대로 진행한다. 확인 지점이면 질문만 간결히.

## 금지
- 정본(`10_prep/*.md`) 없이 앱·프린트에 콘텐츠를 즉흥 작성하는 것.
- `inbox/`·`00_notice/` 파일 수정.
- 라운드 3 이후 Nick에게 "진행할까요?"를 묻는 것 (확인 지점 2곳 제외).
- 아들에게 질문·사진을 요구하는 설계. 필요한 정보는 Nick에게 묻는다.
