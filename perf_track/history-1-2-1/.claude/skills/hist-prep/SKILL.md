# hist-prep — 독서 논술형(문항 사전 공개 · closed-book · 원고지) 대비 절차

## 언제 쓰나
논술 **문항이 미리 공개**되고, 책 한 권(또는 한 장)을 읽은 뒤 **자료 없이 외워서 원고지 분량 안에 손으로** 쓰는 수행평가. (세부 체크리스트형 = 과학 `perf-essay-prep`, 넓은 핵심 질문형 = 사회 `soc-prep`, 계산 = `se-perf-study-app`, 인물 조사 3앱 = `se-perf-eval-person`)

## 목적함수
**문항마다 사실이 정확하고 이유가 붙은 260~290자 답안을 아이가 외워서 제한 시간 안에 원고지에 손으로 쓸 수 있게 한다.** 논술 실력 향상이 아니라 **완성된 답안의 재현**이 목표다.

## 입력
- `00_notice/notice.md` 문항 원문·배점·기본점수·분량·시간·감점 조항.
- `inbox/README.md` 책 정보 + 아이가 표시한 쪽 사진(인용 문장 정본) + 아이 인터뷰 답(`SESSION_LOG.md` 원문).

## 산출물과 순서 (`PLAN.md` §3와 같다. 한 단계 = 파일 하나)

### P1 `10_prep/00_reading_guide_for_son.md` — 읽기 가이드 (아이가 책을 읽기 전에)
카톡으로 보낼 본문 한 덩어리. 문항 3개를 머리에 두고 읽기 → 인상 깊은 문장 3~5개 표시·사진 → 다 읽고 질문 5개(요약·장면·느낌·진로 연결 유무·쪽 범위)에 한 줄 답. 시대 범위 주의 한 줄.

### P2 `10_prep/01_chapter_digest.md` — 책(장) 정리 정본
장 제목이 던지는 물음의 답(핵심 주제 사슬) → 연표(**시험 시대 범위 안 사건에 ■ 표시**) → 인물 관계 → 교과서 용어·흔한 혼동 → 평가가 갈리는 지점(중립) → 문항별 재료 배분. 통설로 초안을 쓰되 "책 대조" 열을 두고, 아이 사진이 오면 **책의 서술·표현을 우선**해 확정한다.

### P3 `10_prep/02_answer_keys.md` — 답안 정본
문항마다 이 순서로:
```
## 문항 N — <원문> (배점 / 기본점수)
### 1) 문항 분해      요구 동사(서술·소개·이유) → 답이 가져야 할 부분(예: 주제 제시 → 근거 사실 2개 → 이유 → 마무리)
### 2) 채점 포인트 추정 변별 점수가 어디서 갈리는지 3~4개 (분량·사실·이유·구체성)
### 3) 뼈대           키워드 사슬 5줄 (이걸 외우면 A를 재구성할 수 있어야 한다)
### 4) 모범답안 A     만점형 270~290자(공백 포함). 첫 문장에 책 제목+장 제목(문항 1만). 키워드 굵게
### 5) 모범답안 B     압축형 220~240자. 시간이 밀릴 때
### 6) 글자 수        A·B 각각 공백 포함/제외 실측값 (Python len()으로 검산)
### 7) 사실 체크      A·B에 나온 연도·인물·지명이 01_chapter_digest에 있는지 하나씩 ✔
### 8) 감점 포인트    분량·시대 범위 밖 중심·사실 오류·이유 없음·억지 연결
```
- 문항 1: 각도 2개(제목의 물음에 답하는 주제 / 봉오동의 역사적 의미). 아이가 고른다.
- 문항 2: 아이가 표시한 문장 중 2개. **인용은 사진 원문 그대로**, 원문이 없으면 "장면 소개"형으로 쓰고 문장 인용은 나중에 교체.
- 문항 3: 아이 인터뷰 각도 1 + 진로 무관 각도 2(선택·전문성·기억). **아이가 "연결 없음"이라 하면 억지로 잇지 않는다.**
- 글자 수 기준: 공백 포함 260~290 → 공백 제외도 200 이상이 되게. 두 방식 어느 쪽으로 세어도 범위 안.

### P4 `10_prep/03_honest_guide.md` — 솔직한 가이드 (앱 📋 탭 원문)
채점 구조 해부(기본점수 → 변별 점수) / 감점 함정 5개 / 45분 배분표(문항당 13분 + 예비 6분) / 원고지 규칙(띄어쓰기·문장부호 한 칸, 첫 칸 들여쓰기) / 암기법(뼈대 → 문장, 하루 10분 × 3일) / 시험장 요령(쓸 순서, 글자 수 세는 법, 수정테이프). 아이에게 말하는 톤, 과장·훈계 없음.

### P5 `10_prep/04_fact_quiz.md` — 사실 퀴즈 정본
12~15문, 답안에 실제로 등장하는 연도·지명·인물·주체만. 혼동 지점(봉오동/청산리, 자유시 참변 주체, 강제 이주 주체, 대한 독립군/한국광복군) 집중. 해설 한 줄.
