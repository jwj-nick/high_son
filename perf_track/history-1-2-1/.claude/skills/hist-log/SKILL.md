# hist-log — 라운드 기록

## 규칙
- Nick의 발화는 **원문 그대로**(오타 포함) 인용 블록으로 남긴다. 요약·정정 금지.
- 아들의 답(카톡 등)을 Nick이 옮겨 주면 그것도 **원문 그대로** 남긴다 — 문항 2·3 답안의 근거가 된다.
- Claude 답변은 **전문**을 남긴다. 사용자에게 보내는 텍스트와 로그의 텍스트가 같아야 한다.
- 답하기 **전에** 로그를 먼저 쓴다.

## 절차
1. `SESSION_LOG.md` 끝에 다음 틀을 추가한다.

   ```
   ---
   ## 라운드 N — <한 줄 제목> (YYYY-MM-DD)
   ### Nick (원문)
   > (원문)
   ### 아들 (원문, 있으면)
   > (원문)
   ### Claude 답변 (전문)
   (답변)
   ```

2. 결정이 바뀌면 `PLAN.md` 해당 표 상태(⬜/🟡/✅)와 §8 변경 이력에 한 줄.
3. 열린 질문이 닫히면 `PLAN.md` §7 상태 갱신.
4. 새 사진이 들어왔으면 `inbox/README.md` §2·§3에 등재.
5. `git add SESSION_LOG.md PLAN.md inbox/README.md` + 이번 라운드 산출물 → 커밋 메시지 `perf(hist-1-2-1): 라운드 N — <요지>`.
