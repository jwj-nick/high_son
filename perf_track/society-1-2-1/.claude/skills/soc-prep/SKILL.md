# soc-prep — closed-book 서술형 4문항 대비 절차

## 언제 쓰나
채점 기준이 **넓은 핵심 질문 몇 개**(성취기준 문장)로 미리 공개되고, 시험 시간에 **자료 없이 외워서 손으로 서술**하는 수행평가. (세부 체크리스트형 = 과학 과제의 `perf-essay-prep`, 계산 시험 = `se-perf-study-app`, 보고서 = `se-perf-eval-step`, 인물 = `se-perf-eval-person`)

## 목적함수
**질문마다 필수 키워드가 정해진 순서로 들어간 완전한 답안을 아이가 외워서 손으로 쓸 수 있게 한다.** 개념 애니메이션·넓은 객관식 문제은행은 목적이 아니다.

## 입력
- `00_notice/questions.md` 핵심 질문(원문 그대로), 배점.
- `inbox/README.md` 부교재 정본 + 아이 기입 상태(약점 근거).

## 산출물과 순서 (`PLAN.md` §3와 같다. 한 단계 = 파일 하나)

### ⓪ `10_prep/00_fill_blanks.md` — 빈칸 복원표
아이가 못 채운 빈칸·활동 문항의 정답을 **부교재에 그대로 옮겨 적을 수 있는 문장**으로. 복원한 표현은 부교재 다른 쪽의 용어를 우선 쓰고, 통상 교과서 표현이면 그렇다고 표시.

### ① `10_prep/01_answer_keys.md` — 4대 질문 답안 정본
질문마다 이 순서로:
```
## 질문 N — <원문>
### 1) 질문 분해      요구 동사(비교·분석·탐구·탐색) → 답이 가져야 할 구조(몇 부분, 어떤 순서)
### 2) 암기용 뼈대     키워드 사슬 (번호 매긴 한 줄들). 이걸 외우면 A를 재구성할 수 있어야 한다
### 3) 모범답안 A     만점형. 뼈대 순서 그대로, 키워드 굵게. 부교재 문장에서만 합성
### 4) 모범답안 B     압축형(답안지가 짧을 때). A의 절반 이하
### 5) 채점 키워드     채점표에 들어갈 용어 (부교재에 있는 용어만)
### 6) 감점 포인트     아이 흔적에서 나온 실수 + 일반적 혼동
### 7) 출제 변형       같은 성취기준을 쪼개서 묻는 부분 서술형 예시
```

### ② `10_prep/02_question_bank.md` — 연습 문항 은행
질문마다 6~7문항, 형태를 섞는다: **통째 서술형 / 부분 서술형 / 비교형 / 사례 판별형 / 계산형 / 용어 정의형**. 문항마다:
```
문항 / 배점 / 힌트 1(어느 방향으로 생각할지, 답을 노출하지 않음) / 힌트 2(키워드 목록) / 모범답안 / 채점 키워드(체크박스) / 돌아갈 곳(①의 질문 번호·뼈대 번호)
```
계산형은 부교재의 실제 수치(p60 순편익, p70 예금·적금, p74~75 비교 우위)를 변형해 만든다.

### ③ `10_prep/03_workbook_digest.md` — 부교재 정리 정본
주제 11~16의 표를 **빈칸을 전부 채운 완성본**으로 다시 정리. 아이 답 + ⓪ 복원. 심화 자료는 요지 3줄 + 활동 문항 모범답. 앱 📖 탭과 프린트 팩의 원천이므로 표 구조를 유지한다.

### ④ 검산
`se-agent-app-reviewer`에 ①~③을 넘겨 사실 오류·범위 밖 개념·키워드 부정확을 잡는다. 🔴 0이어야 다음 단계.

### ⑤ `10_prep/app/2sem_perf_economy.html` — 학습 앱 (단일 HTML)
- **정본 md → 앱·프린트는 `10_prep/app/build.py`가 생성한다.** `template_app.html`·`template_print.html`이 껍데기, ①·②·③ md가 데이터. 콘텐츠를 고칠 때는 md를 고치고 `python build.py`를 다시 돌린다(앱·프린트 직접 편집 금지). 파서가 기대하는 md 형식: ① `## 질문 N — …` + `### 1)~7)` 소제목, 뼈대는 번호 목록, 채점 키워드는 `- [ ] `; ② `### Qn-mm [형태 · 배점] 문항` + `- 힌트 1:`/`- 힌트 2:`/`- 모범답안:`/`- 채점 키워드:`/`- 돌아갈 곳:`; ③ `## 주제 N — …`.
- 바닐라, 런타임 빌드 없음, **Canvas·KaTeX 없음**. DOM·CSS만. 데이터는 파일 안 JS 객체(빌드 시 삽입, 즉흥 작성 금지).
- 탭: **📖 부교재 정리**(③, 주제별 접기, 용어 형광) · **⭐ 4대 질문**(①: 뼈대 → [A 보기] [B 보기], 키워드 형광, 뼈대 가리기 토글) · **✍️ 연습**(②: 문항만 먼저 → 한 화면에 버튼 [생각하기 60초] [힌트 1] [힌트 2] [모범답안] → 채점 키워드 체크박스 → 점수 → 틀린 문항 되풀이함, 형태별·질문별 필터, 랜덤) · **✅ 전날 점검**(4대 질문 뼈대를 가린 채 순서대로 재현, 다 되면 완료 표시).
- localStorage 키 prefix `soc_perf_econ_`. 전송 UI 없음(아웃루프 차단 규약). 모바일: viewport, 고정 px 금지, 터치 44px, `@media (max-width:640px)`, breadcrumb nav(← society index).

### ⑥ `90_output/print_pack.html` — 프린트 팩
