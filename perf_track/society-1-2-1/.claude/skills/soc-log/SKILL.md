# soc-log — 라운드 기록

## 규칙
- Nick의 발화는 **원문 그대로**(오타 포함) 인용 블록으로 남긴다. 요약·정정 금지.
- Claude 답변은 **전문**을 남긴다. 사용자에게 보내는 텍스트와 로그의 텍스트가 같아야 한다.
- 답하기 **전에** 로그를 먼저 쓴다.

## 절차
1. `SESSION_LOG.md` 끝에 다음 틀을 추가한다.

   ```
   ---
   ## 라운드 N — <한 줄 제목> (YYYY-MM-DD)
   ### Nick (원문)
   > (원문)
   ### Claude 답변 (전문)
   (답변)
   ```

2. 결정이 바뀌면 `PLAN.md` 해당 표 상태(⬜/🟡/✅)와 §7 변경 이력에 한 줄.
3. 열린 질문이 닫히면 `PLAN.md` §6 상태 갱신.
4. `git add SESSION_LOG.md PLAN.md` + 이번 라운드 산출물 → 커밋 메시지 `perf(soc-1-2-1): 라운드 N — <요지>`. (Nick이 커밋을 원치 않는다고 한 라운드는 add까지만.)
