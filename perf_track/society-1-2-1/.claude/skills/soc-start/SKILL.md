# soc-start — 재진입

## 절차
1. `inbox/README.md`를 읽는다 (부교재 정본 + 아들 기입 상태 진단. 사진은 세부 확인이 필요할 때만 연다).
2. `SESSION_LOG.md` 마지막 라운드를 읽는다 (Nick의 마지막 지시와 Claude의 마지막 약속).
3. `PLAN.md` §3 산출물 표의 ⬜ 항목과 §5 라운드 계획을 대조해 **현재 라운드**를 정한다. §6 열린 질문 중 닫힌 것이 있으면 먼저 반영한다.
4. `git status`·`ls 10_prep 90_output`으로 디스크 실측 (로그와 어긋나면 디스크가 진실).
5. 브리핑 3줄: 현재 라운드 / 이번에 만들 산출물 / Nick 확인 지점 여부.
6. Nick 확인 지점(`PLAN.md` §5)이 아니면 **묻지 않고** 진행한다. 절차는 이 폴더의 `soc-prep` 스킬(`.claude/skills/soc-prep/SKILL.md`)을 따른다. 확인 지점이면 질문만 간결히.

## 이 과제의 특수성
- 채점 기준이 세부 체크리스트가 아니라 **넓은 핵심 질문 4개**(성취기준 문장, 각 5점)이고, 시험은 **자료 없이 외워서 볼펜으로 서술**한다. 그래서 `01_answer_keys.md`는 "질문 분해 → 암기용 뼈대 → 모범답안 A/B" 순서다.
- 아들의 약점은 지식이 아니라 문장화다(`inbox/README.md` §7·§8). 산출물은 손으로 써 보게 하는 쪽으로 기운다.

## 금지
- 정본(`10_prep/*.md`) 없이 앱·프린트에 콘텐츠를 즉흥 작성하는 것.
- `inbox/`·`00_notice/` 파일 수정.
- 부교재 밖 개념을 채점 키워드로 쓰는 것.
