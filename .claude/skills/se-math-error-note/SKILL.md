# se-math-error-note — 수학 오답노트 생성 스킬

> ⚠️ **이 스킬만 쓰면 약점 DB에 기록되지 않는다.** 2026-07-26부터 오답은 `exam_track/_core/weakness_db/`에 누적되고 재출제 일정이 잡힌다.
> **수학 오답 처리 시**: 이 스킬로 노트·앱을 만든 뒤, **`se-error-note`의 §3(원인 진단)·§5(DB 기록)·§6(재출제 스케줄)을 이어서 수행**한다. 그 단계를 빠뜨리면 학습 루프가 끊긴다.
> 수학 외 과목(과학·국어·영어·한국사·사회)은 처음부터 `se-error-note`를 쓴다.

## 인자 형태
```
/se-math-error-note               # 인터랙티브 (문제 번호 물어봄)
/se-math-error-note Q12           # 수학 기본 (과목 생략 시 공통수학1)
/se-math-error-note Q12 수학      # 과목 명시
/se-math-error-note Q12 수학 ④    # 내가 쓴 답까지 명시
```

## 절차

### 1. 정보 수집
- 문제 번호, 과목 (기본: 공통수학1), 내가 쓴 답 (없으면 "미입력")
- 02_text 그룹 파일 Glob으로 찾기: `<과목>-중간/02_text/Q*.md`
- 해당 번호가 포함된 파일 Read하여 문제 원문·조건·선택지·배점 추출
- `⚠️OCR?` 표시가 있으면 issue.md 참조 후 Nick에게 확인 요청

### 2. 오답노트 .md 생성
**파일 경로**: `<과목>-중간/10_오답노트/Q<번호>_<주제키워드>.md`
- 주제키워드: 2~4글자 한국어 (예: 다항식나눗셈, 인수분해, 이차방정식)
- 기존 파일 있으면 덮어쓰기 전 Nick에게 확인

#### 작성 원칙
- 한국어, 친절하되 수학적으로 정확
- 풀이가 틀리면 안 됨 — 검산 단계 필수 포함
- 개념 체크는 예스/노로 자가진단 가능하게
- 비표준 기호 (deg, ∀ 등) 첫 등장 시 한글 설명 병행

### 3. HTML 앱 생성
**파일 경로**: `<과목>-중간/10_오답노트/Q<번호>_app.html`

단일 HTML 파일 + KaTeX CDN. 페이지 구조:

| 페이지 | 내용 |
|---|---|
| Page 0 | 문제 원문 + 🤔 생각 유도 박스 + [단계별 풀이 시작] [한페이지 요약] 버튼 |
| Page 1~N | 풀이 단계별 (§ 풀이의 단계 수만큼) |
| Page N+1 | 한페이지 요약 (핵심 흐름 + 정답 박스 + 틀린 이유 3가지 + 약점 태그) |

**HTML 작성 원칙** — 반드시 [APP_PRINCIPLES.md](APP_PRINCIPLES.md) 준수:
- 단일 파일, 바닐라 JS, CDN KaTeX
- 진행 도트 클릭으로 단계 이동 가능
- 친절한 말투: ~해요, 함께 생각해봐요
- 색상: primary #4361EE, 배경 #eef2ff, card white
- max-width: 700px, 모바일 대응
- 비표준 수학 기호: 첫 등장 시 초록 `.deg-info` 박스로 설명 + 이후 보라색 한글 병행 표기
- 정답은 summary 페이지와 마지막 단계에서만 표시
- **⚠️ page-0 금지 사항** (APP_PRINCIPLES §page-0):
  - 원문에 없는 좌표/수치를 page-0에 표기 금지
  - JSXGraph 슬라이더를 page-0에 배치 금지
  - 그림: 원본 시험지 구도의 정적 SVG 사용 (축 눈금 수치 없음)

**시각화 판단 — `/se-math-figure` 실행 기준** (아래 중 하나라도 해당하면 반드시 실행):

| 조건 | 예시 |
|---|---|
| 원본 시험지에 그림·그래프·좌표 포함 | `![...]`, `[FIG:]` 태그 존재 |
| 함수 그래프 서술 포함 | 꼭짓점, 교점, 접선, 넓이, 최대·최솟값 |
| 파라미터 변화형 탐구 | m, a, k 등이 변하며 도형/점이 이동 |
| 기하·좌표평면 포함 | 삼각형 넓이, 직선·포물선 교점 |

→ **그림 없는 순수 대수 문제라도** 함수·좌표 개념이 핵심이면 math-figure로 page-0 정적 SVG + page-1 JSXGraph 추가 권장.
