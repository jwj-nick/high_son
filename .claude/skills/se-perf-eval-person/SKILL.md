# se-perf-eval-person — 인물 수행평가 3앱 도우미

## 호출 형식

```
/se-perf-eval-person <인물명> <과목> [과제포맷]

예시:
/se-perf-eval-person 정도전 한국사 Q1Q5형
/se-perf-eval-person 류성룡 한국사
/se-perf-eval-person 마틴루터킹 사회
```

## 출력 (3개 HTML 단일 파일)

| 앱 | 파일명 | 모드 |
|---|---|---|
| 가이드 | `<인물>_guide.html` | 밝음 톤 (학습) |
| 모범답안 | `<인물>_model.html` | 보라 등 (명확) |
| 심화 | `<인물>_deep.html` | 네이비·금색 (사색) |

---

## 실행 절차

### 1단계: 인물 데이터 확보

```
수행평가-<과목>/인물_<이름>.md 존재 여부 확인
  있음 → 읽기
  없음 → /se-person-research <인물명> 먼저 실행
```

### 2단계: 과제 포맷 파악

수행평가 안내문 탐색:
```
수행평가-<과목>/안내문.md
수행평가-<과목>/채점기준.md
```

없으면 Nick에게: "채점 기준이 없습니다. 질문 항목을 알려주시면 시작합니다."

### 3단계: 3앱 생성

#### 앱 1 — 가이드 (guide.html)

**색 테마**: 밝음 (민트·파랑 계열)
**목적**: 학생이 스스로 생각하며 작성하는 안내

**구성 탭**:
```
[개요] [인물소개] [Q1~Q5 각 질문별 탭] [글자수 확인]
```

**컴포넌트**:
- 질문별 form-item (글자 수 가이드 + 힌트 접기)
- 교과서 위치 안내 (file-guide)
- 키워드 카드 (ccard 클릭 선택)
- 글자수 카운터 (textarea 실시간)

#### 앱 2 — 모범답안 (model.html)

**색 테마**: 보라 (#8e44ad)
**목적**: 완성 답안 제시 + 채점 기준 확인

**구성 탭**:
```
[개요+채점] [Q1 답안] [Q2 답안] ... [Q5 답안] [핵심 암기]
```

**컴포넌트**:
- 완성 답안 (복사 가능)
- 채점 기준별 자가 체크
- 핵심 개념 암기 체크리스트

#### 앱 3 — 심화 (deep.html)

**색 테마**: 네이비 + 금색 (#2c3e50 + #f1c40f)
**목적**: 더 깊이 생각하는 확장 학습

**구성 탭**:
```
[현대적 의의] [다른 인물 비교] [역사 논쟁] [나라면?] [평생 질문]
```

**컴포넌트**:
- think-box (사색 가이드 질문)
- 비교 매칭 게임 (선 잇기)
- 스토리북 요약
- 내 생각 기록 공간
