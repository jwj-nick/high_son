# se-person-research — 인물 리서치 공통 sub-skill

## 호출 형식

```
/se-person-research <인물명>

예시:
/se-person-research 정도전
/se-person-research 에라토스테네스
/se-person-research 류성룡
/se-person-research 마틴루터킹
```

## 출력

1. `인물_<이름>.md` — 표준 인물 데이터 파일
2. (선택) `인물_<이름>.json` — 다른 skill 파싱용

## 실행 절차

### 1단계: 기존 자료 탐색

```
해당 프로젝트의 수행평가 폴더 스캔:
  수행평가-한국사/ 수행평가-사회/ ...

기존 인물 .md 있으면 → 재사용 + 보완
없으면 → 신규 작성
```

### 2단계: 정보 수집 기준

**신뢰도 등급**:
- ★★★ 교과서, 국사편찬위원회, 한국사데이터베이스, 학술논문
- ★★ 두산백과, 한국민족문화대백과 (다음 확인 필수)
- ★ 위키피디아 (단독 사용 금지 — 교차확인 필수)

**인용 규칙**:
- 출처 불명확한 인용 → `[출처미확인]` 표시
- 교과서 수록 사실 우선

### 3단계: 수행평가 활용 포인트 추출

Q형 질문(예: 정도전 Q1~Q5)에 맞춰 답안 방향 1~2줄 기술.
→ se-perf-eval-person 이 이 섹션을 앱 콘텐츠로 직접 사용.
