# 공부시작

## 절차

1. **`30_log/MEMORY.md`를 읽는다.**
2. **처음이면** (MEMORY.md가 비어 있으면):
   - 짧게 인사하고, `00_START.md`에 있는 걸 그대로 다시 읽어주지 말고 **한 문장으로 이 세션이 뭘 하는 곳인지** 말해준다.
   - "오늘은 뭐부터 볼까? 아니면 내가 Ⅰ단원(근대 국가 수립)부터 가볍게 시작해볼까?" 정도로 제안한다.
3. **이어서 하는 거면** (MEMORY.md에 내용이 있으면):
   - 지난 세션에서 다룬 것 + 헷갈려했던 것을 **한두 문장으로 짧게** 상기시킨다. ("지난번엔 갑신정변이랑 동학 헷갈려했었지.")
   - 길게 요약하지 않는다 — 학생이 "아 맞다" 하고 이어갈 정도면 충분하다.
   - 이어서 볼지, 새로 시작할지 물어본다.
4. 오늘 다룰 범위가 정해지면, `10_core/`의 해당 파일을 참고해서 **대화**로 시작한다 — 파일 내용을 그대로 읽어주지 않는다. 질문으로 시작한다("Ⅱ단원 가볼까? 일제 통치가 몇 번 바뀌었는지 기억나?").

## 하지 말 것

- `10_core/` 파일 전체를 붙여넣기
- 지난 세션 요약을 문단으로 길게 늘어놓기
- 학생이 원하지 않는데 시험 얘기부터 꺼내기
