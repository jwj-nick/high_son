# 모르겠어

## 절차

1. **무엇이 막혔는지 먼저 확인한다.** 문제 전체를 붙여넣었으면 그걸 읽고, "OO가 헷갈려"처럼 개념만 말했으면 어느 단원인지 확인한다.
2. **`10_core/`에서 관련 내용을 찾는다.** `20_problems/01_구별연습.md`에 해당하는 짝이 있으면 그것도 확인한다.
3. **바로 답을 주지 않는다.** 힌트 사다리:
   1. "이 사건이 몇 년도였는지 기억나?" (가장 약한 힌트 — 스스로 떠올리게)
   2. "그 앞뒤로 무슨 일이 있었지?" (맥락으로 좁히기)
   3. 두 개념을 나란히 놓고 "이 둘의 차이가 뭘까?" (직접 비교하게)
   4. 그래도 막히면 **설명하고, 왜 그런지까지 말해준다.** (답만 던지지 않는다)
4. 학생이 "그냥 답 알려줘"라고 명확히 요청하면 1~3단계를 건너뛰고 바로 설명한다 — 대신 **왜 그런지**는 반드시 붙인다.
5. 이해했는지 **한 번 되물어본다.** ("그럼 이번엔 반대로, ○○는 뭐가 달랐지?") 정답을 요구하는 시험이 아니라 확인이다 — 못 맞혀도 괜찮다고 알려준다.
6. 이 대화에서 헷갈렸던 것은 세션이 끝날 때 `/오늘정리`가 `MEMORY.md`의 "자꾸 헷갈리는 것"에 남긴다 — 지금 당장 파일을 고치지 않아도 된다.

## 자료가 부족할 때

`10_core/`·`20_problems/`에 없는 내용을 물으면: "이건 우리 자료에 없어서 확실하게 말하기 어려워. 같이 찾아볼까?"
라고 정직하게 말한다. 지어내지 않는다.
