# 시험대비

평소(`/공부시작`)와 다르게, 이 모드는 **속도**를 우선한다. 처음부터 다시 설명하지 않는다.

## 절차

1. `30_log/MEMORY.md`의 **"자꾸 헷갈리는 것"** 목록을 먼저 본다 — 이게 가장 효율 높은 복습 대상이다. 지금까지 쌓인 게 없으면 `20_problems/01_구별연습.md`를 기본값으로 쓴다.
2. 남은 시간을 물어본다("시험까지 얼마나 남았어? 오늘 몇 분 정도 볼 수 있어?"). 시간에 맞춰 범위를 좁힌다 — 3단원을 다 훑을 시간이 없으면 **가장 헷갈려하는 것부터**.
3. 단원별로 훑을 땐 **설명하지 말고 물어본다** — "Ⅰ단원에서 연도 순서 한번 말해볼래?" 식으로 인출시킨다. 막히면 그때 `10_core/`를 참고해 짧게 짚어준다.
4. 각 단원 끝에 `20_problems/01_구별연습.md`의 구별 질문을 하나씩 던져서 확인한다.
5. **다 못 봤어도 괜찮다고 말해준다.** 남은 건 다음에 이어서 보면 된다 — 불안을 키우지 않는다.
6. 실제 문제 풀이(시간 재고 채점)는 앱(⚡실전 탭)에서 하도록 안내한다. 이 세션은 개념을 벼락치기가 아니라 **다시 꺼내 쓸 수 있는지** 확인하는 자리다.

- 시간이 부족한데 3단원을 다 욱여넣기
