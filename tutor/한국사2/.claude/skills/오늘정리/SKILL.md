# 오늘정리

**이 스킬을 건너뛰면 다음 세션은 오늘 대화를 전혀 기억하지 못한다.** 학생이 끝낼 기미를 보이면 먼저 제안한다.

## 절차

1. 오늘 대화를 돌아보며 스스로에게 정리한다 (학생에게 보여주지 않아도 됨):
   - 오늘 다룬 단원/주제
   - 학생이 **잘 아는 것**으로 확인된 것
   - 학생이 **여전히 헷갈려하는 것** — 구체적으로 (어느 짝을, 어떻게 헷갈렸는지)
   - 다음에 이어볼 만한 것
2. `30_log/MEMORY.md`를 이 형식으로 갱신한다:

```markdown
## 지금까지 알게 된 것
- (단원) 잘 아는 것 — 계속 여기 누적. 이미 있는 항목과 중복되면 합친다.

## 자꾸 헷갈리는 것
- (짝) 어떻게 헷갈렸는지 한 줄. 여러 번 나오면 "N번째"라고 표시.

## 지난 세션들
- YYYY-MM-DD — 오늘 다룬 것 한 줄 요약, 남은 것 한 줄
```

   - **덮어쓰지 않는다.** 기존 내용에 이어 붙인다. "지난 세션들"은 항상 맨 아래에 새 줄 추가(위에서 아래로 시간순).
   - **날짜는 추측하지 않는다** — 확실하지 않으면 학생에게 오늘 날짜를 물어보거나, 환경에서 확인 가능하면 그걸 쓴다.
   - "자꾸 헷갈리는 것"에 이미 있는 짝이 또 나왔으면 지우지 말고 "2번째", "3번째"로 표시한다 — 반복 자체가 정보다(그 짝을 `/시험대비`가 우선순위로 쓴다).
3. 학생에게 **짧게** 오늘 요약을 말해준다(3줄 이내). "오늘 Ⅱ단원 국내외 운동 봤고, 국내/국외 헷갈렸던 거 기록해뒀어. 다음엔 그거부터 다시 확인하자."

## 하지 말 것

- MEMORY.md를 통째로 덮어쓰기 (기존 기록이 사라지면 안 됨)
- 헷갈렸던 걸 "이제 알겠지" 하고 삭제하기 — 실제로 다음에 또 틀릴 수 있다. 지우는 건 학생이 명확히 "이제 확실히 알겠어"라고 여러 번 확인해줬을 때만.
- 정리를 길게 늘어놓기 — 학생에게 보여주는 요약은 3줄이면 충분하다
