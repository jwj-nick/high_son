# Ⅰ. 근대 국가 수립 운동 (1863~1910)

## 큰 줄기

**흥선대원군의 통상 거부 → 개항(1876) → 개화·개혁의 갈등 → 대한제국 → 국권 피탈(1910)**

이 단원을 보는 두 축:
- **어떻게 근대화할 것인가**: 개화(문 열고 배우자) vs 위정척사(지키자) — 이 갈등이 정변·개혁으로 터진다.
- **누가 주도할 것인가**: 정부(갑오개혁) · 지식인(독립협회) · 농민(동학)이 저마다 근대를 향해 움직인다.

## 연표 (꼭 순서로 기억할 것)

대원군(척화비) → **강화도조약(1876)** → 임오군란(1882) → **갑신정변(1884)** → **동학·갑오개혁(1894)** → 을미사변·을미개혁(1895) → **대한제국(1897)** → **을사늑약(1905)** → 군대해산(1907) → **국권 피탈(1910)**

| 연도 | 사건 |
|---|---|
| 1863 | 흥선대원군 집권 (고종 즉위) |
| 1866 | 병인양요 (프랑스) |
| 1871 | 신미양요 (미국) → 척화비 |
| 1876 | **강화도 조약** (개항) |
| 1882 | 임오군란 |
| 1884 | **갑신정변** (3일 천하) |
| 1894 | **동학 농민 운동 · 갑오개혁** |
| 1895 | 을미사변 · 을미개혁 (단발령) |
| 1896 | 독립협회 |
| 1897 | **대한제국 수립** (광무개혁) |
| 1905 | **을사늑약** (외교권 박탈·통감부) |
| 1907 | 헤이그 특사 → 고종 퇴위 → 군대 해산 (정미7조약) · 국채보상운동 |
| 1910 | **국권 피탈** (경술국치) |

## 흥선대원군 — 안으로는 개혁, 밖으로는 빗장

- **개혁**: 비변사 축소(왕권 강화), 양반에게도 군포를 물리는 **호포제**, 환곡 개선한 **사창제**, 붕당의 근거지였던 **서원 대폭 정리**. (부작용: 경복궁 중건에 **당백전** 남발 → 물가 상승)
- **통상 거부**: 병인양요(1866, 프랑스) · 신미양요(1871, 미국)를 겪고, **척화비**를 세워 통상 수교 거부 의지를 밝힘.

## 개항 — 강화도 조약(1876)

일본이 **운요호 사건(1875)**을 일으켜 압박 → **강화도 조약** 체결. 최초의 근대적 조약이자 **불평등 조약**:
- 부산·원산·인천 **3개 항 개항**
- 일본인에 대한 **치외법권(영사재판권)** — 조선이 일본인 범죄를 처벌 못 함
- **해안 측량권**

> 조약 제1조 "조선은 자주국"은 조선을 위한 말이 아니라, **청의 간섭을 떼어내고** 일본이 파고들려는 계산이었다.

## 개화 세력의 세 갈래 (문을 연 뒤 나라를 어떻게 바꿀지)

| | 급진개화파 | 온건개화파 | 위정척사파 |
|---|---|---|---|
| 인물 | 김옥균·박영효·홍영식·서광범 | 김홍집·김윤식·어윤중 | 이항로·기정진·최익현·이만손 |
| 모델 | 일본 메이지 유신 | 청의 양무운동 | 성리학 전통 수호 |
| 방법 | 정치 제도까지 급진 개혁(갑신정변) | 점진적 개혁, 정부 기구로 추진 | 상소·저항 → 뒤에 의병으로 |
| 지향 | 서양 문물·제도 적극 수용 | **동도서기**(우리 정신 + 서양 기술) | 서양·일본 배척, 유교 질서 유지 |

## 정변과 봉기

- **임오군란(1882)**: 신식 군대(별기군) 우대에 반발한 구식 군인의 봉기. 청군 개입 → 이후 청의 내정 간섭 심화.
- **갑신정변(1884)**: 급진개화파(김옥균 등)가 우정총국 개국식을 이용해 정변, **14개조 개혁 정강** 발표. 청군 개입으로 **3일 천하**로 실패. 위로부터의 급진 개혁 시도.
- **동학 농민 운동(1894)**: 고부 군수의 횡포에 **전봉준**이 봉기. 황토현에서 관군 격파, 전주 점령 후 **집강소**를 두고 **폐정 개혁**(신분 차별·부패 척결) 실천. 일본군의 경복궁 점령에 재봉기했으나 **우금치**에서 패배. **반봉건·반외세**의 대표적 아래로부터의 운동.

## 개혁과 대한제국

| 개혁 | 핵심 |
|---|---|
| 갑오개혁(1894) | 군국기무처 중심. **신분제·노비제·과거제 폐지**, 재정 일원화 — 근대적 개혁의 핵심 |
| 을미개혁(1895) | **단발령**·태양력·종두법. **을미사변**(명성황후 시해) 직후라 반발과 의병으로 이어짐 |
| 독립협회(1896) | 서재필 주도. **독립문** 건립, 만민공동회, 헌의6조(자주·민권) |
| **대한제국(1897)** | 고종 황제 즉위. **광무개혁**(구본신참 — 옛것을 근본으로 새것을 받아들임. 지계 발급·식산흥업) |

## 국권 피탈 — 단계적으로 빼앗기다

러일전쟁 승리 후 일본이 조선을 장악:
1. **을사늑약(1905)** — **외교권**을 빼앗고 **통감부** 설치(초대 통감 이토 히로부미)
2. 고종의 **헤이그 특사(1907)** 파견 → 이를 빌미로 고종 퇴위
3. **한일신협약(정미7조약)** — **군대 해산**
4. **1910년 국권 강제 피탈** (경술국치·한일 병합) → 조선총독부 설치, 무단 통치 시작

## 저항 — 두 갈래

- **의병 운동**: 을미(명성황후·단발령 계기) → **을사**(을사늑약 계기) → **정미**(군대 해산으로 해산 군인 합류, 13도 창의군의 서울 진공 시도)로 갈수록 규모 확대.
- **애국 계몽 운동**: 실력을 길러 국권을 회복하자는 흐름. **신민회(1907, 안창호·양기탁)** — 비밀 결사, 대성·오산학교와 자기회사 설립. **국채보상운동(1907, 대구 시작)** — 나랏빚을 국민 성금으로 갚자는 운동.

무기를 든 의병과 실력을 기른 애국 계몽 운동은 방법은 달랐지만 나라를 지키려는 같은 마음 — 국권 상실 후 **독립운동**(무장 투쟁 + 실력 양성)으로 이어진다.

## 자주 헷갈리는 것

- **강화도 조약(1876)** ↔ 다른 조약들 — 강화도 조약이 "최초의 근대적·불평등 조약". 치외법권·해안측량권이 핵심 키워드.
- **갑신정변(1884)** ↔ **동학 농민 운동(1894)** ↔ **갑오개혁(1894)** — 주체가 다르다. 갑신정변=지식인(위로부터, 급진, 실패), 동학=농민(아래로부터, 반봉건반외세), 갑오개혁=정부(제도 개혁, 신분제 폐지 성공).
- **을사늑약(1905, 외교권)** ↔ **국권 피탈(1910, 전체 주권)** — 을사늑약은 외교권만, 완전한 국권 상실은 1910년.
