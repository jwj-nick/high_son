# 한국사2 과외 시작하기

이 폴더는 **한국사2(근현대사)를 도와주는 선생님**이에요. 터미널(명령 프롬프트)을 열고
이 폴더 안에서 `claude` 라고 치면 대화가 시작돼요.

## 뭘 할 수 있어요?

- 근현대사에서 헷갈리는 거 물어보기 (갑신정변이랑 동학이랑 뭐가 다른지, 을미·을사·정미의병 순서 등)
- 앱(⚡실전 탭)에서 틀린 문제 들고 와서 "이거 왜 틀렸어?" 물어보기
- 시험 전에 "여기 자신 없어" 하는 부분 집중적으로 다시 보기
- 그냥 "오늘 뭐부터 볼까?" 하고 맡기기

## 이렇게 치면 돼요

| 이렇게 말하면 | 이런 일이 일어나요 |
|---|---|
| `/공부시작` | 오늘 뭘 할지 같이 정해요 |
| "동학이랑 갑오개혁이랑 헷갈려" | 힌트 주면서 구별해줘요 (바로 답만 주지 않아요) |
| `/모르겠어` | 방금 틀린 문제나 개념을 붙잡고 끝까지 설명해줘요 |
| `/시험대비` | 시험 얼마 안 남았을 때, 약한 곳만 빠르게 훑어요 |
| `/오늘정리` | 오늘 뭘 했는지 저장해요 — **꼭 하고 끝내세요**, 안 하면 다음에 또 처음부터예요 |

## 알아두면 좋은 것

- 이 선생님은 **정답을 바로 안 줄 때가 많아요.** 힌트를 먼저 줘요. 그래도 정말 급하면 "그냥 답 알려줘"라고 하면 바로 알려줘요.
- 여기서 다룬 내용은 `10_core/` 폴더의 검증된 내용을 근거로 해요 — 앱에서 배운 것과 같은 내용이에요.
- 객관식 문제 풀이(점수 매기기)는 폰 앱(⚡실전 탭)이 더 잘해요. 여기는 **"왜?"를 파는 곳**이에요.
- 대화가 파일로 남아서, 다음에 열어도 지난번 얘기를 기억해요. 그래서 끝날 때 `/오늘정리`가 중요해요.

시작해봐요 — `/공부시작` 이라고 쳐보세요.
