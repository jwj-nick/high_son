# tutor/ — 과목별 세션 키트 (Claude Code, 아이 PC용)

> 설계 근거: [`../00_META/LEARNING_DESIGN.md`](../00_META/LEARNING_DESIGN.md) §E "세션 키트 — Tier2를 대신하는 것" (라운드 4, 2026-08-10 확정).
> 진행 상태: [`../00_META/HANDOFF.md`](../00_META/HANDOFF.md) §5.

## 이게 뭔가

Vercel AI 튜터(Tier2)를 대신하는 것. **서버·비용 없이**, 아이 PC의 Claude Code에서 과목별 폴더를 열면
그 과목의 "친절한 과외 선생님"이 된다. 대화가 파일(`30_log/MEMORY.md`)로 남아 **다음 세션이 이어받는다** —
채팅창을 새로 열어도 "지난번에 뭘 헷갈렸는지"에서 시작한다.

## 왜 앱과 따로인가

`subject_hub/`의 단원앱(⚡실전 탭)은 **객관식 채점 + 원인 진단 + 간격 반복**에 강하다.
이 세션 키트는 **"왜?"를 파고드는 대화 + 힌트로 스스로 도달하게 하기**에 강하다. 둘을 하나로 합치면 둘 다 어중간해진다.

```
앱(폰)                    세션 키트(PC, Claude Code)
채점·확신도·간격반복  ←──  "이거 왜 틀렸어?" 물어보기
                      ──→  "왜 그런지" 대화로 이해
```

## 구조 (과목마다 동일)

```
tutor/<과목>/
├── CLAUDE.md          선생님 역할·규칙 — 세션 열면 자동 로드
├── 00_START.md        아이가 처음 읽는 것
├── 10_core/           핵심지식 (검증된 학습앱에서 증류, 창작 없음)
├── 20_problems/        구별 연습 + "진짜 문제 풀이는 앱에서" 안내
├── 30_log/
│   └── MEMORY.md      ⭐ 누적 — 무엇을 알고 어디서 막히고 어디까지 왔나
└── .claude/skills/    /공부시작 /모르겠어 /시험대비 /오늘정리
```

## 정직한 한계

이건 **강제가 아니라 약속**이다. 서버가 없으니 "답 바로 주지 말고 힌트부터" 같은 규칙을 아이가
"그냥 답 알려줘"로 우회할 수 있다. `CLAUDE.md`에 그 우회를 **허용**해 뒀다(단, 답 다음엔 항상 "왜"를 붙이게)
— 적대적 상황이 아니므로 감수할 만한 교환이라고 봤다. 대신 대화가 로그로 남아 부모가 볼 수 있다.

## 현재 상태 — 한국사2가 파일럿

**한국사2 하나만 먼저 만들었다.** 형태를 확인받은 뒤 나머지 과목(통합사회2·통합과학2·공통수학2·공통영어2)에
반복한다 — 설계 문서의 원칙 그대로("형태가 맞는지 확인한 뒤 반복해야 뒤집지 않는다").

| 과목 | 상태 |
|---|---|
| **한국사2** | ✅ 파일럿 완성 — 3단원 핵심지식 + 구별연습 9쌍 + 스킬 4종 |
| 통합사회2 · 통합과학2 | ⬜ 파일럿 확인 후 |
| 공통수학2 | ⬜ 핵심지식 + 유형별 대표문제(적게) 형태로 — 객관식보다 "풀이 과정 설명"이 핵심이라 구조가 조금 다를 것 |
| 공통국어2 · 공통영어2 | ⬜ 단원앱이 없어 **세션 키트가 유일한 축** — `10_core/`가 텍스트/구문 원리 중심이 될 것 |

## 아이 PC로 전달하는 법 (Nick 담당)

1. `tutor/<과목>/` 폴더를 통째로 복사해서 아이 PC로 옮긴다 (USB·클라우드·git 무엇이든).
2. 아이 PC에 Claude Code가 설치돼 있어야 한다(세팅은 Nick 담당 — HANDOFF §6 대기 항목).
3. 아이가 그 폴더에서 터미널을 열고 `claude`를 실행하면 `CLAUDE.md`가 자동 로드된다.
4. 처음 열 때는 `00_START.md`를 보여주거나, 그냥 `/공부시작`부터 치게 하면 된다.

**이 저장소(`70_HighSchool`)와는 독립적으로 동작한다** — 복사해서 가져가면 그 폴더 하나로 완결된다.
다만 `10_core/`의 정본은 여기(`70_HighSchool/tutor/`)이므로, 학습앱 내용이 바뀌면 여기부터 갱신하고 다시 복사한다.
