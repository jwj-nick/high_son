# 0606-B 계획 — 공식카드 단위 + 개념탭 단위·친절·재미 개선

## 요청 (Nick 2026-06-06)
1. **공식카드** 탭에도 단위 명시 (이론깊이처럼 단위 배지).
2. **이론깊이를 본보기로** 삼아 → **중력운동 / 운동량·충격량 / 관성·안전** 탭의
   - 단위를 더 잘 적고
   - 설명을 더 **친절하고 재미있게**.

## 적용 원칙 (이론깊이에서 가져온 패턴)
- **단위 배지** `.ubadge` — 모든 핵심 기호에 [단위] 표기.
- **의미 한 줄** `.meaning` — "이게 무슨 뜻인지" 일상어로.
- **💬 친근 어조** — 비유·생활 예시·가벼운 농담. "~예요/~죠" 체.
- **재미 요소** — 🎯 깜짝 사실(fun fact) 박스, 친숙한 상황 비유.
- 정확성 유지 — 비유로 단순화해도 틀린 말 금지.

## 작업 항목 (탭별)

### ① 공식카드 (tab 4)
- [ ] 각 공식 fcard에 `.ubadge` 단위 추가 (v[m/s], g[m/s²], p[kg·m/s], I[N·s], F[N] …)
- [ ] 각 공식에 의미 한 줄 보강
- [ ] 단위 검산 팁 한 줄 ("단위 안 맞으면 식 틀림")

### ② 중력운동 (tab 1)
- [ ] g·v·s·평균속도·가속도 단위 배지 삽입
- [ ] 친근 비유: 자유낙하="매초 10씩 속도 적립" / 수평투사="앞으로 걸으며 계단 내려가기"
- [ ] 🎯 fun fact: 3초면 시속 약 108 km! / 번지점프·다이빙 연결

### ③ 운동량·충격량 (tab 2)
- [ ] p·I·F 단위 배지 + 의미
- [ ] 친근 비유: 운동량="멈추기 힘든 정도(쇼핑카트 vs 트럭)" / 충격량="얼마나 세게 오래 밀었나"
- [ ] 🎯 fun fact: 달걀 떨어뜨리기·휴대폰 케이스도 같은 원리

### ④ 관성·안전 (tab 3)
- [ ] 질량[kg] 단위 + "관성의 크기" 의미
- [ ] 친근 비유: 관성="하던 대로 하려는 고집" / 버스 쏠림 일상 경험
- [ ] 🎯 fun fact: 우주선은 엔진 꺼도 계속 감(관성) / 안전벨트 의무화 역사
