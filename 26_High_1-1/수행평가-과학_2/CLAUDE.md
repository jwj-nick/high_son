## 4. ⚠️ 앱 만들 때 꼭 신경 쓸 부분 (이 폴더에서 실제로 겪은 것)

### (A) Canvas 고해상도(DPR) — 모바일 필수
- **너비뿐 아니라 높이도 `devicePixelRatio`로 스케일**해야 함. (안 하면 모바일에서 세로로 잘리고 늘어남 — 실제 발생)
- 원본 logical height는 `cv.dataset.h`에 1회 캐시 (재init 때 누적 방지).
- `window.resize`에 활성 탭 sim 재init (화면 회전 대응).
- → 정식 헬퍼는 스킬 `se_perf_study_app`의 `setupCanvas` 스니펫 사용.

### (B) Canvas lazy init — 숨은 탭은 clientWidth=0
- 캔버스 초기화는 **탭이 보여진 뒤**(탭 클릭 핸들러에서) 호출. 페이지 로드 시 미리 그리면 폭 0.

### (C) KaTeX 함정
- `$...$` **안에 한글 금지** → 깨짐. 한글 텍스트는 수식 밖으로, 꼭 넣어야 하면 `\text{한글}`.
- 곱셈·점은 `\times` / `\cdot` 사용 (유니코드 `×`·`·` 지양).
- 로더에 `throwOnError:false` 유지. 첨자 `v_{나중}`는 KaTeX가 CJK 렌더 가능(예외).

### (D) 점진적 공개 (APP_PRINCIPLES)
- 도전/연습 문제는 **문제 먼저**, 풀이는 토글로 숨김. 풀이 단계는 아코디언으로 하나씩.

### (E) 가르치는 콘텐츠 품질
- 공식엔 **단위 배지 + 의미 한 줄** 항상.
- 유도는 직관(넓이/평균) → `[나중: 적분]` 다리. 단순화해도 **틀린 말 금지**.
- 흔한 실수는 **예시 문제 → ❌오답 → ✅정답 → 그림(SVG)** 풀세트로 (말로만 X).

## ★ 멈춤·승인대기 방지 프로토콜 (치명 교훈 — 전 프로젝트 공통, 2026-06-08)

> 한 Bash 명령이 승인 프롬프트에서 **약 11시간 idle**한 사고. **원인(실측):** `~/.claude/settings.json`의 `ask` 목록에 **`curl`·`wget`·`gh` 등 네트워크 명령**이 있어 항상 승인을 묻는다. 이를 다른 작업과 한 명령에 묶으면 사용자 부재 시 **전체가 승인 대기로 멈춘다**. (`defaultMode:default` — YOLO 아님)

1. **네트워크(curl·wget·gh)는 단독·최소 명령으로.** 빌드·파일조작·python과 한 줄에 묶지 말 것 — 묶으면 통째로 승인 대기.
2. **로컬 작업을 먼저 끝내고 커밋한 뒤** 네트워크 호출. 프롬프트가 떠도 이미 한 일은 안전.
3. 가능하면 **WebFetch 도구**로 받기(bash ask-list 우회). curl 필수(바이너리 등)면 사용자 있을 때 모아서.
4. **결과가 안 오면 추론 말고 즉시 멱등 프로브로 실제 상태 측정.** 산출물 부재는 '실행 안 됨'·'승인 대기'·'hang'을 구분 못 한다.
5. **heredoc 금지**(`<<'EOF'`) · **`PYTHONIOENCODING=utf-8` 선제**(cp949 한글 stdout 충돌→결과 손실). 스크립트는 파일로 Write→실행→삭제, grep은 좁게.
