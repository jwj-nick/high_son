## 핵심 철학: 점진적 공개 (Progressive Disclosure)

학생이 스스로 풀어나가는 흐름을 방해하지 않는다.  
**풀이 과정에서 도출해야 할 정보를 문제 페이지에 미리 보여주면 안 된다.**

---

## page-0 (문제 페이지) 원칙

### ✅ 반드시 표시해야 하는 것
- 원본 시험지 문제 텍스트 — **단어·기호 하나도 추가/삭제 금지**
- 선택지 ①~⑤ (객관식의 경우)
- 원본 시험지 그림과 구도가 동일한 **정적 SVG** 또는 원본 JPG
- 배점

### ❌ 절대 표시하면 안 되는 것
| 금지 항목 | 이유 | 잘못된 예 |
|---|---|---|
| 풀이 중 도출해야 할 수치/좌표 | 풀이 흐름 파괴 | "A=(4,0)" — 원문에 없으면 금지 |
| JSXGraph 슬라이더 | 탐구는 풀이 단계에서 | page-0에 슬라이더 배치 |
| 정답 힌트가 되는 공식/변환 | 스스로 발견해야 할 과정 | "S₂-S₁=16m²" — 풀이에서 도출해야 함 |
| 축에 좌표 수치 표기 | 원본 그림에 없는 정보 | JSXGraph 축의 눈금 숫자 |

### 정적 그림 원칙
- 원본 시험지 그림과 레이블·구도 일치
- 좌표값은 **원문에 명시된 것만** 표시 (명시 안 됐으면 라벨만)
- 축 눈금 숫자 표시 금지 (좌표 추측 가능하므로)
- 참조용 대표 위치 (예: m=1)로 고정된 정적 그림

## page-1~N (풀이 페이지) 원칙

### 구조
- 각 페이지 = **하나의 단계** (단계 번호 + 제목 + "왜 이 단계인가" 필수)
- 해당 단계에서 새로 도출한 정보만 공개 — 점진적 공개 유지

### JSXGraph 인터랙티브 허용 기준
- 파라미터(m, a 등)가 변할 때 도형/값이 어떻게 변하는지 탐구할 때
- 해당 단계에서 파라미터를 **처음 도입하는 시점**
- 초기화: `goTo(n)` 호출 시 lazy init — div가 hidden일 때 초기화하면 렌더링 실패

### 흔한 실수 (warn-box) 필수 포함
- 풀이 도중 학생이 실제로 틀리는 포인트

## 요약 페이지 원칙

- 핵심 풀이 흐름 3~5줄 (번호 목록)
- 정답 (큰 글자, answer-box)
- 약점 태그 (tag 요소)

---

## 연습 앱 (practice_app.html) 원칙

### 문제 독립성
- 각 연습 문제는 **독립적으로 풀 수 있어야** 함
- "Q16의 설정에서..." 참조 시 → 소형 참조 이미지 제공 (static, no slider)
- 인터랙티브 요소 금지 (연습은 풀이 능력 측정이 목적)

### 정답 공개 방식
- 정답·힌트는 **탭(정답판) 전환으로만** 공개
- prob(문제판)에는 문제만, ans(정답판)에는 정답+why+검산, sol(풀이판)에는 단계별 풀이

### 난이도 분류
- 🟢 쉬운 (L1~L3): 핵심 개념 하나씩 분리
- 🟡 중간 (M1~M3): 같은 사고 흐름, 다른 형태
- 🔴 어려운 (H1~H3): 확장·융합·역방향

## 검토 체크리스트 (리뷰어용)

### 오답노트 앱 (Qnn_app.html)

**page-0 체크**
- [ ] 원문과 텍스트 일치 (추가/삭제 없음)
- [ ] 풀이 과정에서 도출해야 할 정보가 노출되지 않음
- [ ] 그림이 원본 시험지와 구도/레이블 일치
- [ ] 그림에 좌표 수치 표기 없음
- [ ] 슬라이더/인터랙티브 없음
- [ ] 선택지 포함 (객관식)

**page-1~N 체크**
- [ ] 각 단계에 "왜 이 단계인가" (step-why) 포함
- [ ] 해당 단계에서 처음 도출하는 정보만 공개
- [ ] warn-box (흔한 실수) 포함
- [ ] JSXGraph는 적절한 단계 + lazy init

**요약 페이지 체크**
- [ ] 핵심 풀이 흐름 포함
- [ ] 정답 큰 글자 (answer-box)
- [ ] 약점 태그

### 연습 앱 (Qnn_practice_app.html)
- [ ] L×3, M×3, H×3 (총 9문제)
- [ ] 각 문제에 why (왜 이 문제인가) 포함
- [ ] 정답/힌트는 탭 전환으로만 공개
- [ ] 원본 참조 문제에 정적 참조 이미지 제공
- [ ] 슬라이더 없음
