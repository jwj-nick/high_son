### 1-A. 원자 만들기 (Build an Atom) ⭐⭐⭐

> **직접 링크:** https://phet.colorado.edu/ko/simulations/build-an-atom

**무엇을 배우나:** 양성자·중성자·전자를 직접 드래그해서 원자를 조립 → 전자 껍질 배치 체험

**단계별 사용법:**
1. 위 링크 접속 → 파란 **"웹에서 실행"** 버튼 클릭
2. 화면 왼쪽 파티클 영역에서:
   - **빨간 공** = 양성자 → 원자핵 영역으로 드래그
   - **흰 공** = 전자 → 바깥 껍질로 드래그
3. 오른쪽 패널에서 자동 표시: 원소 이름, 원자번호, 원자가 전자 수 확인
4. **연습 순서:** H(1) → He(2) → C(6) → N(7) → O(8) → Na(11) → Cl(17) 순으로 직접 만들기
5. 상단 **"게임"** 탭 클릭 → 퀴즈 모드: 원소 이름/기호가 주어지면 전자 배치 맞추기

**학습 포인트:**
- K껍질 2개, L껍질 8개 채워지는 것을 눈으로 확인
- 원자가 전자 개수 = 오른쪽 패널 숫자로 즉시 확인
- 게임 탭에서 오답 시 즉각 피드백

---

### 1-B. 분자 구조 (Molecule Shapes)

> **직접 링크:** https://phet.colorado.edu/ko/simulations/molecule-shapes

**무엇을 배우나:** 공유결합으로 형성된 분자의 3D 구조 → 단일/이중/삼중 결합 시각화

**단계별 사용법:**
1. 링크 접속 → "웹에서 실행" 클릭
2. 왼쪽 패널: **"실제 분자"** 탭 → 드롭다운에서 분자 선택
   - H₂O (물): 단일결합 2개, 굽은형
   - CO₂ (이산화탄소): 이중결합 2개, 직선형
   - NH₃ (암모니아): 단일결합 3개, 삼각뿔형
   - CH₄ (메테인): 단일결합 4개, 정사면체형
3. 3D 모형 마우스로 회전 가능 → 결합 구조 확인
4. **"결합 각도"** 체크박스 켜기: 결합 각도 자동 표시

**학습 포인트:** 결합선(—, =, ≡)이 3D로 어떻게 보이는지 확인

## 2. EBS 고등 통합과학 강의

> **공식 사이트:** https://www.ebs.co.kr

**무료 강의 접근 경로:**
1. https://www.ebs.co.kr 접속
2. 상단 메뉴 **"고등"** 클릭
3. 과목 검색: **"통합과학"** 입력
4. "1학기" 또는 "원자" "화학결합" 키워드로 필터

**추천 강의 검색어:**
- `원자 모형 전자 껍질` → 보어 원자 모형 시각화 강의
- `이온결합 공유결합 차이` → 핵심 비교 강의
- `전자 배치 원자가 전자` → 전자 배치 규칙 강의

**활용 팁:**
- 속도 1.5배로 재생 (오른쪽 하단 설정)
- 강의 PDF 자료 다운로드 → 프린트해서 손으로 채우며 복습

## 3. EBSi (수능 학습 포털)

> **공식 사이트:** https://www.ebsi.co.kr

EBS 수능 준비 포털이지만 고1 통합과학 개념 강의도 제공.

**접근 방법:**
1. https://www.ebsi.co.kr 접속
2. **"과목별 강좌"** → **"과학"** → **"통합과학"**
3. 단원: **"물질과 규칙성"** (원자·화학결합 단원)
4. 강의 목록에서 "원자 모형", "화학결합" 검색

**EBSi 추가 기능:**
- **문제은행:** 원자/화학결합 관련 기출 문제 검색 가능
- **오답노트:** 틀린 문제 자동 저장

## 8. 앱 개발 — 시험 후 검토 (5/8 이후)

시험 전에는 기존 사이트 활용이 훨씬 효율적. 시험 후 복습 도구로 아래 아이디어 검토.

### 아이디어 A: 화학결합 분류 퀴즈 (우선순위 1)
- 22종 물질 → 이온/공유/혼합 분류 선택 → 즉시 피드백
- 기존 study-quiz JSON 구조 그대로 재활용 가능
- 개발 시간: 반나절 (데이터만 교체)
- `/quiz-publish 과학-화학결합` 스킬로 즉시 배포

### 아이디어 B: 원자 모형 빌더 (우선순위 2)
- 원소 번호 입력 → SVG 보어 모형 자동 렌더링
- PhET와 유사하지만 교과서 스타일 (2D, 단순)
- 개발 시간: 1~2일
