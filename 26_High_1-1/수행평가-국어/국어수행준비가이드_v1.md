## 1. 영역 A — 진로/관심 분야 연결

> "왜 이 책을 골랐는가"를 진로와 묶어 설명하는 부분. **글의 도입부**에 배치.

### A-① 자신의 진로나 관심 분야를 조건에 맞게 제시함

**축구책 적용:**
- 진로 한 줄 선언: "나는 미래에 **축구 전술 분석가/감독**이 되고 싶다."
- 왜 이 분야인가: 단순히 축구를 잘하는 선수가 아니라, **경기를 읽고 설계하는 역할**에 끌림.
- 구체화: 데이터 분석·전술 설계·선수 배치라는 측면에서 흥미를 느낌.

> ✍️ **쓸 거리 한 단락 분량.** 진로가 막연하면 점수 깎임 — "축구 좋아함"이 아니라 "전술 분석가" 같은 직무명까지.

### A-② 진로/관심 분야와 선정 책의 연관성 설명

**축구책 적용:**
- 『축구전술혁명』은 **축구 전술의 변천사와 현대 전술의 원리를 분석**한 책.
- 곧 내가 되고 싶은 직무(전술 분석)가 다루는 **바로 그 지식 체계**를 정리한 입문서.
- 한준희(KBS 해설위원)가 감수 → 한국 독자·한국 축구 환경에 맞게 보정된 신뢰도 있는 텍스트.

> ✍️ "진로 = X / 책 = X에 대한 것" 이라는 직접 연결 문장이 반드시 들어가야 함.

### A-③ 책이 자신에게 어떤 의미가 있는지 설명

**축구책 적용:**
- 막연히 축구를 "느낌"으로 보던 시야를 **구조와 패턴으로 보는 시야**로 바꿔준 책.
- 관심사를 직업으로 연결하기 위해 **무엇을 더 공부해야 하는지** 알게 해줌(예: 데이터, 영상 분석, 스포츠과학).
- 책을 읽기 전·후 내가 경기를 보는 방식이 어떻게 달라졌는지 **구체적 비교 1문장**.

> ✍️ "재밌었다"로 끝내지 말 것. **변화·영향**을 말해야 ③번 점수 확보.

## 2. 영역 B — 책·자료 탐색 및 재구성

> 책 자체에 대한 정보 + 외부 자료까지 끌어와야 하는 부분. **본문 초반(작품 소개 단락)**에 배치.

### B-① 책의 주제와 작가 정보 탐색·제시

**축구책 적용 — 미리 정리해 둘 정보:**
| 항목 | 내용 |
|---|---|
| 제목 | 축구전술혁명 |
| 저자 | 다쓰오카 아유무(立岡歩) — 일본의 축구 저널리스트/전술 분석가 |
| 감수 | 한준희 — KBS 축구 해설위원, 풍부한 한국·세계 축구 해설 경력 |
| 주제 | 현대 축구 전술이 어떻게 진화해 왔으며, 무엇이 오늘날의 전술을 만들었는가 |
| 분류 | 스포츠 전술·분석서 / 번역서 |

> ✍️ 책 표지·서문·역자 후기에서 정보 추출. 인터넷 사용 금지 기간(시험 시간)에도 **책 안에서 다 찾을 수 있어야 함**.

### B-② 책 내용 요약·설명

**축구책 적용 — 요약 골격:**
1. 축구 전술의 역사적 변천 (예: WM 시스템 → 4-2-4 → 토털풋볼 → 현대 게겐프레싱)
2. 핵심 전술 개념(빌드업·압박·전환·세트피스 등)을 분해 설명
3. 대표 감독·팀 사례를 통해 전술 원리를 입증

> ✍️ **요약은 6~10문장으로 압축**. 줄거리 나열 금지 — "무엇을 다루는가 + 어떤 흐름으로 다루는가" 두 줄로.

### B-③ 책과 관련된 다양한 글·자료를 읽고 유의미한 정보를 골라 재구성

**축구책 적용 — 활용 가능한 외부 자료:**
| 자료 유형 | 예 | 인용 시 점검 |
|---|---|---|
| 신문 칼럼 | 한준희·한겨레·스포탈코리아 등의 전술 분석 칼럼 | 출처·필자 신뢰성 |
| 통계 | 점유율·xG·패스 성공률 등의 경기 통계 (Opta·FBref 등) | 데이터 출처와 정확성 |
| 영상 | UEFA·FIFA 공식 분석 영상, 감독 인터뷰 | 자극적·과장 없는지 |
| 학술 | 스포츠과학·전술 관련 한글 자료 | 근거 충실성 |

> ⚠️ **§2(매체 자료의 비판적 읽기) 6개 점검 질문을 통과한 자료만 인용.** [03_글쓰기_교과서개념.md §2](03_글쓰기_교과서개념.md) 참조.
> ✍️ "수집"이 아니라 "**유의미한 정보만 골라 재구성**"이 키워드. 자료 3개 이상 보고 그중 1~2개를 책의 논지와 묶어 다시 정리.

## 3. 영역 C — 견해 쓰기 본문 ⭐ (가장 중요)

> 6개 항목 중 ⑥번이 글 전체의 **구조 점수**. 나머지 5개는 내용 점수.

### C-① 작품의 내용·작가·작품에 대한 설명

→ B-①·B-②와 일부 겹침. **본문에서 한 번 더 짧게** 짚어주기. (도입부에 1문단)

### C-② 책에서 인상 깊게 읽었던 부분과 그 이유

**축구책 적용 — 후보 장면 (책 읽으면서 미리 표시할 것):**
- "전술이 결과를 결정한 사례 한 장면" (구체적 경기, 시간대까지)
- "특정 감독의 발상 전환이 축구사를 바꿨다는 서술"
- "압박/빌드업 같은 추상적 개념이 실제 그라운드에서 어떻게 작동하는지 설명한 부분"

> ✍️ **인상 깊은 이유**가 핵심. "재밌었다"가 아니라 "이 부분을 읽고 **내 시야가 어떻게 확장됐는지**".

### C-③ 자신의 경험/사회의 일과 책 내용 연결, 현대사회와의 연결점

**축구책 적용 — 연결 후보:**
| 책 내용 | 현대사회/내 경험 연결 |
|---|---|
| 압박·전환의 속도가 결정적 | 현대 사회 = 정보·의사결정 속도가 경쟁력 |
| 데이터 기반 전술 도입 | 모든 산업의 데이터화 (AI·통계 활용) |
| 감독의 리더십·팀 빌딩 | 학교 동아리·팀 프로젝트에서의 역할 분담 |
| 한국 축구의 전술 한계 | 우리 사회가 "결과만"보고 "과정·구조"를 안 보는 문제 |
| 토털풋볼 — 모두가 모든 위치를 소화 | 융합형 인재가 강조되는 현대 직업관 |

> ✍️ **개인 경험 + 사회 현상**을 둘 다 연결하면 만점에 가까움.

### C-④ 제시한 연결점에 대한 타당한 근거나 자신의 설명

→ ③번에서 만든 연결을 **"왜 그렇게 연결되는가"** 한 단계 더 풀이. 예시·통계·다른 사례 1개 더 끌어와서 보강.

### C-⑤ 작품에 대한 종합적 견해 (해석·평가·해결방안·시사점)

**축구책 적용 — 4종 모두 챙기기:**
| 종합 견해 종류 | 축구책에서 |
|---|---|
| **해석** | 이 책은 "전술은 시대의 산물"이라는 메시지를 던진다 |
| **평가** | 한국 독자에겐 한준희 감수가 큰 도움. 다만 일부 일본 J리그 사례는 한국 독자에겐 멀게 느껴짐 |
| **해결 방안** | 한국 축구도 전술의 **언어화·체계화·교육화**가 필요 |
| **시사점** | 모든 분야에서 "직관 → 구조" 로의 전환이 경쟁력의 본질이다 |

> ✍️ 4가지를 다 안 써도 되지만 **2개 이상**은 명시적으로 짚어야 함.

### C-⑥ 내용 전개의 일반적인 원리 + 세부 내용의 조직 및 전개 방법 ⭐⭐

이 항목이 **이번 가이드의 핵심**. 교과서 §3·§4 그대로 적용.

#### (a) 글 전체의 큰 흐름 — §3 일반적 원리 중 **하나** 선택

| 후보 원리 | 축구책에 적용 시 |
|---|---|
| **시간 순서 (순행식)** ⭐ 추천 | "축구 전술이 어떻게 진화해 왔는가" — 가장 자연스러움 |
| 시간 순서 (역행식) | 현대 게겐프레싱부터 → 그 뿌리를 거슬러 올라감 |
| 공간 순서 | 그라운드의 위치별 전술 (수비→중원→공격) — 축구에 잘 맞음 |
| 논리 순서 (연역) | "전술이 결과를 결정한다" 일반론 → 구체 사례로 입증 |
| 논리 순서 (귀납) | 여러 경기 사례 → "전술이 결과를 결정한다" 결론 |
| 논리 순서 (문제-해결) ⭐ 추천 | "한국 축구의 전술 한계 → 책이 제시하는 해법 → 내 시사점" |

→ **추천 조합:** 시간 순서(순행식)를 큰 뼈대로 + 마지막에 문제-해결로 마무리.

#### (b) 문단별 풀이 방식 — §4 세부 전개 방법 **2~3개 섞기**

| 문단 | 내용 | 사용할 세부 전개 방법 |
|---|---|---|
| 1문단 (도입) | 진로 + 책 선택 이유 | (도입부 — 특정 방법 적용 X) |
| 2문단 (작품 소개) | 작가·주제·요약 | **분석** (책을 구성 요소로 쪼개 설명) |
| 3문단 (전술 진화) | 시대별 전술 변천 | **과정** (시간적 절차) + **분류** (전술 유형별 묶기) |
| 4문단 (인상 깊은 부분) | 특정 사례 분석 | **인과** (왜 그 전술이 그 결과를 가져왔나) |
| 5문단 (현대사회 연결) | 점유율 vs 역습 / 직관 vs 데이터 | **비교·대조** |
| 6문단 (시사점·견해) | 한국 축구·내 진로의 의미 | **인과** + (전체 글의 **문제-해결** 마무리) |

→ 이렇게 짜면 §4의 **분석·분류·비교·대조·인과·과정 5종을 모두 활용**하면서도 자연스러움.

#### (c) 본문 마무리에 한 줄 메타 진술 (안전장치)

```
이 글은 시간 순서(순행식)로 축구 전술의 진화를 큰 흐름으로 잡고,
그 안에서 분류·비교·대조·인과·과정의 전개 방법을 활용하여 견해를 풀었다.
```

→ 채점자가 ⑥번을 명확히 인지하게 함. **필수는 아니지만 안 쓰면 점수 누락 위험.**

## 4. 매체 자료 비판적 읽기 — 영역 B와 함께 적용

> 교과서 §2의 6개 질문은 외부 자료 인용할 때마다 점검. **수행평가 글에 인용한 자료가 이 6개를 통과 못 하면 ⑤번 종합 견해의 신뢰도가 깎임.**

### 점검 체크리스트 (자료 1개당)

- [ ] **관점:** 이 자료의 생산자(기자·해설자·기관)는 어느 편을 들고 있나? 공정한가?
- [ ] **관점:** 제시한 해결 방안이 타당한가?
- [ ] **표현:** 왜곡·과장 없는가?
- [ ] **표현:** 자극적·선정적 표현 없는가?
- [ ] **인용:** 출처가 신뢰할 만한가?
- [ ] **인용:** 인용 정보가 정확한가?

## 5. 글쓰기 6단계 일정 매핑

> 교과서 §5의 글쓰기 절차를 학교 일정에 맞춰 배치.

| 학교 일정 | 글쓰기 단계 | 해야 할 일 | 예상 소요 |
|---|---|---|---|
| 4/28~4/30 (완료) | 계획하기 | 도서 선정, 진로·주제 설정 | 완료 ✅ |
| 5/6~5/8 | 도서 확인 | 책 실물 지참, 교사 승인 | 1차시 |
| ~5월 3주 전 | 내용 생성하기 | 책 정독 + 인상 깊은 부분 표시 + 외부 자료 3개 수집 | 5~7일 |
| ~5월 3주 전 | 내용 조직하기 | 본 가이드 §3-(b)의 6문단 설계도 확정 | 1일 |
| 5월 3주 (수업) | 표현하기 (견해 쓰기 수행) | 실제 글쓰기 | 수업시간 |
| 5월 3주 후 | 고쳐쓰기 | 통일성·응집성·쓰기 윤리 점검 | 1~2일 |
| 5월 4주 | 표현하기 (시각자료) | 전술 다이어그램·포메이션 그림 | 2~3일 |
| 5월 5주 | 공유하기 (발표 수행) | 발표 + 출처·저작권 명시 | 수업시간 |
