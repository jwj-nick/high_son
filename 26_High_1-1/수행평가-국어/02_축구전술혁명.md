## 1. 이 책이 적절한가?

### ✅ 긍정적 요소

**교과 적합성:**
- 공통국어1 수행평가에서 도서 장르 제한은 안내문에 명시되지 않음
- 비문학(논픽션) 독서도 국어 수행평가 도서로 일반적으로 허용
- 한준희 감수 → 한국 독자용으로 재편집된 신뢰도 있는 번역서

**수행평가 수행 측면:**
- 관심 분야 = 견해 쓰기의 깊이가 확실히 달라짐 (모르는 책보다 3배 이상 쓸거리 나옴)
- 시각자료: 전술 다이어그램, 포메이션 그림 → 그리기 쉽고 설명하기도 명확
- 발표: 축구 좋아하는 친구들에게 흥미로운 주제, 차별화 가능

**진로 연계:**
- 진로 희망(축구 전술가)과 연결한 독서 → 선생님에게 선택 이유 설명이 자연스럽고 설득력 있음

---

### ⚠️ 주의할 점

| 위험 요소 | 대응 방법 |
|---|---|
| 선생님이 "문학 작품 선호"할 수 있음 | 5/6~8 확인 받을 때 "논픽션·실용서도 가능한가요?" 먼저 질문 |
| 번역서 → 일부 선생님이 원서 선호 | "한준희 감수로 한국어 버전 다듬어짐"을 언급 |
| 전문 용어가 많아 견해 쓰기가 어려울 수 있음 | 전술 설명보다 "왜 이 전술이 중요한가"라는 자신의 관점 중심으로 작성 |

---

### 결론: 적절함 — 단 5/6 확인 시 선생님께 한 가지 먼저 질문할 것

> **확인 질문:** "선생님, 비문학(스포츠 전술 분석서)도 괜찮을까요? 저는 축구 전술 관련 책을 선택했는데요."
> → OK 받으면 그대로 진행. 문학 작품만 가능하다면 아래 §방향 전환 참고.

## 2. 견해 쓰기 3차 준비

견해(見解)는 "내 생각·판단·관점"이다. 책 내용 요약이 아니라 **내가 어떻게 읽고 생각했는지**를 써야 함.

### 견해 쓰기 구조 (매 차수 공통)

```
① 화제 제시: 이 책에서 가장 인상 깊었던 개념/장면 1가지
② 내용 요약: 2~3문장으로 그 내용 설명
③ 나의 견해: "나는 이에 대해 ~라고 생각한다. 왜냐하면 ~"
④ 근거: 책 내용 + 현실 사례 또는 자신의 경험
⑤ 마무리: 이 견해가 주는 의미 또는 질문
```

---

### 1차 견해 주제 예시 — "가장 인상 깊은 전술 개념"

**방향:** 책에서 가장 흥미로운 전술 1가지를 골라 그것이 왜 혁명적인지, 자신은 어떻게 생각하는지 서술.

예시 방향:
- 현대 축구에서 **포지션의 경계가 흐려지는 현상** (ex. 9번 스트라이커의 소멸)
- **고강도 프레싱 전술** (클로핑의 게겐프레싱)의 등장과 축구 패러다임 변화
- **데이터·과학의 도입**이 감독의 직관을 대체하는 것에 대한 찬반

```
[예시 문장]
"이 책에서 가장 인상 깊은 개념은 '포지션의 유동화'였다. 과거 축구는 4-4-2처럼
정해진 자리가 있었지만, 현대 전술은 선수가 상황에 따라 자유롭게 위치를 바꾼다.
나는 이것이 단순히 전술의 변화가 아니라, 선수에게 더 높은 판단력을 요구하는
방향으로 축구 자체가 진화했다는 뜻이라고 생각한다..."
```

---

### 2차 견해 주제 예시 — "동의 또는 반대"

**방향:** 책이 주장하는 관점 중 하나에 대해 찬성/반대 입장 표명.

예시 방향:
- 저자가 "전술이 선수보다 중요하다"고 주장한다면 → 이에 동의하는가?
- "축구는 점점 개인기보다 조직력이 중요해진다" → 메시 같은 천재의 역할은?
- 한국 축구에 이 책의 전술이 적용 가능한가 / 어떤 점이 어렵나?

---

### 3차 견해 주제 예시 — "나의 꿈과 연결"

**방향:** 책에서 배운 것이 자신의 미래 진로(축구 전술가)에 어떻게 연결되는지.

```
[예시 방향]
"이 책을 읽고 전술가에게 필요한 것은 전술 지식 외에도 데이터 분석 능력과
상대 팀에 대한 빠른 관찰력임을 알게 됐다. 나는 앞으로 ~를 공부하겠다는 다짐..."
```

## 3. 시각자료 만들기 준비

발표를 위한 시각자료 — A3 또는 PPT 기준.

### 추천 시각자료 구성

**페이지 1: 표지 / 책 소개**
- 책 표지 이미지 + 저자·출판 정보
- 한 줄 요약: "이 책이 말하는 것은?"

**페이지 2: 핵심 개념 카드 (3~4개)**
- 전술 용어를 간단하게 설명하는 카드 형식
- 예: `프레싱 = 상대가 공을 받자마자 집단 압박`, `4-3-3 포메이션 = 공격 우위 배치`

**페이지 3: 전술 다이어그램** ⭐
- 손으로 그린 포메이션 그림 (직사각형 = 필드, 원 = 선수 위치)
- 책에서 중요하게 다루는 전술 1~2개를 Before/After 형식으로 비교
- 예: 전통 4-4-2 vs 현대 4-3-3의 공격 흐름 화살표

**페이지 4: 나의 견해**
- 책에서 가장 인상 깊은 내용 + 자신의 의견
- "나는 ~라고 생각한다" 1~2문장

**페이지 5: 마무리 / 진로 연결**
- "이 책을 통해 내가 꿈꾸는 축구 전술가란?" 한 문장

---

### 전술 다이어그램 그리는 법 (손으로도 가능)

```
┌─────────────────────────────┐
│              GK             │
│                             │
│   CB       CB       CB      │  ← 수비 라인
│                             │
│      CM    CM    CM         │  ← 중원
│                             │
│   LW        ST        RW    │  ← 공격 라인
└─────────────────────────────┘
  4-3-3 포메이션 예시
```

화살표로 공격 흐름, 프레싱 방향을 표시하면 시각적으로 임팩트 있음.

## 4. 발표하기 준비

발표 구성 (5행씩 5차 기준 — 각 발표는 짧게):

| 발표 차수 | 내용 | 포인트 |
|---|---|---|
| 1차 | 책 소개 + 선택 이유 | "제 꿈이 축구 전술가라서 골랐습니다" — 첫 문장이 중요 |
| 2차 | 핵심 개념 설명 | 전술 다이어그램 보여주며 설명 → 청중 집중도 ↑ |
| 3차 | 가장 인상 깊은 내용 | 구체적 사례 1개 집중 |
| 4차 | 나의 견해 | "나는 ~에 동의/반대한다, 이유는..." |
| 5차 | 마무리 + 추천 | "이런 사람에게 추천" + 진로 연결 마무리 |

**발표 팁:**
- 전술 다이어그램은 A3 크기로 출력하거나 태블릿 화면으로 보여주기
- 청중이 몰라도 이해할 수 있도록 "축구를 잘 모르는 분도 이해할 수 있게 설명하겠습니다"로 시작
- 한준희 해설위원이 감수했다는 것을 언급하면 신뢰도 UP

## 5. 방향 전환 — 선생님이 다른 장르를 요구하는 경우

만약 5/6 확인 시 "문학 작품이어야 한다"는 피드백이 오면:

### 대안 1: 스포츠 문학으로 전환 (관심사 유지)
- **"파울볼"** 계열의 스포츠 에세이 또는 소설
- 축구 선수 자서전 → 에세이 형식이라 견해 쓰기 용이
- 예: 손흥민·박지성 자서전, 스포츠 작가 에세이

### 대안 2: 진로 관련 넓은 주제로 전환
- 스포츠 과학, 데이터 분석, 전략적 사고 관련 교양서
- 스포츠 사회학 관련 도서 (체육 + 인문 접점)

### 대안 3: 완전히 다른 관심사
- 최후 수단. 5/6~8 안에 다른 책 읽을 시간이 없으므로, 가능한 한 현재 선택 유지 권장
