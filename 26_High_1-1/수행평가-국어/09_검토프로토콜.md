# 09 검토 프로토콜 — 어떤 글이든 채점 기준으로 자가검증

> **목적:** 견해문/포스터 캡션/발표 스크립트/이메일 답변 등 **이번 수행평가에서 적어내는 어떤 글이든**, 학교 채점 기준 + 교과서 글의 짜임 원칙으로 일관되게 점검할 수 있는 검토 도구.
> **사용법:**
> - 사람용: §1·§2 체크리스트로 직접 점검 (15분 이내)
> - Claude 자동 검토용: Nick이 "이 글 검토해줘"라 하면 Claude가 §3 프로토콜대로 점검 → §4 양식으로 리포트
> **출력:** 점수표 + 약점 항목 + 다음 옵션 (08 옵션뱅크 어디로 돌아갈지)

---

## §1. 자가검토 체크리스트 — 견해문 (12+8 항목)

> 글 한 편을 다 읽고, 각 항목 옆에 ✅ / ⚠️ / ❌ 표시.
> ✅ 명확히 충족 / ⚠️ 부분 충족 / ❌ 미충족

### A. 진로·관심 분야 연결 (3개)
- [ ] **A-①** 진로/관심 분야가 **구체적 직무명**까지 명시되었나? (예: "축구 좋아함" ❌ → "전술 분석가" ✅)
- [ ] **A-②** "진로 = X / 책 = X에 대한 것" 같은 **직접 연결 문장**이 있나?
- [ ] **A-③** 책이 너에게 **어떤 변화·영향**을 줬는지 썼나? ("재밌었다" ❌ → "막연히 보던 것을 ~로 보게 되었다" ✅)

### B. 책·자료 탐색·재구성 (3개)
- [ ] **B-①** 작가 + 주제 정보가 본문에 들어갔나?
- [ ] **B-②** 책 내용 요약이 6~10문장 안에 압축되었나?
- [ ] **B-③** 외부 사실/자료를 **자기 말로 재구성**했나? (단순 나열 ❌, 책 논지와 묶어 풀어쓰기 ✅)

### C. 견해 쓰기 본문 (6개) ⭐
- [ ] **C-①** 작품·작가에 대한 설명이 본문에 한 번 더 정리되었나?
- [ ] **C-②** 인상 깊은 부분 + **이유** 둘 다 썼나? ("재밌었다" 류는 이유 ❌)
- [ ] **C-③** 개인 경험·사회 현상과 책 내용의 **연결점**이 있나?
- [ ] **C-④** 그 연결점에 대한 **구체 근거**(수치·사례·자료) 1개 이상 있나?
- [ ] **C-⑤** 종합 견해 4종(해석/평가/해결방안/시사점) 중 **2개 이상**이 명시되었나?
- [ ] **C-⑥** 큰 원리(시간/공간/논리) **명시** + 세부 전개 방법 **2종 이상** 사용되었나?

### D. 글의 짜임 (교과서 §3·§4·§5 — 8개)
- [ ] **D-1 통일성** 모든 문단이 하나의 주제로 모이나?
- [ ] **D-2 응집성** 문단끼리 자연스럽게 이어지나? (접속어·지시어 점검)
- [ ] **D-3 일관성** 처음~끝 같은 문체·관점인가?
- [ ] **D-4 단계성** 도입→본론→결론 흐름이 있나?
- [ ] **D-5 큰 원리 명시** 시간/공간/논리 중 어느 것을 썼는지 글에 드러나나?
- [ ] **D-6 세부 전개 방법** 분석/분류/비교·대조/인과/과정 중 2종 이상이 명확히 식별되나?
- [ ] **D-7 쓰기 윤리** 외부 사실에 출처 의식이 있나? (수업시간엔 "OO에 따르면" 정도)
- [ ] **D-8 자기 말로 재구성** 책·자료의 표현을 그대로 베끼지 않고 자기 말로 풀었나?

## §2. 자가검토 체크리스트 — 포스터/발표용 변형

### 포스터 (시각자료)
- [ ] **P-1** 헤더에 제목 + 시의성(월드컵 등) 한 줄 있나?
- [ ] **P-2** 책 정보 (작가/감수/출판) 있나? — B-① 대응
- [ ] **P-3** 책 핵심 컨셉(예: "작용과 반작용") 강조되었나? — B-② / C-① 대응
- [ ] **P-4** 시각요소 1개 이상이 책 내용을 직접 시각화하나? (타임라인/포메이션 등) — C-② 대응
- [ ] **P-5** 사회·산업 연결 인포그래픽이 있나? (수치 포함) — C-③④ 대응
- [ ] **P-6** 결론 박스에 진로 메시지 + 종합 견해 있나? — A-③ / C-⑤ 대응
- [ ] **P-7** 영역마다 "전개 방법" 작은 라벨이 있나? — C-⑥ 대응
- [ ] **P-8** 출처 표기 푸터 있나? — D-7 대응

### 발표 스크립트
- [ ] **S-1** 도입 30초 안에 청중을 끌어당기는 훅이 있나? (시의성/질문/충격 사실)
- [ ] **S-2** 시간 배분이 명시되었나? (5분이면 5구간)
- [ ] **S-3** 포스터의 시각요소를 가리키며 설명하는 동선이 있나?
- [ ] **S-4** 결론에 진로 메시지 1줄이 명확히 들어가나?
- [ ] **S-5** 어려운 용어(게겐프레싱 등) 첫 등장 시 정의 1줄이 있나?

## §3. Claude 자동 검토 프로토콜

> Nick이 "이 글 검토해줘", "v2 검증해줘", "포스터 캡션 점검해줘" 등을 요청하면 Claude는 다음 순서로 작동.

### Step 1 — 대상 파악
1. 검토할 텍스트 또는 파일 경로 확인
2. 종류 식별: 견해문 / 포스터 / 발표 스크립트 / 기타
3. 분량 측정 (글자 수, 문단 수)

### Step 2 — 기준 적용
- 견해문 → §1 (A·B·C·D 20개 항목)
- 포스터 → §2 P 시리즈 (8개)
- 발표 스크립트 → §2 S 시리즈 (5개) + §1 D-1·D-2·D-3 (응집성)
- 기타 글 → §1 D 시리즈 (글의 짜임 8개)만이라도

### Step 3 — 점수화
각 항목 ✅=2점 / ⚠️=1점 / ❌=0점
- 견해문: 만점 = 20×2 = 40점
- 포스터: 만점 = 8×2 = 16점
- 발표: 만점 = (5+3)×2 = 16점

### Step 4 — 약점 항목 분석
- ⚠️·❌ 항목마다:
  - **이유** (왜 부족한가)
  - **개선 방향** (구체적 수정 제안)
  - **돌아갈 자리** ([08_옵션뱅크.md](08_옵션뱅크.md)의 어느 §)

### Step 5 — 리포트 출력 (§4 양식)

---

## §4. 검토 리포트 양식 (Claude 출력 표준)

```markdown
# 검토 리포트 — [파일/대상명] / [버전]

## 종합 점수: XX / YY (XX%)

## ✅ 강점 (충족된 항목)
- A-①, A-②, B-①, ... (간단히 나열)

## ⚠️ 부분 충족 — 보강 권장
| 항목 | 현재 상태 | 개선 방향 | 돌아갈 자리 |
|---|---|---|---|
| A-③ | 책의 의미를 1줄만 언급 | 변화·영향을 구체 사례로 1문장 추가 | 08 §3 |
| C-④ | 근거가 추상적 | 수치 1개 이상 추가 (156억·800억 등) | 08 §5 |

## ❌ 미충족 — 반드시 수정
| 항목 | 누락된 것 | 어디에 추가 | 돌아갈 자리 |
|---|---|---|---|
| C-⑥ 메타 한 줄 | 없음 | 6문단 마지막 | 08 §7 |

## 글의 짜임 (D 시리즈) 종합 평가
- 통일성: ✅
- 응집성: ⚠️ (3문단→4문단 전환이 갑작스러움)
- 큰 원리: ✅ (시간 순서 명시)
- 세부 전개: ✅ (분석·과정·비교·대조 식별됨)

## 다음 액션 (우선순위)
1. C-⑥ 메타 한 줄 추가 — [08_옵션뱅크.md §7] A 후보로 (즉시)
2. C-④ 근거 보강 — 5문단에 156억 숫자 추가 (5분)
3. 응집성 — 3→4문단 전환에 "그 한 장면이 바로 그것이다" 류 연결문 (2분)

## 예상 채점 변화
- 현재 추정: 12개 항목 중 8개 만점
- 위 3개 수정 후: 12개 모두 만점 가능
```

## §5. 검토 호출 트리거 (편하게 부르는 법)

> 다음 중 어떤 표현이든 Claude는 §3 프로토콜로 작동:

| 표현 예시 | 의미 |
|---|---|
| "검토해줘" / "review" | 가장 최근 산출물 검토 |
| "[파일명] 검토해줘" | 특정 파일 검토 |
| "v2 검증해줘" | 견해문 v2 등 버전 검증 |
| "이 글 채점 기준 통과해?" | 동일 |
| "약한 부분 어디?" | 약점만 추려서 |
| "어디 더 손봐야 해?" | 동일 |

## §6. 시험 당일 자가 검토 (15분 안에)

> 견해문은 무자료 작성이므로 Claude 검토 불가. 대신 **본인이 5분 안에 §1 20개 항목**을 빠르게 점검.

### 시험장 5분 자가 검토 순서
1. **글 끝에 메타 한 줄 있나?** (없으면 즉시 추가) ← C-⑥
2. **5문단에 수치 3개 들어갔나?** (156, 800, 50) ← C-④
3. **1·6문단에 진로 단어 있나?** (수미상관) ← A-①·A-③
4. **2문단에 "작용과 반작용" 있나?** ← B-②
5. **3문단에 4단계(WM/토털/게겐/AI) 다 있나?** ← C-②
6. **4문단에 "왜냐하면" 류 이유 있나?** ← C-②
7. **5문단에 옛 vs 오늘 비교 구조 있나?** ← C-③
8. **6문단에 시사점 + 진로 다짐 있나?** ← C-⑤

8개 다 ✅이면 거의 만점.

## §7. 검토 도구 활용 시나리오

### 시나리오 A: 빈칸 채운 후 v2 검증
```
Nick: "[BLANK] 다 채웠어. 견해문 v2 검토해줘"
Claude: §3 프로토콜 → §4 양식으로 리포트
```

### 시나리오 B: 포스터 시안 점검
```
Nick: "포스터 시안 채점 기준 다 통과해?"
Claude: §2 P 시리즈로 점검 → 약점 + 보강 제안
```

### 시나리오 C: 새 후보 비교
```
Nick: "1문단을 D 후보로 바꾸면 어떤가?"
Claude: 수정안 작성 → 8개 글의 짜임 항목 체크 → 변경 전/후 비교
```

### 시나리오 D: 발표 스크립트 검증
```
Nick: "발표 스크립트 5분 안에 들어가? 청중 시선 끄나?"
Claude: 시간 측정 + S 시리즈 5개 + 동선 검토
```

## §8. 자주 빠지는 함정 (Claude 검토 시 우선 점검)

| # | 함정 | 어떻게 잡나 |
|---|---|---|
| 1 | "재밌었다"로 끝난 인상 깊은 이유 → C-② ❌ | "왜냐하면" 같은 인과 표지 검색 |
| 2 | 글의 짜임 메타 한 줄 누락 → C-⑥ ❌ | 마지막 문단의 마지막 1~2문장에 "전개", "원리", "방법" 단어 검색 |
| 3 | 외부 자료 인용 시 출처 의식 부재 → D-7 ❌ | "에 따르면", "보도되었다" 등 검색 |
| 4 | 진로가 막연 ("축구 좋아함") → A-① ❌ | "전술 분석가", "감독" 같은 직무명 검색 |
| 5 | 책 요약이 줄거리 나열 → B-② ❌ | 책의 큰 구조(작용과 반작용 / 명장 10명 / 미래 예측) 명시 여부 |
| 6 | 5문단 비교 축이 모호 → C-③ ❌ | "옛", "지금", "그러나", "반면" 같은 대조 표지 검색 |
| 7 | 3문단 시간 순서가 깨짐 → ⑥ 큰 원리 ❌ | 연도(1930·1970·2010·2020)가 순서대로 나오는지 |
| 8 | 같은 단어 4번 이상 반복 → D-2 응집성 ⚠️ | 빈도 카운트 |

## §9. 다음 단계

- **즉시 사용 가능:** Nick이 어떤 산출물이든 "검토해줘"라 부르면 작동
- **반복 검토 가능:** v1 → 검토 → v2 → 검토 → v3, 채점 기준 만점에 수렴할 때까지
- **다른 과목 재사용 가능:** 한국사·과학·국어·수학 수행평가 어느 글이든 "글의 짜임" D 시리즈 8개는 그대로 적용 가능 → §1 D 부분만 떼어내 다른 과목용으로 변형 가능
