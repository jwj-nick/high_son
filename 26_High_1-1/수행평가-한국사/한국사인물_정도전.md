# 한국사인물 — 정도전 (鄭道傳)

> 과제 범위: 고려 태조 ~ 조선 병자호란(1636) ✅ 해당 (여말선초)
> 난이도: ★★★ (조선 건국 이념까지 연결 필요)
> 이 파일은 **힌트 초안**입니다. 직접 찾아보고 빈 칸을 채워 완성하세요.

## Q1. 인적사항 (2점)

| 항목 | 내용 | 확인 필요 |
|---|---|---|
| 이름 | **정도전 (鄭道傳)** | ✅ |
| 자·호 | 자: 종지(宗之), 호: 삼봉(三峰) | ✅ |
| 생몰연대 | **1342 ~ 1398** | 직접 확인 |
| 시대 | 고려 말 → 조선 건국기 | ✅ |
| 사망 원인 | 1차 왕자의 난으로 이방원에게 피살 | ✅ |

> 💡 정도전은 고려 관리였다가 이성계를 도와 **조선을 설계한 사람**. 단순한 신하가 아니라 "조선의 설계자"라 불린다.

## Q2. 인물이 살던 시기의 사회 문제 (3점 — 120~160자)

### 핵심 키워드

- 🔑 **권문세족의 토지 겸병** — 고려 말, 특권 귀족이 대규모 농장(농장제) 소유
- 🔑 **불교의 폐단** — 사원이 토지·노비 대거 소유, 세금 면제 → 국가 재정 악화
- 🔑 **고려 왕조의 부패·무능** — 원나라 간섭 후 왕권 약화, 무신정권 유산
- 🔑 **왜구·홍건적 침입** — 민생 피폐, 군사력 약화
- 🔑 **성리학 대 불교** — 새로운 통치 이념의 필요성

### 작성 방향

```
[고려 말 위기] = 토지 문제 + 이념(불교 폐단) + 외침 + 왕권 약화
정도전이 보기엔 → 고려를 개혁이 아니라 교체해야 할 상황
```

> 🤔 스스로 생각해보기: "정도전은 왜 고려를 개혁하는 대신 새 나라를 세우는 길을 선택했을까?"

## Q3. 정도전의 개혁안 (3점 — 120~160자)

### 주요 개혁 목록

| 개혁 이름 | 한 줄 설명 | 내 설명으로 바꾸기 |
|---|---|---|
| **과전법 (科田法)** | 경기도 땅을 관리에게 수조권(세금 거둘 권리)으로 나눠주고, 죽으면 국가 반납 | → 직접 조사 필요 |
| **조선 경국대전 기초** | 법전 편찬으로 법 지배 국가 설계 | ✅ |
| **재상 중심 정치** | 왕보다 능력 있는 재상이 실질 통치 → 이방원과 갈등 원인 | ✅ |
| **불교 억제·성리학 장려** | 불교 폐단 비판 (*불씨잡변*), 유교 통치 이념 확립 | ✅ |
| **군사 개혁** | 사병 혁파 → 공병(公兵)으로 국가 군사 일원화 | ✅ |

> ⚠️ **과전법**이 출제에서 단골! "토지를 나눠줬다"가 아니라 **"수조권을 지급하고 죽으면 반납"**이라는 특징까지 써야 함.

### 저서 목록 (심화 — 관심 있으면)

| 저서 | 내용 |
|---|---|
| *조선경국전* | 조선의 통치 설계도 |
| *경제문감* | 재상 중심 정치론 |
| *불씨잡변* | 불교 비판 |
| *삼봉집* | 문집 |

## Q4. 나만의 개혁안 2가지 (7점 — 학생이 직접 작성)

### 생각 방향

정도전이 해결하려 한 핵심 문제:
1. **토지 불평등** → 과전법으로 일부 해결. 더 근본적인 방법은?
2. **불교의 국가 자원 점유** → 종교와 국가 재정의 관계를 어떻게 설정?
3. **왕권 vs 신권의 균형** → 지금 시대로 치면 어떤 문제와 비슷한가?

> 💡 힌트: "정도전의 개혁안이 해결 못 한 것"을 보완하는 방향으로 쓰면 설득력이 높아집니다.

## 이 인물을 선택하면 좋은 이유 / 주의점

✅ **장점:** 개혁 내용이 구체적(과전법, 재상제, 불교 억제) → Q3 쓰기 쉬움
✅ **장점:** 비극적 최후(이방원에 피살)로 이야기가 풍부
✅ **장점:** 고려 말 문제 → 조선 건국으로 이어지는 인과관계 명확
⚠️ **주의:** "고려 개혁가"인지 "조선 건국자"인지 정체성 설정 필요
⚠️ **주의:** 이방원(태종)과의 갈등 — 재상 중심 정치 vs 왕권 강화 구도 이해 필수
